# Challenge 1: Foundation

**Required.** Roughly 45 minutes.

Add a second page and link the two together.

## Task

1. Create `programmes.html` alongside your `index.html`.
2. Give it the same structure: `lang`, `charset`, `viewport`, `title`, skip link, header, nav, main, footer.
3. Move the detail of one programme onto the new page, and expand it into two or three paragraphs.
4. Link from `index.html` to `programmes.html`, and back again.
5. Add the new page to the navigation on **both** pages.

## Why this matters

Almost every real website is more than one page. The moment you add a second page, you meet a problem that never comes up with one: navigation must stay consistent, and every page needs its own complete `<head>`. There is no shortcut yet — you copy it. Later courses show you how to stop copying.

## Done when

- [ ] Both pages validate with zero errors.
- [ ] Both pages have a unique, descriptive `<title>`.
- [ ] You can move between them in both directions using only the keyboard.
- [ ] The navigation is identical on both pages, and the link text names its destination.
