# 挑战 2：创意

**可选。** 约 90 分钟。

让这个页面真正属于你。

## 任务

完全替换示例内容。围绕你真正关心的事物来构建页面：你自己的社区团体、本地组织、某项公益事业、家族历史，或你熟悉的主题。

1. 把示例文字逐字替换为你自己的内容。
2. 使用你自己的照片，并为每张照片撰写替代文本。
3. 如果你的母语不是英语，请用你的语言撰写页面，并相应设置 `lang`。中文简体页面应声明 `lang="zh-Hans"`，西班牙语页面应声明 `lang="es"`。
4. 如果你用两种语言撰写，请创建两个页面并互相链接，各自设置正确的 `lang`。

## 为什么这很重要

`lang` 属性不是装饰。屏幕阅读器依靠它选择发音引擎。用英语语音朗读中文内容几乎无法听懂，而这正是真实多语言网站上反复出现的错误。

构建你真正关心的东西，也会改变你投入的用心程度。这是练习与作品之间的区别。

## 完成标准

- [ ] 原示例文字一个字都没有留下。
- [ ] `lang` 与你实际使用的语言正确对应。
- [ ] 每张图片的替代文本都贴合你的语境，而非示例的语境。
- [ ] 页面仍然通过校验且零错误。
- [ ] 你愿意把这个页面展示给它所描述的那个社区。
