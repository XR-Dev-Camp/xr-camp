# 挑战 1：基础

**必做。** 约 45 分钟。

新增第二个页面，并把两个页面互相链接起来。

## 任务

1. 在 `index.html` 旁边创建 `programmes.html`。
2. 使用相同的结构：`lang`、`charset`、`viewport`、`title`、跳转链接、header、nav、main 和 footer。
3. 把其中一个项目的详细内容移到新页面，并扩展为两到三段。
4. 从 `index.html` 链接到 `programmes.html`，并加上返回链接。
5. 在**两个**页面的导航中都加入新页面。

## 为什么这很重要

几乎所有真实网站都不止一个页面。一旦增加第二个页面，就会遇到单页面时不会出现的问题：导航必须保持一致，而且每个页面都需要自己完整的 `<head>`。目前还没有捷径——只能复制。后续课程会教你如何不再重复复制。

## 完成标准

- [ ] 两个页面都通过校验且零错误。
- [ ] 两个页面都有独立且具描述性的 `<title>`。
- [ ] 仅用键盘就能在两个页面之间双向跳转。
- [ ] 两个页面的导航完全一致，且每个链接的文字都写明了目标页面。
