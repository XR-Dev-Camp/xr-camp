# Challenge 2: Creative

**Optional.** Roughly 90 minutes.

Make this page genuinely yours.

## Task

Replace the example content entirely. Build the page for something real that you care about — your own community group, a local organisation, a cause, a family history, a subject you know well.

1. Replace every word of placeholder text with your own.
2. Use your own photographs, and write alt text for each one.
3. If your first language is not English, write the page in your language and set `lang` to match. A page in Spanish must say `lang="es"`; a page in Simplified Chinese, `lang="zh-Hans"`.
4. If you write it in two languages, create two pages and link them, each with the correct `lang`.

## Why this matters

The `lang` attribute is not decoration. A screen reader uses it to pick a pronunciation engine. Spanish text read aloud by an English voice is close to unintelligible — and this is a mistake made constantly on real multilingual sites.

Building something you care about also changes how carefully you build. It is the difference between an exercise and a piece of work.

## Done when

- [ ] Not one word of the original example text remains.
- [ ] `lang` correctly matches the language you actually wrote in.
- [ ] Every image has alt text that suits your context, not the example's.
- [ ] The page still validates with zero errors.
- [ ] You would be willing to show this page to the community it describes.
