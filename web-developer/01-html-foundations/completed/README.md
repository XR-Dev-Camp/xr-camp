# Completed — HTML Foundations

The reference solution. Open it **after** you have attempted the project.

## What this is

A community centre information page demonstrating every topic in Course 1.1:
document structure, head and body, headings, paragraphs, lists, links, images
and alt text, semantic landmarks, tables, video with captions, metadata, and
code comments.

The markup is heavily commented. The comments explain *why* each decision was
made, not what the tag is called.

## Why it looks so plain

There is no CSS. That is deliberate, and it is the main lesson of this project.

You have not learned CSS yet — that is Course 1.3. What you see is the
browser's default rendering of well-structured HTML. It is plain, and it is
entirely usable: readable, keyboard-navigable, and correctly announced by a
screen reader.

Structure first. CSS decorates a page that already works; it cannot rescue one
that does not.

## Comparing against your own work

Differences are expected and often fine. Ask about each one:

- Does mine convey the same structure to a screen reader?
- Would my alt text let someone who cannot see the image carry on?
- Does my heading order form a sensible outline on its own?

If yes, your version is correct even where it differs. There is rarely one
right answer in HTML — but there are many wrong ones, and most of them are
wrong for accessibility reasons rather than aesthetic ones.
