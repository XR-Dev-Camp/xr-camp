# Project check — HTML Foundations

Work through every item before you submit. Each one maps to something you were
asked to learn in this course.

## Document structure
- [ ] The file begins with `<!DOCTYPE html>`.
- [ ] `<html>` carries a `lang` attribute matching the language you actually wrote in.
- [ ] `<meta charset="UTF-8">` is the first element inside `<head>`.
- [ ] A viewport meta tag is present.
- [ ] `<title>` is descriptive and specific, not "Untitled" or "My page".
- [ ] `<meta name="description">` is present and readable.

## Headings
- [ ] Exactly one `<h1>`.
- [ ] Heading levels descend without gaps (no `<h2>` followed by `<h4>`).
- [ ] Every heading level was chosen for structure, not for text size.

## Landmarks
- [ ] `<header>`, `<nav>`, `<main>`, and `<footer>` are all present.
- [ ] There is exactly one `<main>`.
- [ ] Where two navigation landmarks exist, each has its own `aria-label`.

## Links
- [ ] A skip link is the first focusable element in `<body>`.
- [ ] The skip link targets an element that exists.
- [ ] Every in-page link resolves to a matching `id`.
- [ ] No link text reads "click here", "read more", or "link".
- [ ] Any link opening in a new tab says so, and carries `rel="noopener"`.

## Images
- [ ] Every `<img>` has an `alt` attribute.
- [ ] Alt text describes purpose in context, not appearance.
- [ ] No alt text begins with "Image of" or "Picture of".
- [ ] Decorative images use `alt=""` rather than omitting the attribute.
- [ ] Every image has `width` and `height`.

## Tables
- [ ] Tables are used only for data, never for layout.
- [ ] Every table has a `<caption>`.
- [ ] Column headers use `<th scope="col">`.
- [ ] Row headers use `<th scope="row">`.

## Media
- [ ] Audio or video carries the `controls` attribute.
- [ ] A `<track kind="captions">` is present.
- [ ] Fallback content between the tags offers another route to the information.

## Keyboard
- [ ] You navigated the entire page using only Tab, Shift+Tab, and Enter.
- [ ] Focus is visible on every interactive element.
- [ ] The tab order follows the visual reading order.
- [ ] Nothing traps focus.

## Validation
- [ ] The page validates at validator.w3.org with **zero errors**.
- [ ] You read every warning and decided about each one deliberately.

## Code quality
- [ ] Indentation is consistent.
- [ ] Comments explain why, not what.
- [ ] No leftover `TODO` comments from the starter.
- [ ] Someone else could open this file and follow it.

## Honest self-assessment
- [ ] You can explain every line you wrote, in your own words.
- [ ] Where you used AI assistance, you understood and verified the result.
- [ ] You tested with a screen reader, or you know that you have not yet.
