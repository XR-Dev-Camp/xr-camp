# Bug reports

One report for each bug you find. Copy the template below for each one.

---

## Bug N: (a short title that says what is wrong)

- **Where:** (page, and the part of it)
- **Steps to reproduce:**
  1. …

- **Expected:** (what should happen)
- **Actual:** (what happens instead)
- **Device and browser:** (for example: Android phone, Chrome)
- **Found with:** (keyboard, Console, Network, Elements, device mode, a breakpoint, axe, a screen reader…)

- **Fix:** (what you changed, and in which file and line)
