# 挑战 3：探索

**选做。** 约 45 分钟。

用性能面板分析一个真实的网站。

## 任务

1. 打开一个大型的真实网站：新闻网站或网上商店。
2. 打开 **Performance**（性能）面板，按下录制按钮，刷新页面，几秒钟后停止录制。
3. 找出：第一批内容出现之前用了多长时间，最长的单个任务是什么，以及哪些文件最大（在 **Network**（网络）面板中查看）。
4. 对你的项目浏览器做同样的事。把两个结果并排写在你的学习日志中。

## 为什么这很重要

XR Camp 的许多学员使用的手机和网络，比大多数网站开发者使用的要慢。能够测量是什么让页面变慢，是为她们构建快速页面的第一步。

## 完成标准

- [ ] 你的学习日志对比了一个真实网站和你的项目浏览器。
- [ ] 你写出了真实网站上最大的三个文件。
