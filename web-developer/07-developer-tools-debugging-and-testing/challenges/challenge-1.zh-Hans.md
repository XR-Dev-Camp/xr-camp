# 挑战 1：基础

**必做。** 约 45 分钟。

自己埋下五个缺陷，然后和同伴交换。

## 任务

1. 复制一份你修复好的项目浏览器。
2. 埋下五个缺陷：至少一个在 HTML 中，一个在 CSS 中，一个在 JavaScript 中，还有一个无障碍问题。偷偷记下你改了什么。
3. 只写下**症状**，就像用户描述问题时那样。
4. 和另一位学员（或者一位同样在学习的朋友）交换。找出并修复对方的缺陷，并为每个缺陷写一份报告。
5. 对比一下：你的同伴找到你埋下的原因了吗？

## 为什么这很重要

埋缺陷会让你思考东西是怎样坏掉的，这会让你修复缺陷的速度快得多。而阅读别人的缺陷报告，能让你很快看出自己的报告是否清楚。

## 完成标准

- [ ] 你埋下了五个缺陷，并写下了症状。
- [ ] 你找到了同伴的缺陷，并写了报告。
