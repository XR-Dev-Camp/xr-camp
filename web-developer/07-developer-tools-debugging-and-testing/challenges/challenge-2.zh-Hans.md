# 挑战 2：创意

**选做。** 约 30 分钟。

用你自己的语言解释一个缺陷，以及你是怎样找到它的。

## 任务

1. 选出让你学到最多的那个缺陷。
2. 用你思考时使用的语言，为刚刚起步的人写一段简短的解释：症状是什么，你打开了哪个工具，你看到了什么，修复方法是什么。
3. 加一张工具显示出问题的截图。
4. 把它加入你的学习日志，或者写成一篇短文，等 XR Camp 社区开放后分享。

## 为什么这很重要

用浅显的话解释一个缺陷，是检验你是否真正理解它的方法。用西班牙语、葡萄牙语和中文写的解释也很少见，因而很有价值：网上的调试帮助大多是英文的。

## 完成标准

- [ ] 你的解释使用你自己的语言，并附有截图。
- [ ] 刚开始学编程的人也能看懂。
