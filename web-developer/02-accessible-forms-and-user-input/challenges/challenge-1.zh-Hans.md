# 挑战 1：基础

**必做。** 约 40 分钟。

添加一个日期字段和第二个菜单，并正确地加上标签。

## 任务

1. 添加一个字段，用于填写想要开始参加的日期，使用 `type="date"`，并加上标签。
2. 添加一个 `<select>`，询问对方是如何知道这个活动中心的：「A friend」（朋友）、「Social media」（社交媒体）、「A poster」（海报）、「Other」（其他）。把一个中立的选项放在最前面：「Prefer not to say」（不想透露）。
3. 决定每个新字段是否应该设为必填。在一段 HTML 注释中解释你的决定。

## 为什么这很重要

你添加的每一个字段，都是人们必须回答的一个问题，也是你必须妥善保管的一项信息。决定哪些是可选的，是一项设计决策，而不是一个细节。

## 完成标准

- [ ] 两个字段都有可见且已关联的标签。
- [ ] 在你的手机上，日期字段会显示日期选择器。
- [ ] 你的注释解释了每个字段为什么是或不是必填。
