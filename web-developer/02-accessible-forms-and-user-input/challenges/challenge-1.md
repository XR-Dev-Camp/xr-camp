# Challenge 1: Foundation

**Required.** Roughly 40 minutes.

Add a date field and a second menu, correctly labelled.

## Task

1. Add a field for the date someone would like to start, with `type="date"` and a label.
2. Add a `<select>` for how they heard about the centre: "A friend", "Social media", "A poster", "Other". Put a neutral first option, "Prefer not to say".
3. Decide whether each new field should be required. Explain your decision in an HTML comment.

## Why this matters

Every field you add is a question people must answer, and information you must look after. Deciding what is optional is a design decision, not a detail.

## Done when

- [ ] Both fields have visible, linked labels.
- [ ] The date field shows a date picker on your phone.
- [ ] Your comment explains why each field is or is not required.
