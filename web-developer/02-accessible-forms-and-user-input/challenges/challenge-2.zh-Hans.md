# 挑战 2：创意

**选做。** 约 45 分钟。

翻译你的表单，包括其中的提示和隐私说明。

## 任务

1. 用你自己的语言制作一份 `join.html` 的副本，例如 `unirse.html` 或 `join-zh.html`。
2. 翻译每一个标签、legend、提示、选项、按钮，以及隐私说明。在文件顶部设置 `lang`。
3. 让 `id`、`name`、`type` 和 `autocomplete` 的值保持英文：它们是代码，不是文字。
4. 留意哪些内容变长了。西班牙语文字通常比英文长；中文通常比英文短。

## 为什么这很重要

用一个人自己的语言写成的表单，要正确填写就容易得多。分清哪些部分是文字、哪些部分是代码，是一项你将在课程 6.2 构建完整的多语言网站时用到的技能。

## 完成标准

- [ ] 每一个可见的词语都使用你的语言，并且 `lang` 与之相符。
- [ ] 每一个 `id`、`name`、`type` 和 `autocomplete` 的值都没有改变。
