# Completed — Accessible Forms and User Input

The reference solution. Open it **after** you have built your own forms.

## What this is

The Riverside Community Centre's "Join a programme" page: a registration form
and a feedback form, with no CSS yet. "Home" points to the finished site from
Course 1.1.

## Comparing against your own work

Your fields and wording can differ. Check only:

- Does every field say what it is, out loud, in a screen reader?
- Can someone complete and send each form with only a keyboard?
- Is every piece of information you ask for really needed?

If yes, your version is correct.
