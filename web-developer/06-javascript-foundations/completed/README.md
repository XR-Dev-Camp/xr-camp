The reference solution: the programme explorer. Open it **after** you have
written your own `explorer.js`.

## Comparing against your own work

Your code can be organised differently. Check only:

- Does every control filter the results, and is the count announced?
- Do saves survive a reload, and does the page still work if storage fails?
- Can you do everything with the keyboard?

If yes, your version is correct.
