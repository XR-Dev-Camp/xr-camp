# Starter — JavaScript Foundations

Begin here.

- `explorer.js` has twelve numbered `TODO` comments, and three programmes to
  start with. Work through them in order, with the browser console open.
- `index.html` is the finished explorer page: you do not need to change it.
- `styles.css` is the site's stylesheet, with explorer styles added.
- `3d-moment.html` is this lesson's 3D moment.
