Accessibility audit: Riverside events page

Audited by Ana. Tested with the keyboard only, NVDA with Firefox, VoiceOver on an iPhone, zoom to 200%, and the axe DevTools and WAVE browser extensions. Before: the original page. After: the repaired page.

Summary

I found 16 problems. The most serious: the Send "button" could not be used with a keyboard, the email field had no label, and the moving banner could not be stopped. The automated tools found only some of them; I found the rest by testing with the keyboard, a screen reader, and my eyes.

What the tools missed

The automated tools could not tell me that the alt text "decoration" was noise, that "click here" goes nowhere useful, that red was the only way to see which events were full, or that the tab order was confusing. Automated tools catch some problems; people catch the rest.
