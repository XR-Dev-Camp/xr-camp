# 挑战 1：基础

**必做。** 约 30 分钟。

录制一段只用键盘浏览你修复好的页面的视频。

## 任务

1. 使用电脑自带的录屏工具（在 Windows 上，使用「截图工具」（Snipping Tool）的录制选项，或者用 Xbox Game Bar 按 **Windows + Alt + R**；在 Mac 上，按 **⌘ + Shift + 5**）。
2. 录下你只用键盘使用修复好的页面的过程：跳转链接、标题、表格、链接，以及提交表单。
3. 然后用 `original.html` 录制同样的过程，在你卡住的地方停下来。
4. 把两段录像和你的审查报告保存在一起。

## 为什么这很重要

一段有人卡住的短视频，往往就是说服一个团队去修复问题的东西。亲眼看到，比一张写满规则编号的表格更有说服力。

## 完成标准

- [ ] 你有两段录像：修复好的页面能正常使用，原始页面无法使用。
- [ ] 修复好的页面的录像中完全没有使用鼠标。
