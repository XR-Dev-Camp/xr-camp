# 挑战 3：探索

**选做。** 约 45 分钟。

为你的网站写一份无障碍声明。

## 任务

1. 阅读 W3C 的指南 [Developing an accessibility statement](https://www.w3.org/WAI/planning/statements/)（制定无障碍声明，英文）。
2. 为你的网站写一个 `accessibility.html`，内容包括：
   - 你的承诺，以及你的目标标准（WCAG 2.2 AA 级）；
   - 你是怎样测试的（键盘、屏幕阅读器、工具、设备）；
   - 所有已知的问题，要诚实地写出来，并说明你打算什么时候修复；
   - 人们怎样向你报告问题，以及你会多快回复。
3. 在每个页面的页脚中链接到它。

## 为什么这很重要

没有哪个网站是完美的。一份诚实的声明会告诉人们可以期待什么，以及当某些东西无法使用时怎样联系你。这比声称完美更能建立信任。

## 完成标准

- [ ] 你的声明涵盖了全部四点。
- [ ] 每个页面都链接到它。
