# Reto 1: Fundamento

**Obligatorio.** Aproximadamente 30 minutos.

Graba un recorrido de tu página reparada usando solo el teclado.

## Tarea

1. Usa la grabadora de pantalla de tu computadora (en Windows, la opción de grabar de la Herramienta Recortes, o **Windows + Alt + R** con Xbox Game Bar; en una Mac, **⌘ + Shift + 5**).
2. Grábate usando la página reparada solo con el teclado: el enlace de salto, los encabezados, la tabla, el enlace y el envío del formulario.
3. Luego graba lo mismo con `original.html`, y detente cuando te quedes atascada.
4. Guarda las dos grabaciones junto con tu reporte de auditoría.

## Por qué esto importa

Un video corto de alguien que se queda atascado suele ser lo que convence a un equipo de corregir un problema. Mostrar tiene más fuerza que una tabla de números de reglas.

## Se completa cuando

- [ ] Tienes dos grabaciones: la página reparada funcionando y la original fallando.
- [ ] En la grabación de la página reparada no se usa el mouse en absoluto.
