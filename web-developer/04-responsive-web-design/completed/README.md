# Completed — Responsive Web Design

The reference solution: the Riverside site, responsive from 320 pixels to
wide desktop screens. Open it **after** you have made your own site responsive.

## Comparing against your own work

Your layout and breakpoints can differ. Check only:

- Does every page work at 320 pixels wide without sideways scrolling?
- Does the right image size load on a phone?
- Does the reading order still match what people see?

If yes, your version is correct.
