# 挑战 3：探索

**选做。** 约 45 分钟。

在宽屏上把报名表单变成两栏，同时不改变它的阅读顺序。

## 任务

1. 只在宽屏上，把「About you」（关于你）这一组 fieldset 和项目选择并排显示，表单的其余部分放在下方。
2. 在一个 `@media (min-width: 60rem)` 查询中，对 `<form>` 使用 CSS grid。
3. **不要**移动 HTML 中的任何内容。
4. 用 Tab 键走一遍表单：焦点必须仍然按照合理的顺序移动，从上到下、从左到右。

## 为什么这很重要

CSS grid 可以把东西放在屏幕上的任何位置，这使得「以一种顺序显示、却以另一种顺序阅读」变得很容易发生。键盘用户和屏幕阅读器用户遵循的是 HTML 的顺序，所以视觉顺序和阅读顺序必须一致。

## 完成标准

- [ ] 在宽屏上，这两组内容并排显示。
- [ ] HTML 的顺序没有改变。
- [ ] Tab 键在表单中移动的顺序与它看起来的顺序一致。
