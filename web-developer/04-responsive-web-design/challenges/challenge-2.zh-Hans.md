# 挑战 2：创意

**选做。** 约 45 分钟。

一份来自三台真实设备的测试记录。

## 任务

1. 借三台不同的设备：你的手机、朋友的手机、一台平板电脑、图书馆的电脑、抽屉里的一部旧手机。
2. 在每台设备上打开你的网站，检查每一个页面：你能阅读内容、点按所有东西、填写表单、滚动表格吗？
3. 还要试一试设备上最大的文字大小，以及横屏。
4. 在你的网站中添加一个 `test-log.html` 页面：一张表格，列出设备、浏览器、哪些可以用、哪些不行，以及你修复了什么。

## 为什么这很重要

你的学员、客户和用户不会拥有和你一样的设备。许多人的设备更旧、更便宜或者更小。测试记录是专业团队证明网站可以正常使用的方式，而且放在作品集中也很出色。

## 完成标准

- [ ] 你的测试记录涵盖三台设备，并写明了每台设备使用的浏览器。
- [ ] 你至少修复了一个测试记录中发现的问题。
