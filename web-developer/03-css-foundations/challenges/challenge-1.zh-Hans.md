# 挑战 1：基础

**必做。** 约 45 分钟。

只修改自定义属性，做出一套深色主题。

## 任务

1. 把 `styles.css` 复制为 `styles-dark.css`，并让一个页面改为链接到它。
2. 在新文件中，**只**修改 `:root` 中的值：深色背景、浅色文字，以及更浅一些的主色和强调色。
3. 用新的背景检查每一种文字颜色：对比度要达到 4.5:1 或以上。
4. 不要修改 `:root` 下面的任何一条规则。

## 为什么这很重要

如果只修改少数几个值，整个网站就会随之改变，说明你的视觉系统是有效的。如果你发现自己在整个文件里到处修改规则，那你就找到了一些本应做成设计变量（tokens）的值。

## 完成标准

- [ ] 你的网站有一个完整的深色版本。
- [ ] 只有 `:root` 部分发生了变化。
- [ ] 每一种文字颜色都达到 4.5:1，而且焦点仍然清晰可见。
