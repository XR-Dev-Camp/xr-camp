# Reto 1: Fundamento

**Obligatorio.** Aproximadamente 45 minutos.

Un tema oscuro, cambiando solo tus propiedades personalizadas.

## Tarea

1. Copia `styles.css` como `styles-dark.css`, y vincula una página a este archivo en lugar del otro.
2. En el archivo nuevo, cambia **solo** los valores de `:root`: un fondo oscuro, texto claro y versiones más claras de tus colores principal y de acento.
3. Revisa cada color de texto contra el nuevo fondo: 4.5:1 o más.
4. No cambies ni una sola regla debajo de `:root`.

## Por qué esto importa

Si todo tu sitio cambia cuando cambias unos pocos valores, tu sistema visual funciona. Si te encuentras editando reglas por todo el archivo, encontraste valores que debieron ser tokens.

## Se completa cuando

- [ ] Tu sitio tiene una versión oscura completa.
- [ ] Solo cambió la sección `:root`.
- [ ] Cada color de texto pasa 4.5:1, y el foco se sigue viendo con claridad.
