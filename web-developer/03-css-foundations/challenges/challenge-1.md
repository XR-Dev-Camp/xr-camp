# Challenge 1: Foundation

**Required.** Roughly 45 minutes.

A dark theme, by changing only your custom properties.

## Task

1. Copy `styles.css` to `styles-dark.css`, and link a page to it instead.
2. In the new file, change **only** the values in `:root`: a dark background, light text, and lighter versions of your primary and accent colours.
3. Check every text colour against the new background: 4.5:1 or more.
4. Do not change a single rule below `:root`.

## Why this matters

If your whole site changes when you change a handful of values, your visual system works. If you find yourself editing rules all over the file, you have found values that should have been tokens.

## Done when

- [ ] Your site has a complete dark version.
- [ ] Only the `:root` section changed.
- [ ] Every text colour passes 4.5:1, and focus is still clearly visible.
