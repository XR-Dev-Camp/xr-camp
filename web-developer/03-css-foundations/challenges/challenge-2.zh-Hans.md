# 挑战 2：创意

**选做。** 约 45 分钟。

一套来自你自己的文化或家乡的调色板。

## 任务

1. 从对你有意义的事物中选取颜色：一块织物、一个市场、一个节日、一片风景、一面旗帜、一幅传统绘画。
2. 从中提取五种颜色组成调色板，并把它们放进你的设计变量中。
3. 检查每一对文字颜色和背景颜色。如果某种颜色不达标，就把它留作装饰（边框、大块形状的背景），并为文字选择一个更深或更浅的色调。
4. 在 `:root` 中添加一段简短的注释，说明这套调色板来自哪里。

## 为什么这很重要

一个看起来属于它所在社区的网站，比一个看起来和其他地方都一样的网站更让人感到亲切。检查对比度能让你知道如何既保持鲜明的特色，又保证文字易于阅读。

## 完成标准

- [ ] 你的调色板来自一个具体的地方，并且注释中写明了来源。
- [ ] 每一对文字颜色都达到 4.5:1。
