# Completed — CSS Foundations

The reference solution: the Riverside site with a complete visual system in
`styles.css`. Open it **after** you have written your own.

## Comparing against your own work

Your colours and sizes will be different. Check only:

- Are your colours, sizes, and spacing defined once, as tokens?
- Does every text colour pass contrast, and is focus always visible?
- Could someone else find a rule in your stylesheet in under a minute?

If yes, your version is correct.
