# 挑战 2：创意

**选做。** 约 45 分钟。

个人视觉风格，使用来自你的文化的调色板。

## 任务

1. 为你的颜色选择一个对你有意义的来源：一种纺织品、一门传统手艺、一个节日、一片风景、你所在城市的一座建筑，或者你家常做的一道菜。
2. 从中挑出四五种颜色：一种用于文字的深色，一种用于链接和按钮的醒目颜色，一种强调色，一种用于背景色带的浅色，以及一种背景色。
3. 把它们放进你的设计变量（design tokens）中。在 [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)（WebAIM 对比度检查器，英文）中检查每一组文字颜色搭配：文字至少 4.5:1，焦点轮廓和边框至少 3:1。如果你喜欢的某个颜色没有通过，就用它的深色版本来写文字，而把原来的颜色留给没有文字的大面积区域。
4. 把对比度写在设计变量上方的注释中。
5. 在你的「About me」（关于我）或「How I built this site」（我是怎样构建这个网站的）板块中，用一两句话说明你的颜色来自哪里。
6. 在你的 3D 展厅中使用同样的颜色：展板的 `data-colour` 值，以及脚本中的边框颜色。

## 为什么这很重要

一个看起来和别人都一样的作品集，很容易被忘记。有故事的颜色让它成为你的作品；而检查这些颜色，则说明你能同时做到有创意和无障碍：这正是设计团队需要的。

## 完成标准

- [ ] 每一种颜色都是一个设计变量，每一组文字颜色搭配都至少为 4.5:1。
- [ ] 设计变量上方的注释列出了对比度。
- [ ] 你的网站用一两句话说明了颜色来自哪里。
- [ ] 3D 展厅使用同一套调色板。
