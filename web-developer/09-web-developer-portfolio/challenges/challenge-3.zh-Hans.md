# 挑战 3：探索

**选做。** 约 45 分钟。

一个不带图片的轻量模式，或者一份打印样式表。二选一。

## 选项 A：轻量模式

为那些使用慢速或昂贵的移动数据的人而做。

1. 复制一份你的首页，命名为 `light.html`。删除其中所有的 `<img>`，以及 `<script>` 标签。
2. 其他所有内容都保留：文字、链接、标题和样式表。
3. 在 `index.html` 的顶部添加一个链接：「Using slow or expensive data? Read the lightweight version.」（网络慢或者流量贵？阅读轻量版。）再从 `light.html` 添加一个返回完整版的链接。
4. 在网络面板中，比较两个页面各下载了多少数据，把两个数字都写进你的学习日志。

## 选项 B：打印样式表

为那些把你的作品集打印出来，或者把它保存为 PDF 发给别人的人而做。

1. 在 `styles.css` 的末尾，添加一个 `@media print { }` 代码块。
2. 在其中：隐藏导航、跳转链接、筛选器和「See my projects」（查看我的项目）按钮；把文字设为黑色、背景设为白色；并用 `break-inside: avoid;` 防止卡片被拆分到两页上。
3. 链接在纸上不能点击，所以要在每个链接后面显示它的网址：

   ```css
   .links a::after {
     content: " (" attr(href) ")";
   }
   ```

4. 用浏览器的打印预览检查效果。

## 为什么这很重要

不是每个人都用和你一样的方式阅读你的作品集。有些人要为每一 MB 付费；有些人会把东西打印出来仔细阅读。按照人们真实的阅读方式来设计，和无障碍是同一种技能。

## 完成标准

- [ ] **选项 A：** `light.html` 包含所有文字和链接，没有图片；两个版本互相链接；你记录了两个页面的大小。
- [ ] **选项 B：** 打印预览中没有导航或按钮，是白底黑字，没有被拆分到两页的卡片，并且显示了每个项目链接的网址。
