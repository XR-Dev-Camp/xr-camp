# 挑战 1：基础

**必做。** 约 45 分钟。

第二篇案例研究。

## 任务

1. 选择第二个项目，和你第一篇案例研究的项目不同：例如课程 1.5 中的无障碍审查，或者课程 1.6 中的项目浏览器。
2. 把 `case-study.html` 复制成一个新文件，起一个清楚的小写名字，例如 `case-study-explorer.html`。修改它的 `<title>`、描述和 `h1`。
3. 为这个项目重新写每一个部分：关键信息、问题、为谁而做、你的过程、至少三个决策、无障碍，以及你学到了什么。
4. 从首页上这个项目的卡片链接到它，链接文字要说出项目名称：「Read the programme explorer case study」（阅读项目浏览器案例研究）。
5. 现在有了两篇案例研究，决定导航应该怎样安排。一个简单的做法是：把「Case study」（案例研究）链接改成「Case studies」（案例研究合集），指向你的项目板块。

## 为什么这很重要

一篇案例研究可能看起来像是运气。两篇就能说明你有一套自己的工作方法：你会规划，你做决定是有理由的，你会测试，你会学习。写第二篇也会快得多，因为你已经知道它的结构了。

## 完成标准

- [ ] 第二篇案例研究包含每一个部分，并且至少有三个说明了「原因」的决策。
- [ ] 首页上它的卡片用清楚的链接文字链接到它。
- [ ] 每个页面上的导航都一样，而且仍然说得通。
