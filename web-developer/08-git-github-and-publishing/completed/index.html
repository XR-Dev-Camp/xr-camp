Ana's web projects

Everything I built in Phase 1 of XR Camp, from my first 3D world to an accessible, responsive website for a community centre.

Phase 1 projects

  • My first 3D world

    Course 0.1

    A small garden under a pink evening sky, with three shapes and a moon that rises and sinks. You can walk around it with the keyboard.

    Built with HTML and A-Frame. Includes a written description of the scene and a button to pause the animation.

    Visit my first 3D world

  • Riverside Community Centre website

    Courses 1.1, 1.3, and 1.4

    A website for a community centre: opening hours, programmes, and how to find it. Built in plain HTML first, then styled, then made to work on every screen size.

    Built with HTML and CSS: semantic landmarks, a data table, grid, and responsive images.

    Visit the Riverside website

  • Join a programme form

    Course 1.2

    A sign-up form where every field has a clear label, with a plain-language note on how the information is used.

    Built with HTML forms and CSS.

    Try the join form

  • Accessibility audit

    Course 1.5

    I tested an events page with a keyboard, a screen reader, and automated tools, wrote down every problem I found, and fixed them.

    Written with HTML, and checked against WCAG 2.2.

    Read my accessibility audit

  • Programme explorer

    Course 1.6

    Search and filter the centre's programmes as you type, and save the ones you like. The number of results is announced to screen readers.

    Built with HTML, CSS, and JavaScript.

    Use the programme explorer

About this collection

I built these projects while learning at XR Camp, a free school for web, 3D, and XR development. Every project works with a keyboard, and the 3D world has a text description for people who cannot see it.

The code for every project is public on GitHub, with a README that explains how each one was built.
