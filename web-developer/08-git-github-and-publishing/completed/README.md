# Completed — Git, GitHub, and Publishing

A model of a finished repository. Open it **after** you have written your own
collection page and README.

- `index.html`: Ana's project collection page. Its links point into the XR
  Camp repository, so the page works from this folder; a comment in it shows
  the shorter links you use in your own repository.
- `README-example.md`: a model README. In a real repository it is called
  `README.md`.
- `LICENSE-example`: the MIT Licence, filled in. In a real repository it is
  called `LICENSE`.
- `gitignore-example`: a small `.gitignore`. In a real repository it is called
  `.gitignore`.

The files end in `-example` so that they are not mistaken for this lesson's
own README and licence.

## Comparing against your own work

Your repository can look different. Check only:

- Does your published address open your collection page, and does every link
  on it work online?
- Does your README say what the project is, how to view it, how it was built,
  who and what you credit, and which licence applies?
- Is there nothing private in the repository: no passwords, no home address,
  no one else's personal information?

If yes, your version is correct.
