# 挑战 2：创意

**选做。** 约 45 分钟。

用你自己的语言写一份 README。

## 任务

1. 复制一份你的 `README.md`，并像 XR Camp 那样按语言命名：西班牙语是 `README.es.md`，葡萄牙语是 `README.pt.md`，简体中文是 `README.zh-Hans.md`。
2. 翻译**整份** README，而不是写一份摘要：描述、步骤、无障碍说明、署名。代码、文件名和网址要保持原样。
3. 在**两个**文件的顶部，都加上一行把它们互相链接起来的语言行，就像每一节 XR Camp 课程顶部的那一行：

   ```markdown
   **Language / Idioma:** [English](README.md) · [Español](README.es.md)
   ```

   用每种语言本身来写它的名字，这样看不懂英文的人也能找到自己的语言。
4. 提交这两个文件，消息写 `Add a Spanish README`（或者你的语言）。

## 为什么这很重要

GitHub 会在你的首页上显示 `README.md`，但你想接触的许多人，你的家人、你的社区、你自己国家的雇主，首先读的是另一种语言。同时提供两种语言，并清楚地把它们链接起来，正是 XR Camp 自己用三种语言接触学员的方式。

## 完成标准

- [ ] 仓库中有第二份完整翻译的 README。
- [ ] 每份 README 都在开头几行链接到另一份。
- [ ] 翻译后的 README 中的每一个链接仍然能用。
