# Challenge 2: Creative

**Optional.** Roughly 45 minutes.

A README in your own language.

## Task

1. Make a copy of your `README.md` and name it for your language, the way XR Camp does: `README.es.md` for Spanish, `README.pt.md` for Portuguese, `README.zh-Hans.md` for Simplified Chinese.
2. Translate the **whole** README, not a summary: the description, the steps, the accessibility notes, the credits. Keep code, file names, and addresses exactly as they are.
3. At the top of **both** files, add a language line that links them, like the one at the top of every XR Camp lesson:

   ```markdown
   **Language / Idioma:** [English](README.md) · [Español](README.es.md)
   ```

   Write each language's name in that language, so people who cannot read English can still find theirs.
4. Commit both files, with the message `Add a Spanish README` (or your language).

## Why this matters

GitHub shows `README.md` on your front page, but many of the people you want to reach, your family, your community, and employers in your own country, read another language first. Offering both, and linking them clearly, is how XR Camp itself reaches learners in three languages.

## Done when

- [ ] A second README, fully translated, is in your repository.
- [ ] Each README links to the other from its first lines.
- [ ] Every link in the translated README still works.
