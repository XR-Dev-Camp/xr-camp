# Reto 2: Creativo

**Opcional.** Aproximadamente 45 minutos.

Un README en tu propio idioma.

## Tarea

1. Haz una copia de tu `README.md` y ponle el nombre de tu idioma, como lo hace XR Camp: `README.es.md` para español, `README.pt.md` para portugués, `README.zh-Hans.md` para chino simplificado.
2. Traduce **todo** el README, no un resumen: la descripción, los pasos, las notas de accesibilidad, los créditos. Deja el código, los nombres de archivo y las direcciones exactamente como están.
3. Al principio de **los dos** archivos, agrega una línea de idiomas que los enlace, como la que está al principio de cada lección de XR Camp:

   ```markdown
   **Language / Idioma:** [English](README.md) · [Español](README.es.md)
   ```

   Escribe el nombre de cada idioma en ese mismo idioma, para que las personas que no leen inglés puedan encontrar el suyo.
4. Haz el *commit* de los dos archivos, con el mensaje `Add a Spanish README` (o el nombre de tu idioma).

## Por qué esto importa

GitHub muestra `README.md` en tu página principal, pero muchas de las personas a quienes quieres llegar, tu familia, tu comunidad y quienes contratan en tu propio país, leen primero en otro idioma. Ofrecer los dos, y enlazarlos con claridad, es la forma en que el propio XR Camp llega a quienes aprenden en tres idiomas.

## Se completa cuando

- [ ] Hay un segundo README, traducido por completo, en tu repositorio.
- [ ] Cada README enlaza al otro desde sus primeras líneas.
- [ ] Cada enlace del README traducido sigue funcionando.
