# 挑战 1：基础

**必做。** 约 45 分钟。

为你的仓库添加许可协议和署名。

## 任务

1. **为你的代码选择一份许可协议。** 如果拿不准，就用 MIT 许可协议，就像 [`completed/LICENSE-example`](../completed/LICENSE-example) 中那样。
2. **在浏览器中添加它：** 在仓库首页选择 **Add file → Create new file**（添加文件 → 创建新文件），把文件命名为 `LICENSE`。选择 **Choose a license template**（选择许可协议模板），挑选许可协议，检查年份和你的名字是否正确，然后提交，消息写 `Add MIT licence for the code`。
3. **为所有不是你做的东西署名。** 创建 `ATTRIBUTION.md`（或者填写 README 中的 **Credits**（致谢）部分），写一个像这样的表格：

   ```markdown
   | What | Made by | Where from | Licence |
   | --- | --- | --- | --- |
   | A-Frame 1.8.0 | The A-Frame authors | https://aframe.io/ | MIT |
   | Lessons and starter files | XR Camp | XR Camp projects repository | See its LICENSE-CODE and LICENSE-CONTENT |
   ```

   表格的四列分别是：什么、制作者、来源、许可协议。你用到的每一张照片、每一个图标、每一种字体或每一个库，都要加一行。如果照片是你自己拍的，也要写明。
4. **说明什么许可协议适用于你的文字和图片。** 在 README 的 **Licence**（许可协议）部分，写明代码使用哪一份许可协议，其他内容又适用什么：例如「Words and pictures: © 2026 your name, all rights reserved」（文字和图片：© 2026 你的名字，保留所有权利）。
5. 在 `index.html` 中**完成 TODO 10**：把同样的信息写成简短的一行，放在页脚。提交。

## 为什么这很重要

许可协议把「请不要复制」变成「你可以这样做」，而署名能让那些作品被你用到的人得到认可。阅读你仓库的雇主会注意到这两样东西：它们说明你明白，代码是按照规则来分享的。

## 完成标准

- [ ] 仓库首页上有一个 `LICENSE` 文件，写有年份和你的名字。
- [ ] 每一个不是你做的库、图片和字体都有署名，并注明了它的许可协议。
- [ ] 你的 README 和合集页面的页脚都说明了代码使用哪一份许可协议，以及文字和图片适用什么。
