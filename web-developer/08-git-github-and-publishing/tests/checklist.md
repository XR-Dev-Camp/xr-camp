# Project check

Work through this list before you submit.

## Repository
- [ ] The repository is public, and its files are at the top level: `index.html` and `README.md` are on the front page, not inside another folder.
- [ ] Your commit messages say what each commit changed.
- [ ] There is a `LICENSE` file, and credits for everything you did not make (Challenge 1).
- [ ] Nothing private is in any file or any commit: no passwords or keys, no home address or phone number, no one else's personal information.

## README
- [ ] It says what the project is, and who made it.
- [ ] It gives the address of your published site.
- [ ] It explains how to view the projects, how they were built, and which licence applies.
- [ ] Its headings are in order, its links say where they go, and any picture has alt text.

## Published site
- [ ] Your GitHub Pages address opens your collection page.
- [ ] Every link on the collection page works **online**, not only on your computer.
- [ ] Styles and images load on every page.
- [ ] Your 3D world opens on your phone.

## Collection page
- [ ] The page's language is set, and its title says whose projects these are.
- [ ] There is one `<h1>`, and each project has an `<h3>` inside the list.
- [ ] Every link makes sense on its own: no "click here" or "view".
- [ ] Tab through the page: the skip link comes first, and focus is always visible.
- [ ] The page works at 320 pixels wide, with no sideways scrolling.

## 3D moment
- [ ] The published world's scene description is on the page, and matches the world.
- [ ] The **Pause animation** button stops and restarts the animation.
- [ ] With reduced motion turned on, the animation does not start.
