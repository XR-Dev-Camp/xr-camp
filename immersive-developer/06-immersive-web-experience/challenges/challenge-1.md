# Challenge 1: Foundation

**Required.** Roughly 45 minutes.

Finish the eight numbered TODOs so the capstone's four combined subsystems — Enter VR, input with a 2D equal, the accessibility and ethics fixes, and spatial audio with captions — all work together.

## Task

1. Work through `starter/index.html`'s four TODOs (1, 3, 5, 7) in order, adding the markup each one describes.
2. Work through `starter/js/main.js`'s four TODOs (2, 4, 6, 8) in order, wiring each piece of markup to the already-finished function it calls.
3. Test each TODO as you finish it, rather than waiting until all eight are done: a mistake is easier to find right after you make it.
4. Run through `starter/rubric.md`'s eight rows against your own build.

## Why this matters

A capstone that combines four lessons' worth of already-working code is closer to a real project than one built from nothing: most real work is connecting parts that already exist, correctly, not writing every part yourself.

## Done when

- [ ] All eight TODOs are complete.
- [ ] Every row in `starter/rubric.md` is met.
- [ ] `node scripts/validate-projects.mjs` passes from the repository root.
