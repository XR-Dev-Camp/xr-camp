# 挑战 2：创意

**选做。** 约 45-60 分钟。

让这个展览成为你自己的：用来自你自己文化、社区或语言的东西，替换一个展台、它的声音和它的字幕。

## 任务

1. 挑选一件展品（陶罐、篮环，或玉石），把它替换成对你有意义的一件物品——一件手工艺品、一件乐器、一种食物，或一栋建筑。
2. 在 `js/exhibit.js` 中，把那一条目的 `name`、`material` 和 `caption` 改成用你自己的话，诚实地描述你的物品。
3. 如果内置的形状（圆柱体、圆环体、二十面体）不适合它，在 `js/app.js` 中修改它的 `geometry` 和 `color`；一个简单的方块或球体也可以。
4. 为它生成一段新的简短声音（如果你有 4.5 的 Python 脚本就复用它，或者写一段简短的无声占位音效，并在 `ATTRIBUTION.md` 中说明），或者复用现有三段声音中的一段，并说明是哪一段。
5. 相应地更新逐字稿和 `ATTRIBUTION.md`。

## 为什么这很重要

一个只展示陶罐、篮子和玉石的展览，默认只教了一种文化的物品。选择哪些内容属于一个共享空间，是一项真实的设计决策，而不是表面装饰。

## 完成标准

- [ ] 现在有一件展品描述的是来自你自己文化、社区或语言的东西。
- [ ] 字幕、逐字稿和 `ATTRIBUTION.md` 对它的描述都保持一致。
- [ ] 结业项目的其余部分（Enter VR、抓取、个性化、边界）依然未经改动地正常工作。
