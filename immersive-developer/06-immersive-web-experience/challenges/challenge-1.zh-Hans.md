# 挑战 1：基础

**必做。** 约 45 分钟。

完成八个编号的 TODO，让这个结业项目被整合的四个子系统——Enter VR、带有 2D 对等方式的输入、无障碍与伦理修复，以及带字幕的空间音频——协同工作。

## 任务

1. 依次完成 `starter/index.html` 中的四个 TODO（1、3、5、7），添加每一个所描述的标记。
2. 依次完成 `starter/js/main.js` 中的四个 TODO（2、4、6、8），把每一段标记接通到它所调用的、已经完成的函数上。
3. 每完成一个 TODO 就测试一次，而不是等全部八个都做完才测试：一个错误在你刚犯下它的时候更容易被发现。
4. 对照你自己的成果，走一遍 `starter/rubric.md` 的八行内容。

## 为什么这很重要

一个整合四节课已经能用的代码的结业项目，比一个从零开始搭建的项目更接近真实的项目：大多数真实的工作，是正确地把已经存在的部分连接起来，而不是每一部分都自己重新写一遍。

## 完成标准

- [ ] 全部八个 TODO 都已完成。
- [ ] `starter/rubric.md` 中的每一行都得到满足。
- [ ] 从仓库根目录运行 `node scripts/validate-projects.mjs` 能通过。
