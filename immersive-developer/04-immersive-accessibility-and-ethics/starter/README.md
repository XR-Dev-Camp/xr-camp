# Starter - Immersive Accessibility and Ethics

Begin here. This scene runs without errors, but it is deliberately broken for
learners with disabilities and takes liberties with their comfort and
privacy, on purpose. See the banner at the top of `index.html`.

- Every file here already works: there is nothing missing to implement, only
  problems to find and fix. Find them by searching for `TODO` across `js/`
  (10 in total, numbered in the order the walkthrough covers them).
- `js/xr.js` has no TODOs: entering VR is unchanged from 4.1/4.2 and is not
  part of this audit.
- No console errors are expected. If you see one, it is a mistake to report,
  not part of the lesson.

Open everything through a local server (`http://`).

Full instructions: [`../README.md`](../README.md).
