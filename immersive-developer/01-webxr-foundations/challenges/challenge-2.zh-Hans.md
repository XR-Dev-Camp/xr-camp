# 挑战 2：创意

**选做。** 约 45-60 分钟。

让「Enter VR」体验说你自己的语言，或体现你自己的社区。

## 任务

1. 用你自己的语言，或者你自己的社区觉得最清楚的平实表达方式，重新撰写 Enter VR 面板的可见文字（图例、提示语、按钮的两种状态文字，以及 `xr.js` 中每一条 `#xr-status` 消息）。
2. 如果你的语言是从右到左书写的，或者句子的节奏不同，检查一下 `#xr-status` 在文字变化时是否依然读起来像一句自然的话。
3. 你也可以选择性地替换玉石、陶罐或篮环中的某一件（用基本几何体搭建，就像 3.4 创意挑战那样），让你在 VR 中走进的这个展览体现出你自己的文化。
4. 保持每个元素的 `id` 不变，这样 JavaScript 才能继续找到它们。

## 为什么这很重要

XR Camp 面向拉丁美洲和中国的女性初学者，而 VR 头显是一种新事物，有时会让人望而生畏。如果一个「Enter VR」按钮，以及它变成「Exit VR」时所传达的意思，读起来像是学习者自己社区里的人会说的话，她就更有可能信任它、理解它。

## 完成标准

- [ ] Enter VR 面板中的每一段可见文字，都已经用你自己的语言或表达方式重新撰写。
- [ ] 页面依然能通过 `tests/checklist.md`。
- [ ] 没有任何一个被 JavaScript 通过 `id` 查找的元素被重命名。
