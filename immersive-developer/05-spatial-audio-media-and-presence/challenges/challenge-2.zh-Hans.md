# 挑战 2：创意

**选做。** 约 45-60 分钟。

让这段语音导览变成你自己的：用你的语言，或一段对你有意义的声音。

## 任务

1. 撰写第二份字幕文件 `assets/captions-mine.vtt`，提示时间点和 `assets/captions.vtt` 一致，但使用你自己的语言，或一门你正在学习的语言。在 `index.html` 的 `<audio>` 元素中添加第二个 `<track>` 元素（使用不同的 `srclang` 和 `label`，`default` 只保留在原始那个上），这样学习者就能从浏览器自己的字幕菜单中任选一个。
2. 在 Python 生成脚本中，改变某一个展台音调的音高、节奏或音色（调整 `freq`、`harmonics` 或 `dur` 的值），让它让你想起来自你自己文化或社区的某种声音：一口钟、一件乐器、一种节奏。重新生成那一个 `.wav` 文件，听一听区别。
3. 如果这个展台现在对你来说描述的是不同的东西，更新 `js/exhibit.js` 中它的描述，以及对应的字幕文字。

## 为什么这很重要

空间音频和字幕是讲故事的工具。three.js 的 API 并不在乎讲的是谁的故事：同样的 `PositionalAudio`、同样的 WebVTT 文件格式、同样的字幕段落，对来自任何语言或文化的故事都同样适用。这个挑战就是要注意到这一点，并加以利用。

## 完成标准

- [ ] 存在一份用你自己语言撰写的第二字幕轨道，提示时间点与原文匹配。
- [ ] 至少有一个展台的声音已经用不同的参数重新生成，并且你能说出你改了什么。
- [ ] 在你做出改动之后，逐字稿和场景描述依然读起来是正确的。
