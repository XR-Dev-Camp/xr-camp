# 挑战 2：创意

**选做。** 约 45-60 分钟。

个性化改造本项目，使其体现你自己的兴趣、社区或语言。

## 任务

1. 把信息台的标题和目标面板的标题（在 `js/main.js` 中，传给 `app.setKioskText` 和 `redrawGoalsPanel` 的字符串）换成你自己的表达，或者添加一个完全属于你自己的第二个面板：一份个人阅读清单、一份本地聚会列表，或是一个对你来说重要的事情的倒计时。
2. 如果你添加了一个真正全新的面板，请完全按照信息台和目标面板的搭建方式，用 `js/panels.js` 中的 `createPanel` 和 `drawPanelText` 来搭建它，并用 `setLockMode` 给它指定自己的锁定模式。
3. 如果你的文字使用了重音符号或非拉丁字符（á、ñ、中文等），测试一下它们在画布上是否能正确绘制。和 A-Frame 内置字体不同，HTML5 Canvas 的 `fillText()` 调用使用的是浏览器自身的字体栈，所以你系统能够显示的大多数文字应该都能正常工作——但请亲自测试，而不是想当然。
4. 更新 `js/describe.js` 中的场景描述，让它依然准确地描述你添加的内容。

## 为什么这很重要

空间 UX 设计上的选择——距离、锁定方式、可读性——适用于任何内容，而不只是一个进度仪表盘。搭建一个对你来说真正有意义的东西，能更好地检验你是否真正理解了*为什么*要做出每一个选择，而不只是学会了照搬。

## 完成标准

- [ ] 房间里显示的内容真正属于你，而不只是原始的文字。
- [ ] 任何新面板在每个路点都清晰可读，并且有一个可用的锁定模式。
- [ ] 场景描述依然与房间里实际的内容一致。
