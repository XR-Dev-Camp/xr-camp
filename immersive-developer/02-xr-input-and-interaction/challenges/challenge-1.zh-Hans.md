# 挑战 1：基础

**必做。** 约 45 分钟。

给世界内菜单添加第四个按钮，接线方式和另外三个一样。

## 任务

1. 在 `menu.js` 中，为 `buildMenu()` 添加第四个按钮：把它标记为「Turn left」（或你自己的表达），赋予它 `userData.action = 'turnLeft'`，并调整位置，让四个按钮依然能舒适地排成一行（调整 `x` 坐标，必要时加宽整个组）。
2. 在 `main.js` 中，为 `onMenuAction(action)` 扩展一个 `'turnLeft'` 的分支，调用 `app.controls.rotateLeft(Math.PI / 8)`——和页面自身的「Turn left」按钮已经在调用的方法相同。
3. 测试它：在 VR（或 Immersive Web Emulator）中，指向这个新按钮并选择它。视角应该像桌面端的「Turn left」一样精确旋转。

## 为什么这很重要

菜单的每一个按钮都遵循同样的三部分模式：一个带有操作名称的、标注了标签的网格；`controllers.js` 中的一次射线检测命中；以及 `onMenuAction` 中的一个分支。自己动手添加第四个按钮，能确认你已经充分理解这个模式，能够扩展它，而不只是读懂它。

## 完成标准

- [ ] 世界内菜单中出现了第四个按钮，标签清晰，且不与其他按钮重叠。
- [ ] 选择它（在 VR 中，或在模拟器中）会像页面的「Turn left」按钮一样旋转视角。
- [ ] 无论在 VR 还是桌面视图中，控制台都没有出现任何报错。
