# 挑战 2：创意

**选做。** 约 45-60 分钟。

让这个交互实验室说你自己的话，并选择你自己想要抓取和放置的物品。

## 任务

1. 用你自己的语言、方言，或者你的社区的表达方式，重新撰写菜单的三个按钮标签（在 `menu.js` 中），以及 `controllers.js`、`ar.js` 和 `main.js` 播报的状态信息。`drawButtonTexture()` 已经用 `<canvas>` 绘制标签，所以你写的任何文字或带重音符号的字符都会完全按原样显示——这和 A-Frame 的默认文字不同，它会丢失重音符号和所有中文。
2. 更换哪一件展品可以被抓取和放置：用陶罐或篮环代替玉石（或者按照 `exhibit.js` 的 ITEMS 模式，换成你自己的物品）。更新 `getGrabTarget`、`createPlacement` 的替代网格，以及每一条目前提到「玉石」的信息。
3. 你也可以选择性地把被放置物体的颜色或形状，改成对你或你的社区有意义的样子。

## 为什么这很重要

一个只会说一种语言、只让你握住一件特定物品的交互实验室，无声地告诉所有其他人：这不是为他们而设计的。这些改动虽小，却是「你只是照着做完了一节课」和「这是一个真正属于你的项目」之间的区别。

## 完成标准

- [ ] 菜单，以及本课新增的每一条状态信息，都用你自己的话表达出来。
- [ ] 一件不同的展品可以被（直接）抓取和（用 AR 或「Place object (2D)」）放置，并且每一条提到它的信息都保持一致。
- [ ] 一切依然正常工作：控制台没有报错，每一种 2D/键盘替代方式也依然能用。
