# 挑战 1：基础

**必做。** 约 45 分钟。

给展览添加第四个物体，放在它自己的展台上。

## 任务

1. 在 `exhibit.js` 中，给 `ITEMS` 添加第四条记录：一个 `id`、一个 `name`、它的材质 `made`、一段博物馆展签式的 `note`，以及一个 `x` 位置（试试 `2.6`，让它立在玉石之后）。
2. 只用基本几何体（`BoxGeometry`、`CylinderGeometry`、`SphereGeometry`、`ConeGeometry`、`TorusGeometry`）为它编写一个 `build...()` 函数，并把它添加到 `BUILDERS` 中。
3. 像另外三个物体一样选择它的材质：这个真实物体有多粗糙或多光滑？它是金属（`metalness` 接近 1）还是非金属（`metalness` 接近 0）？
4. 检查 `describe.js` 中的 `describeExhibit()`：它应该已经能描述你的新物体了，因为它读取的是 `data.made` 和 `data.note`，而不是一份手写的列表。如果没有，说明有什么地方仍然按名字读取原来那三个物体，而不是遍历 `items`。
5. 点击**重建场景**。你的第四个物体应该重新出现，Stats 面板中的 Geometries 和 Textures 计数应该回到和之前一样的数字。

## 为什么这很重要

添加一个物体会触及本课搭建的一切：数据驱动的 `ITEMS` 数组、一个基本几何体和材质的选择、从同一份数据读取的描述，以及资源释放。如果你的第四个物体能出现、能正确描述自己，并且在重建之后不会造成内存泄漏，就说明你理解了这四个文件是如何组合在一起的。

## 完成标准

- [ ] 第四个物体立在它自己的展台上，用基本几何体搭建。
- [ ] 它的材质符合它的材质构成。
- [ ] 场景描述中提到了它，且没有为它专门写一段特殊代码。
- [ ] 重建场景功能正常，Stats 面板的内存计数不会上升。
