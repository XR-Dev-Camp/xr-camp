# Challenge 2: Creative

**Optional.** Roughly 60 minutes.

Make the exhibit yours: swap in objects from your own culture or community.

## Task

1. Replace one, two, or all three entries in `ITEMS` with objects that matter where you are from, or to your community: a molcajete, a teapot, a drum, a lantern, a piece of embroidery on a hoop, a maté gourd.
2. Build each one from primitives, the same way the clay pot, basket ring, and jade stone were built. Keep using real-world proportions.
3. Write each `note` as you would a museum label, and write it in your own language. If you write it in a language other than English, keep a short English gloss in a comment above it, so the reference solution's structure still helps future readers.
4. Choose materials that answer light the way the real object would: matte clay, polished stone, woven fibre, painted wood, or metal.
5. Everything else — the pedestals, the pause button, the render loop, disposal — should keep working unchanged, because it was written to read from `ITEMS`, not to know about a clay pot by name.

## Why this matters

A data-driven exhibit is only worth building if the data can change without the code changing. This challenge proves it, and gives you a personal version of the exhibit you can carry into 3.5, where it gains real glTF models.

## Done when

- [ ] At least one object is from your own culture or community, built from primitives.
- [ ] Its note is written in your own language (with an English gloss in a comment, if it is not English).
- [ ] The description, the pause button, and Rebuild scene all still work, unmodified.
