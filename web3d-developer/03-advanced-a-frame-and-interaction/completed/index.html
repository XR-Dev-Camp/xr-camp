Everything in this room

This list is not only a fallback: it is the same information as the room, in words, so it is always here (WCAG 1.3.1).

    1. Select an exhibit

    Each button selects one exhibit: the exact same result as clicking, tapping, or pointing a VR controller at it. Tab to a button, then press Enter or Space.

      2. Idle animation

      The selected exhibit pulses gently while it waits. This is the only thing in the room that moves on its own; reduced motion turns it off automatically, and this button does the same thing by hand.

      3. Input mode

      Off: click or tap to select. On: hold your view on an exhibit for 1.2 seconds; looking away cancels. Gaze selection needs no pointer or controller, which helps when neither is available, but the forced wait is hard for anyone who cannot hold their gaze steady or wants more time.

      Try it in VR

      Install the free Immersive Web Emulator browser extension, open its panel, and press "Enter VR" above. Its virtual controllers use laser-controls automatically: point the laser at an exhibit and pull the trigger to select it, the same selectExhibit() path as every other input here.
