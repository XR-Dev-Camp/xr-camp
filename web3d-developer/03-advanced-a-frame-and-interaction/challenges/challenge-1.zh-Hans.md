# 挑战 1：基础

**必做。** 约 45 分钟。

添加第四个交互式展品，使用和另外三个相同的组件和相同的共用代码路径。

## 任务

1. 在 `completed/index.html`（或你自己的起始代码工作副本）中，添加一个新实体：任何你喜欢的基本元素标签都可以（`a-box`、`a-cylinder`、`a-torus` 等等），给它自己的 `id`。
2. 给它加上 `class="interactive"` 和 `interactive-exhibit="exhibitId: <你的id>; action: turn"`（或者 `lift`，如果你更希望它只是高亮，就用 `none`）。
3. 在 `main.js` 的 `exhibitData` 中添加一个对应的对象：`id`、`label`、`description`、`action`，以及 `hasAudio: false`。
4. 重新加载页面。确认你的新展品出现在 2D 列表中，自动获得了自己的「选择」按钮，并且对点击、点按、按钮，以及（如果能测试的话）VR 控制器的扳机，都做出同样的反应。

## 为什么这很重要

之所以存在一个组件和一个共用的 `selectExhibit()` 函数，就是为了让添加第四个展品只需要一次数据改动和一个 HTML 实体，而不需要新代码。如果你发现自己不得不为第四个展品写一个新函数，说明某个地方仍然硬编码成了「三个展品」：找到它，把它变得更通用。

## 完成标准

- [ ] 新展品出现在房间、2D 列表和「选择」按钮中，全部由同一个 `exhibitData` 条目构建而成。
- [ ] 用任意一种输入方式选中它，都会播放它的动作，并更新信息面板和 `#status`，除了 `exhibitData` 条目和 HTML 属性之外，没有编写任何新函数。
