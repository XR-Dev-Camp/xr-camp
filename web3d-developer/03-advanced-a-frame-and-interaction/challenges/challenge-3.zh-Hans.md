# 挑战 3：探索

**进阶选做。** 约 90 分钟。

给 `interactive-exhibit` 组件添加第二种、独立的交互方式：一个专门的「细看」动作，与选择分开。

## 任务

1. 给 `interactive-exhibit` 添加一个新的 schema 属性：类似 `examinable`（布尔值，默认 `false`）。
2. 对于 `examinable: true` 的展品，监听一个不同于 `click` 的第二个事件，例如射线检测器自身的 `raycaster-intersected-cleared`，或者你自己用 `mousedown`/`mouseup` 的计时实现的长按（至少 600 毫秒算作一次长按）。
3. 在这第二种交互发生时，做一些选择动作不会做的事：比如临时把展品的缩放加倍，或者把它的材质换成一个高亮的变体，持续两秒钟，然后恢复。用 `tick()` 或 `setTimeout`（要在 `remove()` 中安全地清除）来计时恢复的时机。
4. 给这个新交互配上自己的键盘路径：为每个支持细看的展品添加第二个按钮（「细看：<标签>」），这样这里的一切都不依赖键盘无法复现的鼠标手势。
5. 在信息面板或 `#scene-description` 中说明这个新交互，让它是可被发现的，而不是一个隐藏功能。

## 为什么这很重要

真实的展品往往需要不止一种交互方式（先选择，再细看）。这个挑战测试你的组件设计能否泛化：添加第二种交互应该是扩展 `interactive-exhibit`，而不是需要一个带着自己一套选择逻辑副本的、并行的第二个组件。

## 完成标准

- [ ] 至少有一个展品同时支持选择和细看这两种独立的、有说明的交互。
- [ ] 细看交互有一条可用的键盘路径。
- [ ] 细看交互启动的任何计时器都会在 `remove()` 中被清除，这样在动画进行到一半时移除展品，不会留下任何仍在运行的东西。
