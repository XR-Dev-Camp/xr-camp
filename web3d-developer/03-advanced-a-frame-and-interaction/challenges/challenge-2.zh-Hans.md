# 挑战 2：创意

**选做。** 约 45–60 分钟。

个性化改造本项目，使其体现你的兴趣、社区或语言。

## 任务

1. 用一件来自你自己文化、社区，或者对你有意义的地方的东西——一个物件、一种传统、一个故事——替换某个展品的 `label` 和 `description`。用平实的语言写一两句话就够了。
2. 如果你用西班牙文或中文书写，请对照第 3.2 课 README 中「多语言文字」那一节的说明检查：不带重音的普通西班牙文（没有重音符号或「ñ」）可以安全地用在 `<a-text>` 中，但带重音的西班牙文和任何中文文字都需要改用 canvas 绘制的贴图，就像第 3.2 课处理中文欢迎面板时用的技巧一样。
3. 给你重新命名的展品设定自己的 `action`（转动、抬起，或者不动），并决定它是否应该有钟声，如果有，说明理由：这个声音是否和这个展品所代表的东西相称？
4. 更新信息面板的文字，用你自己的话，让屏幕阅读器用户听到的内容与视力正常的用户看到的内容保持一致。

## 为什么这很重要

目前的展品都比较通用（一个展台、一盏灯笼、一个铃铛）。一个对你有意义的展品，对学习者、以及以后访问你这个版本房间的任何人来说，都更有价值。多语言安全的文字不是第 3.2 课中一次性的修复：它是每次添加标签时都要检查的习惯。

## 完成标准

- [ ] 至少有一个展品的标签和描述是你自己写的，并且在 3D 场景、信息面板和 2D 列表之间保持符合 WCAG 1.3.1 的一致性。
- [ ] 你添加的任何带重音符号或非拉丁文字都使用了 canvas 贴图，而不是 `<a-text>`。
- [ ] 这个展品在每一种输入方式下依然可用：点击、「选择」按钮，以及（如果你测试的话）注视选择或 VR 控制器。
