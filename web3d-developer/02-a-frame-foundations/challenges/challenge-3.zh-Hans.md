# 挑战 3：探索

**进阶选做。** 约 90 分钟。

添加一段你自己的短视频片段。

## 任务

1. 选择一段对你有意义的短片段（家里的一件物品、一个地方、一段家庭录像），长度为几秒钟，要远低于 [`docs/en/3d-assets-and-versions.md`](../../../docs/en/3d-assets-and-versions.md)（英文）中 10 MB 的视频预算。把它保存为 `.mp4` 格式，放在你自己的 `assets/` 文件夹中。
2. 把它作为一个 `<video>` 添加到 `<a-assets>` 中，设置为静音（场景中的自动播放需要这个条件）并加上 `playsinline`，然后用 `<a-video src="#your-clip" width="..." height="..." position="..."></a-video>` 显示它，尺寸要设置得不与其他面板重叠。
3. 在 `exhibitData` 中添加一条对应的记录，让它像其他一切一样拥有「查看」按钮和 2D 列表条目。
4. 由于 `<a-video>` 本身不支持字幕，请在 2D 后备方案能够显示字幕的地方添加字幕：要么在页面其他位置用一个普通的 HTML `<video>` 元素，配上 `<track kind="captions" src="your-captions.vtt" srclang="en">`，要么在展览列表中为这个点位的描述添加一段简短的文字记录。
5. 决定这段视频是否应该在 3D 场景中自动播放。如果它带有声音，就要完全按照第 7 步中对待音频的方式处理：声音绝不自动播放（WCAG 1.4.2）。一段无声的、循环播放的画面可以自动播放；声音不可以。

## 为什么这很重要

视频是本课刻意没有附带的一种素材类型，因为一个必需的视频文件同时也是一个必须有人制作或找到的必需素材，本课无法替每一位学习者选定这样一段视频。添加你自己的视频，是每一个 A-Frame 项目最终都会面对的那种选择的一个小型、真实的版本：引入一个真正的媒体素材，并且慎重地决定它如何表现、如何保持无障碍。

## 完成标准

- [ ] 你自己的一段短视频通过 `<a-video>` 在 3D 房间中播放。
- [ ] 它拥有「查看」按钮和 2D 列表条目。
- [ ] 它在 2D 中提供了字幕或文字记录。
- [ ] 如果它带有声音，不会自动播放。
