# 挑战 1：基础

**必做。** 约 45 分钟。

添加第四个「查看」点位，用一个基本元素标签搭建。

## 任务

1. 在房间里添加一个新的基本元素标签（圆柱体、圆锥体、球体，或另一个长方体），给它自己的 `id`，放在房间中还不拥挤的位置。
2. 在 `main.js` 的 `exhibitData` 中为它添加一条记录：一个与实体一致的 `id`、一段简短的 `label`，以及一段 `description`。
3. 确认在不做任何其他修改的情况下，它已经出现在 2D 列表中，**并且**拥有了自己的「查看」按钮。如果没有，检查它的 `id` 是否完全一致。
4. 点击（或用 Tab 键切换到它并按回车）它的新按钮，确认相机会转向它。
5. 更新 `#scene-description` 的初始文字，提及它。

## 为什么这很重要

因为列表、按钮和「查看」行为都是从同一个数组构建出来的，添加一个点位应该只需要一个新实体和 `exhibitData` 中的一个新对象，仅此而已。如果你发现自己不得不手动修改列表或按钮，说明本课前面的某个部分仍然是硬编码的，而不是由数据驱动的，值得回头检查一下。

## 完成标准

- [ ] 房间里出现了第四个基本元素标签，拥有自己的 `id`。
- [ ] 它在 `exhibitData` 中有一条记录，并自动出现在列表和按钮中。
- [ ] 它的「查看」按钮会让相机转向它。
- [ ] `#scene-description` 的初始文字提及了它。
