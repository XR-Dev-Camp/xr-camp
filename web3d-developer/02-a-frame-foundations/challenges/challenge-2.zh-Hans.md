# 挑战 2：创意

**选做。** 约 60 分钟。

一个来自你自己文化的贴图图案，以及一块用你自己语言写成的欢迎面板。

## 任务

1. 设计一个简单的、可重复的图案，它对你的家乡而言有特殊意义（一种纺织纹样、一种瓷砖图案、一种边框设计），做成 SVG，方式和 `assets/woven-pattern.svg` 的制作方式一样：简单的形状，一到两种颜色，尺寸要足够小，远低于 1 MB 的贴图预算。
2. 用本课同样的方法把它转换成 PNG（在浏览器中渲染这个 SVG 并截图，或者使用你喜欢的任何工具），然后用它替换地面或展台上的编织图案。
3. 添加一块用对你有意义的语言写成的欢迎面板。首先测试 A-Frame 的默认字体能否显示它：在一个草稿页面中把这个词写进一个普通的 `<a-text>`，仔细观察结果，就像本课测试西班牙文和中文时那样。如果有任何字母缺失或显示错误，就像中文面板那样，改用 canvas 绘制的贴图。
4. 在 `ATTRIBUTION.md` 中记录你这张贴图的来源，方式和 `woven-pattern.png` 的记录方式一样，即使它是你自己制作的。

## 为什么这很重要

这个房间的结构（基本元素标签、贴图、`<a-assets>`、canvas 文字）可以迁移到任何文化的视觉语言和任何文字系统上。对一种新语言用默认字体先测试、而不是想当然地假设，正是本课最希望你养成的习惯。

## 完成标准

- [ ] 一张新的、自己制作的贴图图案替换或加入了编织图案，并在 `ATTRIBUTION.md` 中注明来源。
- [ ] 存在一块用你选择的语言写成的欢迎面板，并且事先用默认字体做过测试。
- [ ] 如果默认字体无法显示它，就已经改用 canvas 贴图绘制，并且正确显示。
