# 挑战 2：创意

**选做。** 约 45-60 分钟。

为大厅换一套皮肤，让它的三种物品类型及其描述文字，体现你自己的文化、社区或语言。

## 任务

1. 在 `js/hall.js` 中，用三个来自你自己文化或社区的物体，替换 `ITEM_TYPES` 中三条记录的 `name` 和 `color`。保持 `id` 的值不变（`clay-pot`、`basket-ring`、`jade-stone`），因为其他代码引用了它们；如果你愿意，也可以在它们出现的每一处都一致地重命名。
2. 更新 `describe.js` 中的说明文字，以及 `main.js` 中构建出的列表行，让场景描述和 2D 列表准确描述你的物体，而不是原来的物体。
3. 如果你用英文以外的语言书写，这里完全欢迎——编号的 TODO 和代码注释可以继续保留英文，但面向学习者的文字（场景描述、2D 列表、页面自己的标题）可以用你的语言书写。
4. 如果你使用了任何你认为属于自己创作的新颜色或形状，请按照本项目现有的格式更新 `ATTRIBUTION.md`。

## 为什么这很重要

自阶段 3 开始以来，这个展览大厅一直沿用同样的三个物体。用对你有意义的东西替换它们，正好可以检验本课有没有什么地方悄悄依赖于「陶罐、编织篮环、玉石」这个具体名字——一个搭建良好的系统不应该在意它的数据代表着什么。

## 完成标准

- [ ] `ITEM_TYPES` 中是你自己的三个物体，配有你自己的颜色。
- [ ] 场景描述和 2D 列表准确地描述了它们。
- [ ] 大厅依然能通过 `tests/checklist.md` 中的每一项检查。
