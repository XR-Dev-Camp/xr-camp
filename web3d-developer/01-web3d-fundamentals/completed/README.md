# Completed — Web3D Fundamentals

The reference solution. Open it after you have tried the starter.

- `index.html`, `lab.js`, `styles.css`: the concepts lab. One three.js
  scene, rendered on demand; controls for coordinates, transforms, the scene
  graph, cameras, lights, and materials; a scene description and a scene
  graph list that follow every change.
- `compare/`: the same exhibit in raw WebGL (one triangle), three.js,
  A-Frame, and X3D with X3DOM.
- `analysis.md`: Ana's written comparison, and her choice for the virtual exhibit.

Open everything through a local server (http://).
