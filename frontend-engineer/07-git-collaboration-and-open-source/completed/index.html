Study tips

One tip from each person who has practised contributing here. Add yours at the end of the list: see CONTRIBUTING.md.

  • Study at the same time every day, even for 20 minutes. (XR Camp)
  • When you are stuck for 15 minutes, write down exactly what you tried, then ask. (XR Camp)
  • Commit small, commit often: you can always go back. (XR Camp)
  • Read the error message out loud. It usually says what is wrong. (Ana)
  • Explain your code to a friend who does not code. If you cannot, you do not understand it yet. (Lucía)
