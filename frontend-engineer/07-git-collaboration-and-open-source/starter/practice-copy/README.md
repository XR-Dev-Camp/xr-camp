# XR Camp contribution practice

**English** · [Español](#español) · [简体中文](#简体中文)

A safe place to practise contributing to open source, for **XR Camp Course 2.7: Git Collaboration and Open Source**.

This is a **template repository**. You do not send changes here. Instead:

1. Press **Use this template → Create a new repository**, and make your own public copy.
2. Invite a study partner: **Settings → Collaborators → Add people**. Ask them to do the same with their copy.
3. Follow the lesson: open issues, make branches, send pull requests to each other, review, resolve a merge conflict, and write release notes.

## What is inside

| File | What it is for |
| --- | --- |
| [`index.html`](index.html) | The **study tips wall**: one small page that everyone adds to. You will make (and fix) a merge conflict here. |
| [`3d/index.html`](3d/index.html) | A small 3D scene with some deliberate problems to find and fix. |
| [`GOOD-FIRST-ISSUES.md`](GOOD-FIRST-ISSUES.md) | Problems waiting for you. Copy one into an issue in your repository. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute: every open-source project has a file like this. Read it first. |
| [`CHANGELOG.md`](CHANGELOG.md) | Release notes. You will add yours. |

To see the pages, open your copy's **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, and save.
