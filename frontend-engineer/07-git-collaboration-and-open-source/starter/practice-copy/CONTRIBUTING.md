# Contributing

Thank you for helping. This guide is short on purpose: read all of it.

## Before you start

- **Open an issue first**, unless the change is tiny (a typo). Say what is wrong or what you want to add. Wait for a "yes" before spending hours on it.
- **One change per pull request.** A fix and a new feature are two pull requests.
- Be kind. Everyone here is learning. Review the code, not the person.

## Making a change

1. Make a branch from `main` with a short name that says what it is: `fix-3d-description`, `add-tip-maria`.
2. Make your change. Test it in a browser, with the keyboard.
3. Commit with a message that says what changed and why, in the present tense: `Add a scene description to the 3D example`.
4. Push the branch, and open a pull request. Fill in the template. Link the issue: `Fixes #3`.
5. Answer review comments. Push more commits to the same branch; the pull request updates by itself.

## Adding a study tip

Add one `<li>` to the list in `index.html`, **at the end**, with your tip and your first name or username. Keep it under 200 characters.

## Code style

- HTML: two spaces to indent; lowercase tags; every image has `alt`.
- Accessibility first: everything must work with a keyboard and a screen reader.
- No new libraries without an issue discussing it first.
