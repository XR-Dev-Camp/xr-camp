# Starter — Git Collaboration and Open Source

This lesson happens mostly on GitHub, in your own copy of the practice
repository: <https://github.com/XR-Dev-Camp/contribution-practice>. Press
**Use this template** there to make your copy.

- `practice-copy/` is the same files as the practice repository, for when
  GitHub is slow or blocked where you are: upload them to a new repository on
  Gitee (or any Git host), or practise with Git alone on your computer.
- `contribution-log.md` is where you record every issue, review, and pull
  request you make.

Full instructions: [`../README.md`](../README.md).
