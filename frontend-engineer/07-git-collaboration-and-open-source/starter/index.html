Start here

This lesson happens on GitHub (or Gitee), in your own copy of the practice repository. Nothing in this folder needs editing.

  1. Open the XR Camp contribution practice template, and press Use this template.
  2. Invite a study partner as a collaborator.
  3. Record your work in contribution-log.md.

If GitHub is slow or blocked

The practice-copy folder has the same files. Upload them to a new repository on Gitee, or practise with Git on your computer.
