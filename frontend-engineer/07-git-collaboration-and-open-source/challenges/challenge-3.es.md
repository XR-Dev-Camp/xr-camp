# Reto 3: Explorador

**Extensión opcional.** Aproximadamente 90 minutos, más la espera por quienes mantienen el proyecto.

Haz una contribución real a un proyecto real de código abierto.

## Tarea

1. Elige un proyecto que hayas usado: el propio XR Camp, A-Frame, three.js, el contenido de MDN, o un proyecto en tu propio idioma. Lee su README, `CONTRIBUTING.md`, código de conducta y licencia.
2. Encuentra un problema pequeño y real: un error de tipeo, un enlace roto, una oración poco clara, un `alt` que falta, una traducción. Muchos proyectos los etiquetan como **good first issue** (buen primer issue). Busca uno en el que nadie esté trabajando todavía.
3. Comenta en el issue que te gustaría trabajar en él (o abre uno, si es nuevo), y espera una respuesta si la guía del proyecto lo pide.
4. Haz un fork, crea una rama, corrige el problema, y abre un pull request que siga exactamente las reglas del proyecto.
5. Responde a la revisión. Ten paciencia: quienes mantienen el proyecto suelen ser voluntarias.
6. Registra todo en tu historial de contribuciones, sea cual sea el resultado. Un pull request cerrado, con una conversación educada, sigue siendo experiencia.

## Por qué esto importa

Una contribución fusionada en un proyecto real, con una conversación de revisión pública, es una de las cosas más sólidas que puedes mostrarle a quien te quiera contratar. Demuestra que puedes leer el código de otra persona, seguir sus reglas y trabajar con gente que nunca conociste.

## Se completa cuando

- [ ] Leíste la guía de contribución del proyecto antes de empezar.
- [ ] Un issue y un pull request, enlazados, en un proyecto real.
- [ ] Respondiste a cada comentario de revisión.
- [ ] Toda la historia está en tu historial de contribuciones.
