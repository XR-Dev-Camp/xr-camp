# Reto 2: Creativo

**Opcional.** Aproximadamente 45–60 minutos.

Lleva el repositorio de práctica a tu idioma.

## Tarea

1. Abre un issue en tu copia: «Translate the 3D example into Spanish» (traducir el ejemplo 3D al español; o al chino, portugués, quechua: tu idioma).
2. En una rama, crea `3d/index.es.html` (o `index.zh-Hans.html`, y así sucesivamente) con `<html lang>` bien configurado, y todas las palabras traducidas: el encabezado, las instrucciones, el botón y la descripción de la escena.
3. Enlaza las dos páginas entre sí, cada enlace en su propio idioma: `<a href="index.es.html" lang="es">Español</a>`.
4. Pídele a una compañera que hable el idioma que revise la traducción, no solo el código.
5. Agrega una línea a `CHANGELOG.md`, bajo **Unreleased** (sin publicar).

## Por qué esto importa

Las traducciones están entre las contribuciones más bienvenidas en los proyectos de código abierto, y entre las más difíciles de revisar para quienes los mantienen. Una traducción con un issue claro, una revisora nativa y una línea en el changelog es una contribución modelo.

## Se completa cuando

- [ ] Una página 3D traducida, con el `lang` correcto, fusionada mediante un pull request.
- [ ] Ambas páginas se enlazan entre sí.
- [ ] Una hablante del idioma la revisó.
