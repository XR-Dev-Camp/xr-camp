# Challenge 1: Foundation

**Required.** Roughly 45 minutes.

Become a better reviewer.

## Task

1. Review three pull requests: your partner's, and two more (ask classmates, or review your own older PRs as if a stranger wrote them).
2. In each review, leave at least: one question, one specific suggestion (use **Insert a suggestion**), and one comment on something done well.
3. Test each PR before you approve: open the branch's page, and use it with the keyboard.
4. Write a short guide, `REVIEWING.md`, in your practice repository: five rules for kind, useful reviews, each with an example. Send it as a pull request.

## Why this matters

Teams learn most in reviews, and many developers review more code than they write. Reviewing well, specific, kind, and tested, is a skill people notice and remember.

## Done when

- [ ] Three reviews, each with a question, a suggestion, and praise.
- [ ] You tested each change before approving.
- [ ] `REVIEWING.md` is merged, through a pull request.
