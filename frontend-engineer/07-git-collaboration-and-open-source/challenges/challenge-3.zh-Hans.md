# 挑战 3：探索

**进阶选做。** 约 90 分钟，外加等待维护者回应的时间。

为一个真实的开源项目做出一次真实的贡献。

## 任务

1. 选择一个你用过的项目：XR Camp 本身、A-Frame、three.js、MDN 的内容，或者一个用你自己语言写的项目。阅读它的 README、`CONTRIBUTING.md`、行为准则和许可证。
2. 找一个小的、真实存在的问题：一个拼写错误、一个失效的链接、一句不够清楚的话、缺失的 `alt`，或者一处翻译。很多项目会给这类问题打上 **good first issue** 标签。找一个还没有人在处理的问题。
3. 在议题下留言表示你想认领它（如果这个问题还没有被记录，就自己开一个），如果指南要求的话，就等待对方回复。
4. Fork、创建分支、修复问题，并发起一个严格遵循该项目规则的拉取请求。
5. 回应审查意见。要有耐心：维护者往往是志愿者。
6. 不论结果如何，都要把整个过程记录在你的贡献记录中。一个被礼貌讨论后关闭的拉取请求，依然是一次经验。

## 为什么这很重要

一次被合并进真实项目的贡献，加上一段公开的审查对话，是你能向雇主展示的最有说服力的东西之一。它证明了你能读懂别人的代码、遵循他们的规则，并和你从未见过面的人一起协作。

## 完成标准

- [ ] 你在开始之前阅读了该项目的贡献指南。
- [ ] 在一个真实项目中，有一个议题和一个拉取请求相互关联。
- [ ] 你回应了每一条审查意见。
- [ ] 整个过程都记录在你的贡献记录中。
