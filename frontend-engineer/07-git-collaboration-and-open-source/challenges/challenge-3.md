# Challenge 3: Explorer

**Optional stretch.** Roughly 90 minutes, plus waiting for maintainers.

Make a real contribution to a real open-source project.

## Task

1. Choose a project you have used: XR Camp itself, A-Frame, three.js, MDN's content, or a project in your own language. Read its README, `CONTRIBUTING.md`, code of conduct, and licence.
2. Find a small, real problem: a typo, a broken link, an unclear sentence, a missing `alt`, a translation. Many projects label these **good first issue**. Search for one that nobody is working on yet.
3. Comment on the issue that you would like to work on it (or open one, if it is new), and wait for a reply if the guide asks you to.
4. Fork, branch, fix, and open a pull request that follows the project's rules exactly.
5. Respond to review. Be patient: maintainers are often volunteers.
6. Record everything in your contribution log, whatever the result. A closed pull request with a polite discussion is still experience.

## Why this matters

A merged contribution to a real project, with a public review conversation, is one of the strongest things you can show an employer. It proves you can read someone else's code, follow their rules, and work with people you have never met.

## Done when

- [ ] You read the project's contributing guide before starting.
- [ ] An issue and a pull request, linked, in a real project.
- [ ] You responded to every review comment.
- [ ] The whole story is in your contribution log.
