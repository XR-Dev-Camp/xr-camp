# 挑战 2：创意

**选做。** 约 45–60 分钟。

把这个练习仓库带进你的语言。

## 任务

1. 在你的副本中开一个议题：「Translate the 3D example into Chinese」（或者其他你的语言）。
2. 在一个分支上，创建 `3d/index.zh-Hans.html`（或者其他对应的文件名），正确设置 `<html lang>`，并翻译每一个词：标题、说明文字、按钮，以及场景描述。
3. 把这两个页面互相链接起来，每个链接都用它自己的语言标注：`<a href="index.zh-Hans.html" lang="zh-Hans">简体中文</a>`。
4. 请一位会说这门语言的伙伴，不只审查代码，也审查翻译内容本身。
5. 在 `CHANGELOG.md` 的 **Unreleased** 下面加一行说明。

## 为什么这很重要

翻译是开源项目中最受欢迎的贡献之一，同时也是维护者最难审查的贡献之一。一份配有清晰议题、母语审查者和更新日志条目的翻译，就是一次典范式的贡献。

## 完成标准

- [ ] 一个已翻译的 3D 页面，`lang` 设置正确，已通过拉取请求合并。
- [ ] 两个页面互相链接。
- [ ] 一位使用这门语言的人审查过它。
