# Challenge 2: Creative

**Optional.** Roughly 45–60 minutes.

Bring the practice repository into your language.

## Task

1. Open an issue in your copy: "Translate the 3D example into Spanish" (or Chinese, Portuguese, Quechua: your language).
2. On a branch, make `3d/index.es.html` (or `index.zh-Hans.html`, and so on) with `<html lang>` set correctly, and every word translated: the heading, the instructions, the button, and the scene description.
3. Link the two pages to each other, with each link in its own language: `<a href="index.es.html" lang="es">Español</a>`.
4. Ask a partner who speaks the language to review the translation, not only the code.
5. Add a line to `CHANGELOG.md` under **Unreleased**.

## Why this matters

Translations are among the most welcome contributions to open-source projects, and among the hardest for maintainers to review. A translation with a clear issue, a native reviewer, and a changelog line is a model contribution.

## Done when

- [ ] A translated 3D page, with the right `lang`, merged through a pull request.
- [ ] Both pages link to each other.
- [ ] A speaker of the language reviewed it.
