# 挑战 2：创意

**选做。** 约 60 分钟。

使用你自己的数据：你的学习计划，或者你所在社区的活动安排。

## 任务

1. 编写一份格式完全相同的 JSON 文件：一个 `phases` 列表（每项包含 `phase` 数字和 `title`），以及一个 `lessons` 列表（每项包含 `phase` 数字、`title`、`minutes`、`sessions`，以及取值为 `"ready"` 或 `"coming-soon"` 的 `status`）。
2. 它可以是你自己的 XR Camp 学习计划，带上你自己设定的目标日期；也可以是你所在社区的每周活动安排。
3. 让 `loadCatalog` 指向你的文件：`loadCatalog('data/my-plan.json')`。
4. 检查一下 JSON 是否有效：少一个逗号就会出错。你的错误提示信息会告诉你哪里出了问题。

## 为什么这很重要

因为 `render.js` 和 `format.js` 从不提及 XR Camp，它们可以处理任何相同格式的数据。只依赖数据结构本身、而不依赖数据来源的代码，才能被复用。

## 完成标准

- [ ] 你的页面显示了你自己的数据，且已分组并计算总数。
- [ ] 一个有问题的 JSON 文件会显示你的错误提示信息，而不是一片空白。
