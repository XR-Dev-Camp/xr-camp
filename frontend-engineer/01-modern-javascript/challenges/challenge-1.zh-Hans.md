# 挑战 1：基础

**必做。** 约 45 分钟。

一个按标题筛选课时的搜索框。

## 任务

1. 在地图上方加一个带标签的搜索框：`<label for="search">Search lessons</label>` 和 `<input id="search" type="search">`。
2. 在 `main.js` 中，当它发生变化时（`input` 事件），只用标题包含搜索词的课时重新绘制。先把两者都转成小写。
3. 它必须和「仅显示已就绪」一起工作：两个筛选器同时生效。
4. 更新 `#summary`，说明有多少课时匹配，好让屏幕阅读器也能朗读出来。

## 为什么这很重要

组合筛选器正是许多应用变得混乱的地方。如果每个筛选器都是一个小函数，`draw` 把它们全部应用一遍，那么添加新的筛选器就既简单又安全。

## 完成标准

- [ ] 输入内容后能筛选课时，不区分大小写。
- [ ] 搜索和「仅显示已就绪」可以一起工作。
- [ ] 摘要会朗读出有多少课时匹配。
