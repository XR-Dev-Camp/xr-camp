# Completed — Modern JavaScript

The reference solution: the course map, the first part of My XR Camp. Open it
**after** you have written your own modules.

## Comparing against your own work

Your modules can be organised differently. Check only:

- Does each module have one clear job?
- Does a failure show a helpful message, and does Try again work?
- Could someone who has never seen your code find where the data is loaded in under a minute?
