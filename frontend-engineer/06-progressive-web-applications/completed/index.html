This app on your device

Install

  • Chrome, Edge, or Samsung Internet on Android: open the browser menu and choose Install app or Add to Home screen.
  • Chrome or Edge on a computer: choose the install icon in the address bar, or look for Install in the browser menu.
  • Safari on iPhone or iPad: choose Share, then Add to Home Screen.
  • Other browsers: some cannot install web apps. Bookmark this page instead: in most modern browsers it still opens offline.
