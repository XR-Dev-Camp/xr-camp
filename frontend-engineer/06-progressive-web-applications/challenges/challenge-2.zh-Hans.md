# 挑战 2：创意

**选做。** 约 60 分钟。

让这个应用成为你自己的：它的图标、颜色、名称，以及用你的语言写的离线页面。

## 任务

1. 用 SVG 画一个属于你自己的图标：来自你所在城镇、你的文化，或者你所在社区天气的元素（一座山、一座火山、一条河、一盏灯笼）。保持简洁：只有少数几个形状的图案在小尺寸下才最清晰。
2. 制作一个可遮罩版本：用颜色填满整个正方形，并把重要的形状都保留在中心圆形内（半径为宽度的 40%）。在免费的 [Maskable.app editor](https://maskable.app/editor) 中检查一下效果。
3. 生成 PNG 文件：在浏览器中打开 SVG，以 192 像素和 512 像素分别截图（或者使用任何免费的图像编辑器），替换 `icons/` 中的文件。在 `ATTRIBUTION.md` 中标注你图标的来源。
4. 修改 `name`、`short_name`、`theme_color` 和 `background_color`。如果你的应用是西班牙语或中文的，把 `lang` 设置为 `es` 或 `zh-Hans`，并翻译 `offline.html` 和更新提示。
5. 修改 `VERSION`，让已经安装这个应用的学习者也能获得更新。

## 为什么这很重要

主屏幕上的一个图标就是一种承诺：这是专门为你做的东西。当名称、图标和离线页面都用你所在社区的语言说话时，这个应用就会给人一种归属于他们的感觉。

## 完成标准

- [ ] 你自己的图标出现在 **Application > Manifest** 中，可遮罩的那个版本在被裁成圆形后依然完好。
- [ ] 名称和颜色都是你自己的，离线页面上的文字依然满足对比度要求（4.5:1）。
- [ ] `offline.html` 和更新提示都是你的语言，`lang` 设置正确。
- [ ] 在 `ATTRIBUTION.md` 中标注了你图标的来源。
