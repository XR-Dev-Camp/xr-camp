# 挑战 1：基础

**必做。** 一个用来确认你理解了核心思路的小改动。约 45 分钟。

## 任务

1. 选择一小段应用中目前还没有显示出来的文字——例如，仪表盘上一句简短的欢迎语，或者天气城市选择器帮助文字的标签。
2. 把它的键加入全部三个语言文件（`en.js`、`es.js`、`zh-Hans.js`）中，自己写出对应的西班牙语和中文（或者借助 AI 助手，并如实记录在 `ai-log.md` 中）——一次简短、诚实的尝试就够了，不需要完美。
3. 在页面中用 `t('your.key')` 使用它，如果它永远不需要参数，也可以用 `data-i18n="your.key"`。
4. 用语言切换器切换语言，确认你新加的文字也跟着变化。

## 为什么这很重要

从头到尾亲手添加一个新字符串——一个键、三份翻译，以及一个使用它的地方——正是「为多语言做好准备」这件事最小的一个单元。如果你能正确地做这件事一次，你就能做上一百次，而这正是一个真正的应用最终需要的。

## 完成标准

- [ ] 新的键存在于全部三个语言文件中。
- [ ] 它在英语、西班牙语和简体中文下都正确显示。
- [ ] `node scripts/validate-projects.mjs` 依然通过。
