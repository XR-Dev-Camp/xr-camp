# 挑战 2：创意

定制这个项目，让它反映出你自己的兴趣、社区，或语言。约 45–60 分钟。

## 任务

让 My XR Camp 成为你自己的。至少选择一项：

- **你自己的图标。** 用一种感觉像你自己的风格，画一个新的 `icon.svg`（以及对应的可遮罩版本），并重新生成 PNG。更新 `ATTRIBUTION.md`。
- **你自己的城市。** 把你附近的一个城市加入 `config.js` 的 `CITIES` 中，附上它的经纬度，并在每一个语言文件中加入一个 `city.<id>` 键。
- **你自己的语言。** 如果你会说一种目前三份初稿还没有覆盖的语言，就添加第四个语言文件、在 `config.js` 中添加一条 `LOCALES` 记录，并在语言切换器中添加一个选项。像西班牙语和中文一样，把它标注为初稿，除非你是一位有信心不需要审查的母语者。
- **你自己的配色主题。** 修改 `styles.css` 中的 CSS 自定义属性（`--color-primary` 等等），并对照 WCAG 2.2 AA 重新检查每一组颜色搭配。

## 为什么这很重要

一个只能按照作者设想的方式运作的工具，只是一个演示品。而一个学习者可以把它调整成适合自己的城市、自己的语言、自己的品味，却不用碰任何让它能运作起来的代码——这才更接近一个值得保留的东西。
