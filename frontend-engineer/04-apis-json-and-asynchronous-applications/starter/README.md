# Starter — APIs, JSON, and Asynchronous Applications

Begin here.

- `js/config.js` is finished, and starts with TODO 1: read the API's JSON in
  your browser before writing any code.
- `js/api.js` (TODOs 2 and 5), `js/forecast.js` (TODOs 3–4),
  `js/view.js` (TODOs 6–8), `js/cache.js` (TODO 9), and `js/main.js`
  (TODOs 10–13) have numbered TODOs.
- Until TODO 10 is done, the page says "Loading…" forever. That is expected.
- `data/sample-forecast.json` has the same shape as the API's answer, for
  working offline.
- `3d-moment.html` shows the forecast as 3D bars. It uses your modules, so it
  works once TODOs 2–6 are done.

Open everything through a local server (http://).
