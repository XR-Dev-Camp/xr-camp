# 挑战 2：创意

**选做。** 约 60 分钟。

为**你自己的**社区制作一个公共数据仪表盘。

## 任务

1. 把你自己所在的城镇加入 `config.js` 中的 `CITIES`：在任意地图上查到它的经纬度。
2. 再添加一项对你所在地区有意义的每日数据。Open-Meteo 的文档中列出了这些选项：例如 `uv_index_max`（紫外线）、`wind_speed_10m_max`（风速），或 `precipitation_sum`（降雨量，而不只是概率）。把它加到 URL、`toDays`、表格和示例文件中。
3. 把摘要句子改成对你的社区真正有用的内容：适合摆摊的日子、适合晾衣服的日子、适合步行去图书馆的日子。
4. 用你自己的语言显示日期和数字：把 `<html lang>` 设置为 `es` 或 `zh-Hans`，其余交给 `Intl` 处理。翻译所有标签。
5. 按照许可要求，在页面上注明数据来源。

## 为什么这很重要

同样的四种状态、缓存和竞态防护，适用于任何公共数据：公交时刻表、空气质量、图书馆开放时间。一旦你把一个数据仪表盘做对了，你就能为你的社区需要的任何东西做出同样的仪表盘。

## 完成标准

- [ ] 你的城镇出现在列表中，表格和示例文件中都有一项新的每日数据。
- [ ] 摘要句子对你的社区来说是有用的。
- [ ] 日期和标签都以你的语言显示。
- [ ] 页面上注明了数据来源。
