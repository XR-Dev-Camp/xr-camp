# 挑战 1：基础

**必做。** 约 45 分钟。

记住学习者的选择，并用人类能理解的语言说明数据有多新。

## 任务

1. 把选中的城市和「使用示例数据」这个设置保存到 `localStorage` 中（放在一个专属的小模块里，而不是 `cache.js` 中：一个文件一个职责）。页面加载时把它们恢复出来。
2. 把「Saved in this browser at 14:05」替换成相对时间：「5 分钟前更新」「2 小时前更新」。使用 `Intl.RelativeTimeFormat`，它支持所有语言：

   ```js
   new Intl.RelativeTimeFormat('en', { numeric: 'auto' }).format(-5, 'minute')   // "5 minutes ago"
   ```

3. 把它写成一个纯函数 `describeAge(savedAt, now)`，这样你就可以用固定的时间来测试它（把 `now` 作为参数传入，而不是在函数内部调用 `Date.now()`）。
4. 检查以下情况：30 秒前、5 分钟前、3 小时前、2 天前。

## 为什么这很重要

「14:05」需要学习者自己算一下时间差；「5 分钟前」则不需要。而记住某个人选择的城市、让他们不用再选一次，正是这种小小的用心，会让人愿意再次使用一个应用。

## 完成标准

- [ ] 重新加载页面后，城市和示例数据的设置都被保留。
- [ ] 数据来源那一行会说明数据是多久之前保存的。
- [ ] `describeAge` 是一个纯函数，你用四个固定的时间点检查过它。
