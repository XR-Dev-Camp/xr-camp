# 挑战 3：探索

**进阶选做。** 约 90 分钟。

添加第二个 API：显示所选城市附近最近发生的地震。

## 任务

1. 美国地质调查局（USGS）以 GeoJSON 格式免费发布地震数据，无需密钥，也允许 CORS。先从过去一周内震级 2.5 及以上的地震开始：`https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/2.5_week.geojson`。先在浏览器中读一读它的响应内容（本课第 1 步的做法）。
2. 每一次地震都是一个 `feature`，包含 `properties.mag`、`properties.place`、`properties.time`，以及 `geometry.coordinates`（经度、纬度、深度：注意顺序）。
3. 写一个纯函数 `nearby(features, city, km)`，只保留距离城市 `km` 公里以内的地震。查一查计算球面上两点间距离用的**半正矢公式（haversine formula）**。
4. 用同样的四种状态展示结果：加载中、错误、空（「本周 500 公里内没有震级高于 2.5 的地震」：这是好消息，用平静的语气表达）、就绪。
5. 制作一份结构相同的示例文件，供离线时使用。如果 USGS 的数据源在你所在地区较慢或被屏蔽，就先用示例数据来构建。
6. 这两个请求是相互独立的：用 `Promise.allSettled` 同时发起它们，这样一个失败不会掩盖另一个的结果。

## 为什么这很重要

真实的仪表盘会整合多个数据来源，而每一个都可能各自失败。`Promise.allSettled`、每个来源各自一套状态、每个来源各自一份示例文件——这些正是专业应用在部分网络不可用时依然保持可用的方法。

## 完成标准

- [ ] 所选城市附近的地震以无障碍的表格或列表形式显示出来。
- [ ] 每个数据来源都有各自的加载、错误、空和就绪状态。
- [ ] 一个数据源失败不会影响另一个。
- [ ] 两者都能用示例数据离线工作。
