# 挑战 3：探索

**进阶选做。** 约 60 分钟。

用「上移」和「下移」按钮重新排列目标。

## 任务

1. 给每个目标再添加两个按钮：**上移**和**下移**，二者都带有指明该目标名称的 `aria-label`。
2. 按下按钮时，在 `state.goals` 中把该目标和它的邻居互换位置，保存状态，并在页面中移动对应的元素。移动的是它的**邻居**，而不是它本身：上移时用 `item.after(item.previousElementSibling)`；下移时用 `item.before(item.nextElementSibling)`。
3. 检查焦点是否仍停留在被按下的按钮上。（如果你移动的是拥有焦点的元素本身，它会暂时离开页面，浏览器会因此丢失焦点。这时你就得再调用一次 `button.focus()`。）
4. 在第一个目标上隐藏或禁用「上移」，在最后一个目标上隐藏或禁用「下移」。
5. 朗读新的位置：「Finish Phase 1 moved to position 1 of 3」。

## 为什么这很重要

拖放操作很常见，但对许多使用键盘和屏幕阅读器的用户来说是不可能完成的。用按钮来移动项目是一种无障碍的替代方案，许多设计系统也同时提供这两种方式。

## 完成标准

- [ ] 目标可以用键盘重新排序，且顺序在重新加载后依然保留。
- [ ] 焦点停留在被按下的按钮上，新的位置会被朗读出来。
