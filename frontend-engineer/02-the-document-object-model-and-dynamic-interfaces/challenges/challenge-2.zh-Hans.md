# 挑战 2：创意

**选做。** 约 60 分钟。

给每节课添加笔记。

## 任务

1. 给每一行课时添加一个**笔记（Notes）**按钮，点击后在下方展开一个小表单：一个带标签的文本框和一个**保存笔记**按钮。
2. 把笔记保存在状态中（例如 `state.notes[lessonId]`），保存位置是 `state.js`，并存入 `localStorage`。
3. 当某节课有笔记时，在其标题下方显示一段简短的预览。
4. 保存后，把焦点移回笔记按钮，并朗读「Note saved」。

## 为什么这很重要

一个能承载你自己想法的仪表盘会变得真正属于你：写笔记的学习者会记得更多内容。从技术上看，这道题综合运用了本课的全部内容：状态、事件委托、动态表单和焦点管理。

## 完成标准

- [ ] 笔记能打开、保存，并在重新加载后依然保留。
- [ ] 保存后焦点会回到笔记按钮上。
