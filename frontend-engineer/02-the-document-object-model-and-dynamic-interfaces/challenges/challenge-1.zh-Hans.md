# 挑战 1：基础

**必做。** 约 45 分钟。

一个「仅显示未完成课时」的筛选器，并保持焦点合理。

## 任务

1. 在地图上方添加一个带标签的复选框：「Show only lessons not done yet」。
2. 打开它时，用 `hidden` 属性隐藏已完成的课时，而不是重新绘制，这样其他内容都不会改变。先在 `styles.css` 中加入 `[hidden] { display: none !important; }`：否则 `.lesson { display: flex; }` 会占上风，被隐藏的行仍会显示。
3. 现在在筛选器开启时勾选一节课：它会消失。这时焦点在哪里？把它移到同一阶段中下一个可见的复选框上；如果没有剩余的了，就移到该阶段的标题上（给标题加上 `tabindex="-1"`，让它可以通过脚本接收焦点）。
4. 在 `#status` 中朗读还剩多少节课。

## 为什么这很重要

筛选器和焦点常常互相冲突：你刚用过的元素消失了。决定在某个东西消失时焦点该去哪里，是构建动态界面时最重要的技能之一。

## 完成标准

- [ ] 筛选器能隐藏已完成的课时，且无需重新绘制页面。
- [ ] 在筛选时勾选一节课，焦点会移到一个合理的位置。
- [ ] 剩余课时的数量会被朗读出来。
