# 挑战 1：基础

**必做。** 约 45 分钟。

给整洁版本的计划器添加一个功能，看看这个结构能带来多大帮助。

## 任务

1. 给「Still to do（尚未完成）」中的每个时段添加一个**编辑**按钮。按下它后，把该时段的文字替换成一个带标签的文本框（「Topic for Tuesday at 19:00」）和一个**保存**按钮。按下保存（或回车）会修改主题。
2. 给 store 添加一个新动作 `renameSession(id, topic)`，它会拒绝空的主题。
3. 保持焦点合理：开始编辑时焦点进入文本框，保存后焦点回到该时段的编辑按钮上。朗读这次变化。
4. 记录下你改动过的每一个文件，以及原因。
5. 现在设想把同样的功能加到 `old/app.js` 中。你需要碰哪些部分？

## 为什么这很重要

架构的意义不在于整洁本身，而在于让下一次改动变得容易。如果你在第 4 步写下的是「store：新增一个动作；组件：新增一个按钮；main：click 监听器里多一个分支」，那就说明这个结构正在发挥作用。

## 完成标准

- [ ] 仅用键盘就能重命名时段。
- [ ] 空主题会被拒绝，并在字段旁边显示提示信息。
- [ ] 只有 store 会修改状态；组件只负责构建。
- [ ] 你的学习日志中记录了改动过的文件清单，以及第 5 步的回答。
