# 挑战 2：创意

**选做。** 约 45–60 分钟。

只修改 `config.js`（外加一件事），让这个计划器成为你自己的。

## 任务

1. 在 `config.js` 中设置你真实的每周目标和时段长度。其他一切是否都随之自动更新，包括摘要句子和总时长？
2. 你的一周是从周一开始，还是周日开始？相应地修改 `DAYS`，并更新 `index.html` 中的 `<option>`。
3. 使用浏览器内置的 `Intl` API，用你自己的语言显示日期名称和时间，这样就不需要额外的翻译列表：

   ```js
   new Intl.DateTimeFormat('es', { weekday: 'long' }).format(someDate)
   new Intl.DateTimeFormat('zh-Hans', { hour: 'numeric', minute: '2-digit' }).format(someDate)
   ```

   保持存储值仍是英文的日期名称（这样排序才能继续正常工作），只翻译显示出来的部分。哪个文件才是做这件事的合适位置：`utils.js`、某个组件，还是 `main.js`？写下你的理由。
4. 把 `<html lang>` 设置为与你所显示的语言相匹配。

## 为什么这很重要

设置集中在一处，格式化与数据分离，这正是让一个应用容易翻译的关键。课程 6.2 正是建立在这个基础之上。

## 完成标准

- [ ] 你自己的目标、时段长度和一周的第一天，全部来自 `config.js`。
- [ ] 日期和时间以你的语言显示，存储的数据保持不变。
- [ ] 旧的已保存时段依然能正确加载并排序。
