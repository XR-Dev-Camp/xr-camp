# Starter — Application Architecture and Maintainable Code

Begin here.

- `old/index.html` and `old/app.js` are the tangled planner. It works, but it
  is written badly on purpose. Do not edit it: you compare against it.
- `behaviour.md` is where you list what the old app does, and what is wrong
  with it (TODOs 1–2), before you change any code.
- `js/` holds the new structure, with numbered TODOs 3–13:
  `config.js`, `utils.js`, `store.js`, `components/`, and `main.js`.
  `index.html` has TODO 11.
- `check.html` tests `utils.js`. It is finished: run it after TODOs 4 and 5.
- Until the TODOs are done, the console shows errors about missing exports
  and missing elements: that is expected.
- `3d-moment.html` is a tangled 3D scene to refactor.

Open everything through a local server (http://).
