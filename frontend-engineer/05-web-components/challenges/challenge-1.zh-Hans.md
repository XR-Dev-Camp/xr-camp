# 挑战 1：基础

**必做。** 约 45 分钟。

在不破坏已经在使用这张卡片的人的前提下扩展它的功能。

## 任务

1. 添加一个 `lesson-number` 属性，比如 `lesson-number="2.5"`。设置了它之后，在标题内部、标题文字之前显示它：「2.5 Web Components」。没有设置时，只显示标题。
2. 把它加入 `observedAttributes`，并检查在 Elements 面板中修改它是否会立即更新卡片。
3. 把这个数字放进它自己的 `<span part="number">` 中，这样页面就可以用 `lesson-card::part(number)` 来给它设置样式。在你的页面上给它设置一下样式。
4. 按钮的名称是否也应该跟着变化？做出决定，并写下理由。（是「Done: 2.5 Web Components」，还是「Done: Web Components」？）
5. 在 `main.js` 中，为课程目录里的每一张卡片设置 `lesson-number`，如果「Course 2.5 of XR Camp.」这句话现在和数字重复了，就把它删掉。
6. 更新 `components.md`：属性表、part 表和示例。

## 为什么这很重要

一旦其他页面开始使用你的组件，它的属性、事件和 part 就成了一种承诺。一个新的、可选的属性能够遵守这个承诺：之前写好的每一张卡片依然能像原来一样正常工作。而删除或重命名某个东西则会破坏这个承诺。

## 完成标准

- [ ] 有和没有 `lesson-number` 的卡片看起来都正确。
- [ ] 属性变化时，这个数字会实时更新。
- [ ] 页面用 `::part(number)` 给这个数字设置了样式。
- [ ] 在屏幕阅读器的标题列表中，标题读起来依然通顺。
- [ ] `components.md` 中记录了新的属性和 part。
