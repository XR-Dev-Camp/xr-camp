# 挑战 2：创意

**选做。** 约 45–60 分钟。

制作一张用你的语言表达、内容来自你的社区的卡片。

## 任务

1. 直接在 `index.html` 中写一张新卡片，内容是你想学习或想教给别人的东西：你所在城镇的一场工作坊、你家族的一门手艺、一个和朋友一起做的项目。使用插槽：一个描述，以及你想放进默认插槽的任何其他内容（一个列表、一个链接、一条备注）。
2. 让卡片自己的文字跟随页面的语言变化。用 `this.closest('[lang]')?.lang` 找到最近的 `lang`，并把文字保存在一个小表格中：

   ```js
   const WORDS = {
     en: { ready: 'Ready', 'coming-soon': 'Coming soon', done: 'Done' },
     es: { ready: 'Disponible', 'coming-soon': 'Próximamente', done: 'Hecho' },
   };
   ```

   如果表格里没有你的语言，就把它加进去。对于你还没写的语言，回退到英语。
3. 用浏览器的 `Intl` API 显示时长，这样数字也能跟随你的语言：`new Intl.NumberFormat('zh-Hans').format(10)`。
4. 只给一张卡片设置 `lang`（`<lesson-card lang="zh-Hans">`），检查是否只有那张卡片发生了变化。按钮的无障碍名称是否也跟着变了语言？

## 为什么这很重要

一个组件会在很多地方、被很多人使用。当它的文字取自页面所使用的语言时，一个组件就能服务于每一个社区——XR Camp 的课程之所以用英语、西班牙语和中文撰写，正是出于这个原因。

## 完成标准

- [ ] 有一张关于你自己社区的卡片，两个插槽都用上了。
- [ ] 徽章、按钮和时长都以页面所使用的语言显示。
- [ ] 遇到未知语言时会回退到英语，且不会报错。
- [ ] 按钮的名称仍然以可见的文字开头。
