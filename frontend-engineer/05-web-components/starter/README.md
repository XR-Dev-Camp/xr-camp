# Starter — Web Components

Begin here.

- `index.html` is the lesson cards page. TODO 1: write your first
  `<lesson-card>` straight into the HTML.
- `js/lesson-card.js` is your custom element, with TODOs 2–8: the class,
  the template with slots and parts, the shadow root, styles, attributes,
  heading levels, and the `lesson-toggle` event.
- `styles.css` is finished except TODO 9: `::part()` and `:not(:defined)`.
- `js/main.js` loads the catalog and fills the Phase list (finished), with
  TODOs 10–11: build the cards, and listen for their events.
- `js/data.js`, `js/format.js`, `js/progress.js` and `data/catalog.json` are
  finished.
- `components.md` is the documentation: TODO 12. The `<model-stage>` part is
  already written, as an example.
- `3d-moment.html` and `js/model-stage.js`: a 3D viewer in your own element,
  with TODOs 13–14.
- Until TODO 10 is done, the catalog shows plain titles instead of cards:
  that is expected.

Open everything through a local server (http://).

Full instructions: [`../README.md`](../README.md).
