# Project check

Work through this list before you submit.

## Rules and honesty
- [ ] `ai-log.md` starts with your rules, written before your first question.
- [ ] You pasted no secrets, no personal data, and no code you have no right to share.
- [ ] You followed your school's or employer's AI rules, if they have any.
- [ ] Every use of an assistant is in the log, including the answers you did not use.
- [ ] Your page and your portfolio say where AI helped.

## Understanding first
- [ ] Your own explanation of the code was written before you asked anything.
- [ ] At least two items asked for an explanation, not a fix.
- [ ] Every "What I checked" says what you predicted before you ran it.
- [ ] You can explain every line you accepted or changed, without looking.

## The review
- [ ] At least seven items, each with all six parts.
- [ ] Every verdict has a source: a documentation page, a specification, or a test you ran.
- [ ] At least one rejection, with evidence.
- [ ] Every claim in `invented-apis.md` is checked on MDN and in the Console.
- [ ] One item compares the assistant with your own keyboard and screen-reader test.
- [ ] One question was asked in a second language, and compared.
- [ ] Each accepted or changed suggestion is its own commit, and `planner/check.html` still passes.

## The review page
- [ ] One `h1`, then `h2` sections and `h3` items, in order.
- [ ] The table has a caption, and column and row headers.
- [ ] The table's box can be reached with Tab, and scrolled with the arrow keys.
- [ ] At 320 CSS pixels wide, the page never scrolls sideways.
- [ ] Every verdict is a word; colour only helps.
- [ ] Quotes in other languages are marked with `lang`.
- [ ] Focus is visible on every link.
- [ ] The console shows no errors.

## 3D and XR (manual)

Automated tools cannot see inside a 3D canvas, so these are checked by a person. See [`docs/en/xr-accessibility.md`](../../../docs/en/xr-accessibility.md).

- [ ] The scene description says what is shown, where the light comes from, and whether it moves.
- [ ] With reduced motion on, the knot is still when the page opens.
- [ ] The Pause animation button stops and restarts the turning, from the keyboard, and the description changes to match.
- [ ] The knot turns slowly (30 degrees a second), nothing flashes, and the camera never moves.
- [ ] Every claim in the AI explanation has a verdict and a link to threejs.org/docs.
