# Starter — AI as a Development Assistant

Begin here.

- `planner/` is the code under review: the session planner from Course 2.3.
  If you finished your own planner, use yours instead.
- `ai-log.md`: your rules for using AI, and a log of every use (TODOs 1–2).
  Write your rules before you open any assistant.
- `review.md`: the review itself, item by item (TODOs 3–5, 8–10, 13).
- `invented-apis.md`: a made-up "AI answer", written by XR Camp, with claims
  to check against MDN (TODOs 6–7).
- `index.html`: your review, as a web page (TODOs 11–12). `styles.css` is
  finished.
- `3d-moment.html`: a three.js scene, and a made-up AI explanation of its
  code to check against the three.js docs (TODO 14).

Never paste secrets, personal data, or code you have no right to share into
an assistant. Open everything through a local server (http://).

Full instructions: [`../README.md`](../README.md).
