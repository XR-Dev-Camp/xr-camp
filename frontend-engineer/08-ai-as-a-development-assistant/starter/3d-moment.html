Check an AI's explanation of a 3D scene

Below is a small three.js scene, and an AI assistant's explanation of its code. Some claims are right, and some are wrong. Check every one against the official documentation at threejs.org/docs, before you look at completed/3d-moment.html.

A purple torus knot, a tube tied in a knot like a pretzel, floats in the middle of a pale background. Light comes from the upper right, so that side is brighter. It turns slowly around its vertical axis.

The code

const camera = new THREE.PerspectiveCamera(50, 1, 0.1, 100);
scene.add(new THREE.AmbientLight('#ffffff', 0.6));

const sun = new THREE.DirectionalLight('#ffffff', 2.5);
sun.position.set(3, 4, 5);

const knot = new THREE.Mesh(
  new THREE.TorusKnotGeometry(1, 0.32, 128, 16),
  new THREE.MeshStandardMaterial({ color: '#5b2a86', roughness: 0.35 }),
);

const TURN_SPEED = THREE.MathUtils.degToRad(30);   // per second
knot.rotation.y += TURN_SPEED * seconds;

renderer.setAnimationLoop(paused ? null : frame);
