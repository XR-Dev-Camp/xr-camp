# Security and Privacy Policy

## Scope

This is the **public** XR Camp projects repository. By design it contains no authentication code, no learner data, and no production infrastructure. Those live in the private `xrcamp-platform` repository.

That design is the security control. The most valuable thing you can report here is a **boundary violation** — private material that has leaked into the public repository.

## Report privately

Email **security@xrcamp.dev**. Do not open a public issue.

> **Setup required:** this address must exist and be monitored before the repository is made public.

Include what you found, where, and how you found it. You will receive acknowledgement within three working days.

## Report immediately if you find

- API keys, tokens, credentials, or connection strings
- Learner names, email addresses, progress data, or journal contents
- Instructor private contact details or mentor notes
- Private community or office-hour links
- Production environment files or configuration
- Unreleased course drafts
- Assessment answer keys

Any of these in this repository is an incident, however small it appears.

## Also worth reporting

- A vulnerable dependency in an example project
- A reference solution that teaches an insecure pattern (learners copy these — an insecure example propagates)
- A project that collects personal data without disclosure
- A demo page that loads third-party trackers

## What we ask

Give us reasonable time to remediate before public disclosure. Do not access, modify, or exfiltrate data beyond the minimum needed to demonstrate the issue. Do not run automated scans against xrcamp.dev without prior written permission.

## Credit

With your consent, we will credit you in [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) and, where the finding is instructive, turn it into a teaching example — with your name attached if you wish.
