# 挑战 2：创意

**选做。** 约 45–60 分钟。

自定义这个项目，让它反映出你自己的兴趣、社区或语言。

## 任务

1. 在 `js/scene.js` 中，把 `EXHIBITS` 里的一项或多项替换为一个对你有意义的对象（一种食物、一座建筑、一件乐器，或来自你自己文化或社区的一个符号）——你只需要修改它的名称、它的 `made` 描述和颜色；几何形状可以仍然是一个简单的形状。
2. 在 `CAMERA_PRESETS` 中添加一个属于你自己的相机预设（在 `front`/`left`/`right`/`close` 之外的第五个选项），用你自己的语言命名，并把它接入 `index.html` 中的单选按钮，以及 `validation.js` 和 `js/main.js` 中的 `CAMERA_PRESETS` 列表。
3. 在 `updateDescription()` 中，完全用你自己的语言写出你新展品的描述，或者添加一个简短的双语版本。
4. 如果你使用了任何不是自己原创的参考图片或事实，请更新 `ATTRIBUTION.md`（一个你自己想出来的纯色和形状不需要署名）。

## 为什么重要

一个只保存别人那三个物件的 API 只能教会你其中的机制，却教不会你它们为什么可能对你有意义。重命名一件展品、添加一个相机角度，会触及和本课本身相同的验证、存储和渲染代码——只是把它指向了一些私人的东西。

## 完成标准

- [ ] 至少有一件展品和一个相机预设完全属于你自己（能正确保存、加载和显示）。
- [ ] `node --test` 依然通过，并针对你新预设的名称做了相应更新。
- [ ] 2D 展品列表和 3D 视图依然彼此一致。
