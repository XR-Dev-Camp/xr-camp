Ask an AI about the exhibit's scenes

Course 5.3 gave the exhibit a database of saved scenes. This lesson adds two small AI-assisted tools on top of it: a button that drafts a description of a scene from its own saved data, and a box where you can search scenes in plain language instead of scrolling a list. Neither tool changes anything by itself — read the notice below before you type anything into either one.

How the AI tools on this page work

Checking which AI provider is configured…

  • Every description and every search result is generated by a language model, not written by a person.
  • Only this scene's own data (its name, which exhibits it places, their positions, and any annotations) is ever sent — never an image, an IP address, or any personal or account data (this project has no accounts).
  • A description is always shown as a draft. It is never saved until you read it and choose "Save this description" yourself.
  • A search result lists only scenes that really exist in this project's database; see "Data sent" for exactly what was read to answer it.

                  This is a learning prototype
                  
      
                  This project has no accounts (Course 5.2) and no security hardening pass (Course 5.5) — every scene here is shared, local, single-tenant data. Its default AI provider is a deterministic mock that makes no network call; switching it to a real provider costs money per request and sends this project's scene data to whatever server AI_BASE_URL names (see server/.env.example). Before any part of this design stores or sends a real person's data, have it reviewed by someone with security and data-protection expertise.
