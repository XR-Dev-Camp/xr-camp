Offline scene bundles

The exhibit's models (Course 3.5) are downloadable as a scene bundle: one manifest naming every file and its size, so you know exactly what you are about to store before a single byte arrives. Download a bundle once, then open its scene with no network at all.

Settings


A school or community can host its own copy of the assets/ folder and put that server's URL here — useful when the main site is slow or blocked. The mirror must allow cross-origin requests (CORS) or be on this same site.

    How offline downloads keep going

    Checking Background Sync support…

    If a download is cut off by losing the connection, this page remembers which bundle was mid-way through and finishes it automatically once the connection is back — through Background Sync where the browser supports it, or by watching for the connection to return while this page stays open, everywhere else.

    This is a learning prototype

    This project stores files only on your own device, in this browser's storage for this site. Nothing is uploaded anywhere. A browser can still clear storage it has not been asked to keep (see "Ask the browser to keep this storage" above) — for anything you truly cannot afford to lose, keep a separate copy too.
