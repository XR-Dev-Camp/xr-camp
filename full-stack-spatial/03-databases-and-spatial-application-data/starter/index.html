Save your own exhibit, exactly as you left it

Course 5.2 gave every learner an account. This lesson gives every account a real database: arrange the clay pot, the basket ring, and the jade stone however you like, save the arrangement as a scene, add a short note to any exhibit, and load it back later — from this device or another one. A scene you mark public can be viewed (never changed) by anyone else signed in; a private scene is yours alone. Read the notice below before reusing any of this.

                    This is a learning prototype

                    This project is for learning, and it is deliberately small: one SQLite file, one process, no scheduled backups, and an in-memory session store carried over from Course 5.2. Before any part of this design stores a real person's data, have it reviewed by someone with security and data-protection expertise. Course 5.5 returns to a project like this one to find and fix planted vulnerabilities.
