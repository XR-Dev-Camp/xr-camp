# 挑战 2：创意

**选做。** 约 45–60 分钟。

用来自你自己的文化、语言或社区的东西，替换掉展品三个物件中的一个——并让技术栈的每一层都对此保持一致。

## 任务

1. 挑选一个对你有意义的真实物件——一件手工艺品、一件乐器、一种食物、一座建筑——并为它写一段简短、尊重的描述（一句话就够了；按照今天「made」描述陶罐、篮环和玉石的方式来写）。
2. 更新 `server/validation.js` 中的 `KNOWN_EXHIBITS`，以及 `js/scene.js` 中的 `EXHIBITS` 数组，把其中一项替换成你的新展品的 id 和名称。
3. 在 `js/scene.js` 的 `buildMesh` 中，为它添加一个简单的 three.js 几何体和颜色——它不需要是一个逼真的模型；一个可识别的替代形状就足够了（参考现有三个形状，了解预期的细节程度）。
4. 更新 `starter/index.html` 和 `completed/index.html` 的注释 `<select>`，使其与你的新展品列表匹配。
5. 如果你的物件名称使用了纯 ASCII 之外的字符（重音符号、汉字，或者 `KNOWN_EXHIBITS` 现有三个名称没有用到的其他任何字符），确认它在每一个出现的地方都能正确显示——包括 `scene.js` 绘制的 HTML 叠加标签，而不只是 three.js 自身的文字几何体（关于原因，参见本课程风格指南中的说明）。
6. 保存一个使用你的新展品的场景，重新加载页面，再把它加载回来。

## 为什么重要

XR Camp 的展品，是学习者最终会构建的任何东西的一个占位符——一座家中的博物馆、一件家族物品、一件本地工艺品。从头到尾（验证、存储和 3D 视图）修改展品的内容，是为了同一类改变中一个大得多的版本所做的一次小小的预演：在本课已经交给你的这个模式和权限规则之上，构建一个完全不同的展览。

## 完成标准

- [ ] 你的新展品出现在 3D 视图、位置/旋转表格和注释表单中。
- [ ] 一个使用它的场景能正确验证、保存并重新加载。
- [ ] 你添加的任何非 ASCII 文字，在你能测试的每一个浏览器中都能正确显示。
- [ ] `node scripts/validate-projects.mjs` 依然通过（锁定的库版本和必需文件不受这次改动影响）。
