Review and fix: a small spatial app

This starter is a small, deliberately vulnerable spatial app -- accounts, saved scenes with an optional rough location, annotations you leave on a scene, and a shared chat room -- reusing Course 5.4's account and WebSocket foundations. It runs only on your own computer (127.0.0.1) and is never meant to be put online. Seven numbered TODOs, in the server and client code, each mark one real vulnerability: find it, understand why it matters, and fix it. completed/ shows the fixed version.

DELIBERATELY VULNERABLE -- for learning on localhost only; never deploy. Every file with a bug repeats this warning at its top.

                      Before you reuse this

                      This starter is deliberately vulnerable, on purpose, so you can find and fix real security mistakes on a small, safe copy of an app -- never copy its server code into a real project. The server only binds to 127.0.0.1; it is not reachable from any other device even on your own network.
