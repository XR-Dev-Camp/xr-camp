# Reto 2: Creativo

**Opcional.** Aproximadamente 45–60 minutos.

Escribe tu propio modelo de amenazas estilo STRIDE para una pequeña aplicación de tu propia vida, cultura, o comunidad, no la aplicación de esta lección.

## Tarea

1. Elige una aplicación pequeña, real (o realista) que conozcas bien: el formulario de inscripción de un grupo comunitario, el chat de pedidos de un mercado local, el portal de tareas de una escuela, una hoja de cálculo de ayuda mutua de un barrio convertida en un formulario web; cualquier cosa con cuentas, o contenido enviado por usuarios, o datos personales de alguien.
2. Escribe una tabla STRIDE para ella, en la misma forma que el README de esta lección: una fila por cada amenaza de **S**uplantación (Spoofing), **T**ampering (manipulación), **R**epudiation (repudio), **I**nformation disclosure (divulgación de información), **D**enial of service (denegación de servicio), y **E**levation of privilege (elevación de privilegios), cada una nombrando algo *concreto* que podría salir mal en *esa aplicación específica*, no la descripción genérica de la categoría.
3. Para al menos tres filas, nombra una corrección específica y realista, citando una OWASP Cheat Sheet, un artículo de MDN, u otra fuente primaria donde aplique, de la misma forma que hace el propio README de esta lección.
4. Anota qué amenaza, para tu aplicación, sería la más dañina si se dejara sin corregir, y di por qué: a quién se le hace daño, y cómo.

## Por qué importa

STRIDE es una forma de pensar, no un hecho sobre una sola base de código; la destreza que esta lección quiere que conserves es preguntar "¿qué podría salir mal aquí, específicamente?" sobre *cualquier* aplicación, incluidas las que no construiste tú y por las que no te están calificando. Hacerlo una vez para algo que te importa, en tus propias palabras, es lo que hace que el hábito se quede.

## Terminado cuando

- [ ] Una tabla STRIDE para una aplicación de tu elección, con una amenaza concreta (no genérica) en cada fila.
- [ ] Al menos tres filas nombran una corrección específica y con fuente citada.
- [ ] Una nota breve sobre qué amenaza importa más para esta aplicación, y por qué.
