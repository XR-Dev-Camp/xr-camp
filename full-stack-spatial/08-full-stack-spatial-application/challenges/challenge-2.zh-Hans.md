# 挑战 2：创意

**选做。** 约 45–60 分钟。

自定义这个项目，让它反映出你自己的兴趣、社区或语言。

## 任务

1. 重写 `server/ai.js` 的 `mockDescription`，让它的句子听起来像是来自你自己社区的一位策展人或讲解员真正会说的话——依然只用场景真实的名称和注释文字来构建它（绝不为一个具体场景编造事实），但改变措辞、语气或结构，让它感觉是属于你自己的。
2. 如果你的语言使用了一种 A-Frame 默认文字字体不完全支持的文字（参见本仓库关于 A-Frame 文字和重音符号的风格指南），测试一下你自己新添加的界面文字是否依然能正确显示——描述面板是普通的 HTML，而不是 A-Frame 文字，所以这应该不需要额外的努力就能正常工作，但请确认这一点。
3. 更新 `index.html` 中的 `<meta name="description">` 和描述面板的提示文字，让它们匹配你的新语气，用英文写（翻译之后再做）。
4. 在 `CHANGELOG.md` 的 `1.0.0` 条目中添加一条简短的说明，描述你改动了什么，以及为什么。

## 为什么重要

一份描述的意义在于帮助某人想象出一个他无法直接看到的场景——能够做到这一点的文字，在每一种语言和文化中都是不同的。课程 5.6 刻意把这个功能设计成不依赖特定服务商，好让它的输出不被锁定在一种声音里；这个挑战要求你通过赋予它你自己的声音来证明这一点。

## 完成标准

- [ ] `mockDescription` 产生了带有你自己声音的文字，但依然只由真实的场景数据构建而成。
- [ ] 描述面板自己的文字（提示、标签）与那个声音相匹配。
- [ ] `npm test` 依然通过——除非你刻意且一致地修改了原始测试的断言，否则你测试数据的确切措辞不需要与它们完全匹配。
- [ ] `CHANGELOG.md` 中说明了你的改动。
