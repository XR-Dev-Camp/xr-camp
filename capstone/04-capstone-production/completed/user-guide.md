# User guide

## Getting started

Open the exhibit's link in any modern web browser, on a phone, tablet, or computer. No account, download, or payment is needed.

## What you can do here

Look around the gallery room by dragging the view, or use the "Turn left" and "Turn right" buttons. Choose an object from the list, or select it directly in the 3D view, to read about it. If you prefer not to see the 3D room, the same information is always available as a list below it.

## For maintainers

Object content lives in `data/exhibits.json`, separate from the code — a museum volunteer can update a description without touching any JavaScript. If a new object is added, it needs an entry in this file and a position in the spatial layout; no other files need to change. Known limitation: only English content exists at this stage; Spanish and Simplified Chinese are planned for a later translation pass, per XR Camp's process.
