# Challenge 1: Foundation

**Required.** Roughly 45 minutes.

Follow your own README as if you were a stranger.

## Task

1. Copy your production project into a completely new, empty folder (or ask someone else to try this with you).
2. Follow your own `readme-template.md` (or its finished `README.md`) step by step, doing exactly what it says and nothing more.
3. Note every step that failed, was unclear, or assumed knowledge the instructions never gave, and fix the README until it works from nothing.

## Why this matters

A README the author can follow proves nothing — the author already knows what it left out. A README that works from a truly empty folder is what makes your capstone usable by a mentor, a future employer, or your own future self after months away from the code.

## Done when

- [ ] The project was set up from scratch following only the README's own words.
- [ ] Every step that failed or confused was fixed.
- [ ] The README now works, verified by a genuinely fresh attempt.
