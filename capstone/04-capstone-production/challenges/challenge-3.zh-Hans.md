# 挑战 3：探索

**进阶选做。** 约 90 分钟。

为你的构建添加一项基础的自动化检查。

## 任务

1. 写一个小脚本（用 Node.js 即可，只使用内置模块，或者如果你已经安装了 `playwright-core`，也可以用它，就像本仓库自己的测试脚本那样），打开你的生产页面并检查控制台错误。
2. 在你的 README 中，用一节「Testing（测试）」记录如何运行它。
3. 运行它一次，并把结果记录在你的变更日志中。

## 为什么这很重要

一项能捕获「页面报错了」的自动化检查，编写成本很低，却能在你亲自发现之前，就先捕获到一次真实的回归问题。这是迈向专业团队所依赖的那种测试方式的一小步。

## 完成标准

- [ ] 存在一个脚本，能打开生产页面并报告控制台错误。
- [ ] README 中记录了如何运行它。
- [ ] 它至少运行过一次，结果已被记录下来。
