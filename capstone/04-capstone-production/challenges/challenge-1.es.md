# Reto 1: Fundamento

**Obligatorio.** Aproximadamente 45 minutos.

Sigue tu propio README como si fueras una persona desconocida.

## Tarea

1. Copia tu proyecto de producción a una carpeta completamente nueva y vacía (o pídele a alguien más que lo intente contigo).
2. Sigue tu propio `readme-template.md` (o su `README.md` terminado) paso a paso, haciendo exactamente lo que dice y nada más.
3. Anota cada paso que falló, que no quedó claro, o que asumió un conocimiento que las instrucciones nunca dieron, y corrige el README hasta que funcione desde cero.

## Por qué importa

Un README que su autora puede seguir no prueba nada; la autora ya sabe qué omitió. Un README que funciona desde una carpeta genuinamente vacía es lo que hace tu proyecto final utilizable por una mentora, una futura empleadora, o tu propia yo futura después de meses lejos del código.

## Se completa cuando

- [ ] El proyecto se configuró desde cero siguiendo solo las palabras del README.
- [ ] Cada paso que falló o confundió se corrigió.
- [ ] El README ahora funciona, verificado por un intento genuinamente nuevo.
