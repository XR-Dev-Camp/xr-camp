# 挑战 1：基础

**必做。** 约 45 分钟。

像一个陌生人一样，照着你自己的 README 走一遍。

## 任务

1. 把你的生产项目复制到一个全新的空文件夹里（或者请别人和你一起试一遍）。
2. 一步步照着你自己的 `readme-template.md`（或它完成后的 `README.md`）操作，只做它说的事，不多做任何事。
3. 记录每一处失败、不清楚，或者假定了说明里从未给出的知识的步骤，并修改 README，直到它能从零开始正常运作。

## 为什么这很重要

一份作者自己能照着做的 README 什么也证明不了——作者自己已经知道它漏掉了什么。一份从一个真正空的文件夹开始也能用的 README，才能让你的毕业设计对一位导师、未来的雇主，或者几个月后已经忘记这段代码的你自己而言，真正可用。

## 完成标准

- [ ] 只依靠 README 自身的文字，从零开始搭建过这个项目。
- [ ] 修复了每一处失败或造成困惑的步骤。
- [ ] 经过一次真正从零开始的尝试验证，README 现在能正常运作。
