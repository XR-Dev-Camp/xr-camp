# Presentation outline

## Structure

1. **The problem (45 seconds):** A small museum's collection is invisible to anyone who cannot visit in person.
2. **Demonstration (3 minutes):** Live walk-through of the exhibit: look around, select an object, then the same walkthrough done entirely by keyboard.
3. **What I learned (1.5 minutes):** Building the scene description and 2D list from one shared data source; the Pause-button fix from the Stage 3 design review.
4. **What's next (30 seconds):** Spanish and Simplified Chinese translations, and testing with real museum visitors.

## Speaking notes

Open with the problem in one sentence, not a slide of statistics. During the demonstration, narrate what a screen reader user would hear, not just what is on screen — it makes the accessibility work visible to an audience that cannot otherwise see it. Practised aloud twice before the real presentation; the first run was 40 seconds over time, so the "what's next" section was trimmed to two clauses.
