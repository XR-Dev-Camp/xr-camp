# Wireframes

## Screen or scene 1: the gallery room (3D view)

Layout description: a single rectangular room. The 3D canvas fills the left two-thirds of the page on wide screens (stacked above the rest on narrow screens). To its right, a controls panel holds "look around" buttons, a select-object list, and an information panel. Below the canvas, always visible, is the 2D object list: the same information as the room, in words.

Key elements, top to bottom:

1. Page heading and one-paragraph introduction.
2. The 3D canvas, with a loading message before the models finish loading.
3. The scene description paragraph, built from the same data as the 3D scene.
4. The always-present 2D object list.
5. The controls panel: look-around buttons, an object selector, and an information panel that fills in when an object is chosen.

## Screen or scene 2: an object's information panel

Layout description: a panel within the controls area (not a separate page), so choosing an object never loses the visitor's place in the room.

Key elements:

1. The object's title, as a heading.
2. A short description (two to three sentences).
3. The material and approximate date, where known.
