# User journeys

## Journey 1: primary audience — an online visitor

| Step | What they do | What they need to see or do next |
| --- | --- | --- |
| 1. Arrive | Opens the exhibit link from a social post or the museum's own site | A clear heading saying what this is and that it is free |
| 2. Orient | Reads the scene description and the 2D object list | A sense of what the room contains before entering the 3D view |
| 3. Explore | Looks around the gallery room, or moves through the 2D list with the keyboard | The same object information either way |
| 4. Act | Selects an object to read its label | A readable panel with the object's story, not just its name |
| 5. Leave | Closes the tab, or shares the link | A shareable URL that returns to the same room |

## Journey 2: a different stakeholder — the museum's collections volunteer

| Step | What they do | What they need to see or do next |
| --- | --- | --- |
| 1. | Receives the exhibit's content file to review | A plain-language, non-technical way to check object descriptions for accuracy |
| 2. | Suggests a correction to one label | A simple place to note the correction (a shared document, not a code change) |
| 3. | Confirms the correction appears in the next update | The exhibit's data model kept content separate from code, so this was possible without touching `data-model.md`'s structure |
