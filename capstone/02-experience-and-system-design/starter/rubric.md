# Stage 2 rubric: Experience and System Design

| Level | Journeys and wireframes | Spatial design | Data, API, and security | Test plan |
| --- | --- | --- | --- | --- |
| **Not yet** | Missing, or only one journey | No keyboard/button equivalents noted | Fields do not match the content described in Stage 1 | No accessibility or performance targets named |
| **Meets expectations** | Two journeys, wireframes for every screen or scene | Layout and scene graph cover the whole scope | Data model, API sketch, and security plan are all present and specific | Names specific accessibility checks and a rough performance budget |
| **Strong** | Wireframes were reviewed by a real person and revised | Every interaction has a documented keyboard/button equivalent | Security plan names concrete risks and mitigations, not only "none" | Test plan also names languages for future localisation checks |
| **Exceptional** | Journeys reflect real user feedback (Challenge 1) | Layout reflects a genuine personal/cultural reference (Challenge 2) | Data model supports multiple languages by design (Challenge 3) | Test plan links directly to specific WCAG success criteria |

This stage is approved when a reviewer could hand every document here to someone else and they could start building Stage 3 from them alone.
