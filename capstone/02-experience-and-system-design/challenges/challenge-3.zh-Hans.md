# 挑战 3：探索

**进阶选做。** 约 90 分钟。

从一开始就设计你的数据模型，让它支持第二种语言。

## 任务

1. 在 `data-model.md` 中，修改你的主要内容类型，让每一个文本字段（标题、描述、标签）都能容纳不止一种语言的值——例如，一个物体应该有 `title.en` 和 `title.es`，而不是一个单一的 `title` 字符串。
2. 在同一份文档中说明，你的 API 草图（`api.md`）会如何选择返回哪种语言，以及缺少翻译时会发生什么。
3. 在你的测试计划（`test-plan.md`）中添加一条，等第三阶段有代码可以测试时，检查这一行为。

## 为什么这很重要

XR Camp 是先用英语写成、之后再翻译的，它自己的课程目录和内容文件也正是采用这种模式。从一开始就为不止一种语言而设计，即便你还没有翻译，也能避免以后一次代价高昂的重新设计——这也是对你正在学习的这门课程本身是如何构建的一次真实练习。

## 完成标准

- [ ] 至少有一种内容类型是按字段而不是按整条记录复制来支持多语言的。
- [ ] API 草图解释了如何选择语言，包括一种回退方式。
- [ ] 测试计划中包含一项针对翻译缺失情况的检查。
