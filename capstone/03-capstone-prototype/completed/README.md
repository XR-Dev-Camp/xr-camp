# Completed - Capstone Prototype

The reference solution. Open it after you have tried the starter.

- `prototype-plan.md`, `test-log.md`, and `design-review.md` are Ana's filled-in worked example.
- `index.html` and `js/main.js` are a tiny working three.js prototype: one primitive exhibit stand, a scene description and 2D twin built from one shared data object, keyboard-only "turn" controls, and a reduced-motion-aware Pause button — a trimmed reuse of the pattern in `web3d-developer/07-interactive-web3d-experience`.
- `styles.css` extends the shared capstone stylesheet with the 3D lab layout used across `web3d-developer`.

Open everything through a local server (`http://`); modules need it.

Full instructions: [`../README.md`](../README.md).
