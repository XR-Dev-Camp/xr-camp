# 挑战 2：创意

**选做。** 约 45–60 分钟。

为原型加入一处体现你自己语言或社区的细节。

## 任务

1. 为你原型的数据添加一个标签、描述或细节，让它专属于你自己的语言、社区或文化（例如，一个有本地意义的物品名称、一段有文化特色的描述，或者一个使用非纯 ASCII 文字系统的标签——记住，A-Frame 内置的字体会丢失重音符号和中文，所以如果你需要在 3D 标签中用到这些，请使用 HTML 叠加层或 canvas 文字）。
2. 把它展示给一位不属于这个社区的人，并在 `design-review.md` 中记录，不额外解释的情况下，这对他们来说是否说得通。
3. 如果说不通，就调整这段描述。

## 为什么这很重要

一个只有作者本人才看得懂的毕业设计，还没有找到它真正的受众。把一个具有文化特色的细节，拿给一位不熟悉它的人测试，能告诉你：起作用的是你的解释，而不仅仅是你的这个参照本身。

## 完成标准

- [ ] 原型中包含至少一处扎根于你自己语言或社区的细节。
- [ ] 一位不属于这个社区的人评审过它，他们的反应被记录了下来。
- [ ] 3D 标签中的任何非 ASCII 文字，都使用了 HTML 叠加层或 canvas 文字，而不是 A-Frame 内置的文字几何体。
