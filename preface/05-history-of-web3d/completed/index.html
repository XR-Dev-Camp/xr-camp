Timeline of Web3D

  1. May 1994: At the first World Wide Web conference, Mark Pesce shows a 3D demo he built with Tony Parisi, and the idea of VRML, a language for 3D on the web, is born.
  2. 1997: VRML97 becomes an international standard (ISO/IEC 14772).
  3. 2004: X3D, the successor to VRML, becomes an ISO standard (ISO/IEC 19775).
  4. 2009: X3DOM, from Fraunhofer IGD, shows X3D directly inside HTML pages.
  5. 2010: Ricardo Cabello releases three.js on GitHub.
  6. March 2011: WebGL 1.0: browsers can draw fast 3D without plug-ins.
  7. October 2015: glTF 1.0, a compact format for 3D models, is released by the Khronos Group.
  8. December 2015: Mozilla's VR team releases A-Frame.
  9. January 2017: WebGL 2.0 ships in Chrome and Firefox.
  10. June 2017: glTF 2.0, now the standard format for 3D models on the web.
  11. December 2019: The WebXR Device API ships in Chrome 79.
  12. 2022: glTF 2.0 becomes an ISO standard (ISO/IEC 12113).
  13. May 2023: WebGPU ships in Chrome 113.

My conclusions

The same box looks different in each tool, because each one chooses a different camera, lighting, and size for you. Declarative tools make those choices so you can start fast. Imperative tools make you choose, which is more work, and more control.

If I were building a virtual museum for my town, I would start with A-Frame, because I could build it quickly and it opens in a headset. I would keep the 3D models as glTF, so they would still work if I moved to three.js later.
