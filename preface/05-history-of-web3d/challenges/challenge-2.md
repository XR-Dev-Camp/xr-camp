# Challenge 2: Creative

**Optional.** Roughly 45 minutes.

Add a fourth example: your world from Course 0.1.

## Task

1. Copy your `my-first-world/index.html` from Course 0.1 into `examples/`, and name it `my-world.html`.
2. In `index.html`, copy one whole `<figure>` block in the lab section, paste it after the others, and point its `<iframe>` at `examples/my-world.html`. Give it a new `title` and `<figcaption>`.
3. Replace the code snippet with the lines from your world that you are proudest of. Inside `<pre><code>`, write `&lt;` instead of `<` and `&gt;` instead of `>`, so the browser shows the code instead of running it.
4. Your world animates, so it must keep its **Pause animation** button.

## Why this matters

Your first world belongs in your lab: it is a data point too. And writing `&lt;` for `<` is how every tutorial you have ever read shows code on a web page.

## Done when

- [ ] The lab shows four examples.
- [ ] The new `<iframe>` has a `title` that describes your world.
- [ ] Your code snippet shows as text, not as a scene.
