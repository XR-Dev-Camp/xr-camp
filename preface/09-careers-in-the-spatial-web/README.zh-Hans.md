## 学习目标

完成本项目后，你将能够：

1. 描述网页、3D 和沉浸式开发领域的十二种职位，以及每一种职位日常都在做什么。

3. 把这些职位所需的技能，与 XR Camp 教授这些技能的课程对应起来。

5. 根据你实际拥有的时间，规划切实可行、带有日期的里程碑。

## 历史故事

### 不存在单一的「技术工作」

人们常常把技术工作想象成一个人独自敲代码。实际上，一个构建沉浸式博物馆的团队可能包括：一位与参观者交流的设计师、一位构建页面的开发者、一位准备 3D 模型的技术美术、一位与屏幕阅读器用户一起测试的无障碍专家，以及一位编写文档并教导他人的人。其中每一种都是一份职业。

### 十二种职位

| 职位 | 他们做什么 | XR Camp 在哪里教授 |
| --- | --- | --- |
| **前端开发者** | 构建网站和应用中人们能看到、能使用的部分 | 第一和第二阶段 |
| **网页与用户体验（UX）设计师** | 基于与真实用户一起开展的研究，设计产品的外观、感受和运作方式 | 每个阶段，特别是第一和第四阶段 |
| **无障碍专家** | 确保产品能被残障人士使用，并用辅助技术进行测试 | 每一节课，特别是 1.5 和 4.4 |
| **JavaScript 工程师** | 编写交互式应用背后的逻辑 | 第一、第二和第五阶段 |
| **Web3D 与 XR 开发者** | 构建在浏览器中运行的 3D 和沉浸式体验 | 第三和第四阶段 |
| **空间用户体验设计师** | 设计人们在 3D 和 XR 中如何移动、如何指向，以及如何保持舒适 | 课程 4.3 |
| **技术美术** | 准备 3D 模型、材质和特效，让它们既好看又运行流畅 | 第三阶段 |
| **地理空间开发者** | 构建处理位置数据的地图和应用 | 可选的地理空间方向 |
| **数字孪生开发者** | 构建真实地点的实时 3D 副本，并与传感器数据相连 | 第三和第五阶段 |
| **AI 辅助开发者** | 使用 AI 工具更快地构建，同时检查并理解每一个结果 | 课程 2.8 和 5.6 |
| **标准贡献者** | 帮助编写万维网的标准 | 课程 0.7 和 6.3 |
| **开发者布道师与教育者** | 教导开发者、编写文档并建设社区 | 课程 6.3 和 6.5 |

许多人在职业生涯中会在这些职位之间转换，而大多数真实的工作都会融合其中的两三种。

### 工作方式

- **受雇**于一家公司或机构，在办公室或远程工作：远程工作意味着你的工作不必局限在你所在的城市。
- **自由职业：** 为客户一个接一个地构建项目。你将在课程 6.4 中学习基础知识。
- **你自己的产品或工作室。**
- **非营利和公益性工作：** 博物馆、学校、医疗卫生机构和社区组织同样需要这些技能。

### 制定一份适合你生活的计划

XR Camp 的学习周期很长，因为它会带你一路走到专业水平。一份忽视你真实生活的计划，撑不过第一个忙碌的星期。请从你实际拥有的时间出发：如果你每周能学习四次、每次 45 分钟，每节课都会告诉你它需要几周时间。每个阶段结束时，你都会拥有一件可以展示的真实作品，所以即使在全部完成之前，你的进步也看得见。

### 在技能地图中保持诚实（TODO 4）

只使用三个等级：**尚未开始**、**已经起步**、**有信心**。「尚未开始」没有什么可羞愧的：XR Camp 就是为此而存在的。这张地图只有在真实的时候才有用，而你将在每个阶段结束时更新它。

## 关键代码解析

**`class="role mine"`。** 一个元素可以有多个类，用空格隔开。每张职位卡片都有 `role` 这个类；你选中的三张还带有 `mine`，CSS 会给它们加上一圈粗边框。这就是 HTML 中的一个词如何改变页面外观的方式。

**技能表格。** 每一项技能是一行，使用 `<th scope="row">`，这样屏幕阅读器会朗读「JavaScript，我现在的位置，尚未开始」，而不是孤零零的一句「尚未开始」。

## 无障碍要求

| 要求 | WCAG 2.2 | 原因 |
| --- | --- | --- |
| 选中的职位也用文字列出，而不只是被突出显示 | 1.4.1 | 边框不是唯一的辨别方式。 |
| 技能表格有标题和表头 | 1.3.1 | 每个等级都与它对应的技能保持关联。 |
| 标题按层级排列 | 1.3.1、2.4.6 | 便于浏览。 |
| `lang` 与你所用的语言一致 | 3.1.1 | 正确的发音。 |

## 性能注意事项

纯 HTML 和 CSS：瞬间加载。职业页面常常是招聘人员在两场会议之间用手机浏览的：快速而简洁，本身就是一种专业。

## 常见错误

| 错误做法 | 会发生什么 | 正确做法 |
| --- | --- | --- |
| 因为头衔好听而选择职位 | 一份不适合你的计划 | 选择你每天都乐于去做的事 |
| 把所有技能都标为「有信心」 | 这张地图就失去了作用 | 保持诚实；每个阶段都更新它 |
| 里程碑没有日期 | 它们会被无限期地推迟 | 使用日历上的真实日期 |
| 按你并不拥有的时间做计划 | 忙碌一周之后就放弃了 | 按你真实的一周来做计划 |

## 故障排查

**粗边框没有出现。** 检查拼写：`class="role mine"`，中间有一个空格，并且写在引号之内。

**我不知道自己想要哪些职位。** 这很正常。选出你现在最好奇的三个；以后你还可以更改。

## 值得认识的女性

**Mariana Costa Checa** 是一位秘鲁社会企业家。2014年，她联合创办了 **Laboratoria**：这是一个诞生于利马的组织，帮助在进入技术行业时面临重重障碍的女性（其中许多人来自低收入家庭）在拉丁美洲各地获得技术工作。它最初的做法是把她们培养成网页开发者和用户体验设计师。

Laboratoria 与 XR Camp 出发点相同：才华无处不在，机会却并非如此。已经有成千上万的女性通过它转换了职业，其中许多人正是从你现在所在的地方起步的。

## 标准聚焦

网络标准不仅创造了技术，也创造了职业。因为 HTML、CSS 和 JavaScript 是在每一款现代浏览器中表现都相同的开放标准，而 WebXR 也是以同样的方式构建的，所以你在 XR Camp 学到的技能不会被绑定在某一家公司或某一个国家：只要是万维网能够运行的地方，它们就能被带到任何工作中去。
