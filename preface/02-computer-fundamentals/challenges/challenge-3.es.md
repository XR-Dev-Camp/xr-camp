# Reto 3: Explorador

**Opcional.** Aproximadamente 30 minutos.

Instala VS Code y abre en él tu carpeta de XR Camp.

## Tarea

1. Descarga VS Code desde [code.visualstudio.com](https://code.visualstudio.com/). Es gratis y funciona en Windows, macOS y Linux.
2. Elige **File → Open Folder** (Archivo → Abrir carpeta) y abre tu carpeta `xr-camp` completa.
3. Explora la barra lateral: ahora cada lección está a un clic de distancia.
4. Abre tu página de configuración y fíjate en los colores: VS Code resalta el HTML para que las etiquetas, los atributos y el texto se vean distintos.
5. Actualiza la línea «Text editor» (editor de texto) de tu página de configuración.

## Por qué esto importa

Un editor de texto sin formato alcanza para aprender, pero quienes desarrollan de forma profesional usan un editor de código que entiende el lenguaje. Abrir la carpeta completa, en lugar de un solo archivo, es la forma en que vas a trabajar en cada proyecto de ahora en adelante.

## Se completa cuando

- [ ] Tu carpeta `xr-camp` está abierta en VS Code.
- [ ] Tu página de configuración dice qué editor usas.
