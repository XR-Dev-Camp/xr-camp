# 挑战 3：探索

**选做。** 约 30 分钟。

安装 VS Code，并在其中打开你的 XR Camp 文件夹。

## 任务

1. 从 [code.visualstudio.com](https://code.visualstudio.com/) 下载 VS Code。它是免费的，可以在 Windows、macOS 和 Linux 上使用。
2. 选择 **File → Open Folder**（文件 → 打开文件夹），打开你的整个 `xr-camp` 文件夹。
3. 浏览一下侧边栏：现在每一节课都只需点一下就能打开。
4. 打开你的设置页面，留意其中的颜色：VS Code 会给 HTML 加上高亮，让标签、属性和文字看起来各不相同。
5. 更新设置页面上「Text editor」（文本编辑器）那一行。

## 为什么这很重要

用纯文本编辑器学习已经足够，但专业开发者使用的是能理解编程语言的代码编辑器。打开整个文件夹，而不是只打开一个文件，就是你从现在起处理每个项目的方式。

## 完成标准

- [ ] 你的 `xr-camp` 文件夹已在 VS Code 中打开。
- [ ] 你的设置页面写明了你使用的是哪款编辑器。
