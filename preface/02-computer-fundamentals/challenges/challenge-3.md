# Challenge 3: Explorer

**Optional.** Roughly 30 minutes.

Install VS Code and open your XR Camp folder in it.

## Task

1. Download VS Code from [code.visualstudio.com](https://code.visualstudio.com/). It is free and works on Windows, macOS, and Linux.
2. Choose **File → Open Folder** and open your whole `xr-camp` folder.
3. Explore the sidebar: every lesson is now one click away.
4. Open your setup page and notice the colours: VS Code highlights HTML so that tags, attributes, and text look different.
5. Update the "Text editor" line on your setup page.

## Why this matters

A plain text editor is enough to learn, but professional developers use a code editor that understands the language. Opening the whole folder, rather than one file, is how you will work on every project from now on.

## Done when

- [ ] Your `xr-camp` folder is open in VS Code.
- [ ] Your setup page says which editor you use.
