## 学习目标

完成本项目后，你将能够：

1. 说出你的设备所用的操作系统，并找到它的版本。
2. 使用每位开发者每天都要用上几十次的键盘快捷键。
3. 创建、命名和查找文件与文件夹，并看懂文件扩展名。
4. 解释电脑上的文件与云端文件之间的区别。
5. 让浏览器保持最新版本，并会使用标签页、书签和截图。
6. 用强密码、密码管理器和两步验证登录来保护你的账户，并识别诈骗。
7. 在出问题时，按照一套冷静、可重复的步骤来处理。

### 第 1 步 —— 你的设备（TODO 1–2）

电脑、平板和手机都运行着一个**操作系统**：负责运行其他所有程序的那个程序。电脑上主要的操作系统有 Windows、macOS、ChromeOS 和 Linux，手机上则是 Android（安卓）和 iOS。

找到你的操作系统：

| 系统 | 在哪里查看 |
| --- | --- |
| Windows | **开始 → 设置 → 系统 → 系统信息** |
| macOS | **苹果菜单 → 关于本机** |
| ChromeOS | **设置 → 关于 ChromeOS** |
| Android | **设置 → 关于手机** |
| iPhone | **设置 → 通用 → 关于本机** |

把你的设备和系统写在页面上。每次向别人求助时，你都需要这些信息：「它不能用」很难回答；「它在 Windows 11 的 Firefox 里不能用」就容易多了。

### 第 2 步 —— 键盘、鼠标、触屏和触控板（TODO 3）

开发者使用键盘远远多于鼠标。下面这些快捷键几乎在所有程序中都能用。在 Mac 上，表格中写着 **Ctrl** 的地方请改用 **Command (⌘)**。

| 操作 | Windows、ChromeOS、Linux | macOS |
| --- | --- | --- |
| 复制 | Ctrl + C | ⌘ + C |
| 粘贴 | Ctrl + V | ⌘ + V |
| 剪切 | Ctrl + X | ⌘ + X |
| 撤销 | Ctrl + Z | ⌘ + Z |
| 保存 | Ctrl + S | ⌘ + S |
| 在页面中查找 | Ctrl + F | ⌘ + F |
| 全选 | Ctrl + A | ⌘ + A |
| 刷新页面 | Ctrl + R（在 Windows 和 Linux 上也可以按 F5） | ⌘ + R |
| 新建标签页 | Ctrl + T | ⌘ + T |
| 在程序之间切换 | Alt + Tab | ⌘ + Tab |

逐个练习，然后把你学会的快捷键填进页面上的表格。**撤销**是最重要的一个：在文本编辑器里，只要能撤销，你做的任何操作都不是永久的。

**Tab** 键可以在网页上的链接和按钮之间移动。许多人就是用这种方式浏览整个万维网的，这也是为什么你在 XR Camp 构建的每一个页面都必须能够只用键盘操作。

### 第 3 步 —— 文件、文件夹和扩展名（TODO 4）

文件名的结尾是一个**扩展名**，它告诉电脑这是什么类型的文件：`index.html` 是网页，`photo.jpg` 是图片，`notes.txt` 是纯文本。

许多电脑默认隐藏扩展名，这会导致像 `index.html.txt` 这样让人困惑的错误。请把扩展名显示出来：

- **Windows 11：** 文件资源管理器 → **查看 → 显示 → 文件扩展名**。
- **macOS：** 访达 → **设置 → 高级 → 显示所有文件扩展名**。

现在，像这样整理你的 XR Camp 文件夹：

```text
xr-camp/
├── my-first-world/     # from Course 0.1
├── my-setup/           # this lesson
├── journal/            # your learner journal and notes
└── downloads/          # lessons you have downloaded
```

**能为你节省大量时间的命名规则：** 使用小写字母、数字和连字符。不要用空格、重音符号或大写字母：写 `my-first-world`，而不是 `My First World!`。大多数网页服务器会把 `Photo.jpg` 和 `photo.jpg` 当作两个不同的文件，而文件名中的空格可能会让链接失效。

### 第 4 步 —— 下载、上传和云端（TODO 5）

- **下载**是把文件从互联网复制到你的设备上。它通常会保存在你的**下载**文件夹里：请立刻把它移到 `xr-camp/` 中。
- **上传**是把文件从你的设备复制到互联网上。
- **云端**是指存放在别人电脑上的文件，例如 Google Drive、OneDrive、iCloud 或百度网盘，并与你的电脑保持同步。

云存储很适合用来备份，但它也可能带来意外：一个文件可能显示在你的文件夹里，但在下载完成之前，它其实并不在你的电脑上。请把你的工作文件夹放在自己的设备上，再用云端或 U 盘保存一份副本。

在页面上写下你的备份计划：副本存放在哪里，以及你多久备份一次。

### 第 5 步 —— 你的浏览器（TODO 6）

使用一款现代浏览器，并让它保持更新：更新会修补安全漏洞，并加入你将要学习的万维网新功能。

| 浏览器 | 检查更新 |
| --- | --- |
| Chrome | **⋮ 菜单 → 帮助 → 关于 Google Chrome** |
| Firefox | **☰ 菜单 → 帮助（新版本中称为 Help and Report，即「帮助与报告」）→ 关于 Firefox** |
| Edge | **… 菜单 → 帮助和反馈 → 关于 Microsoft Edge** |
| Safari | 随 macOS 一起更新：**系统设置 → 通用 → 软件更新** |

然后练习：

- **书签：** 把本课和 XR Camp 仓库加入书签。
- **标签页：** 在一个标签页中打开课程，在另一个标签页中打开你的作品。
- **截图**，提交作业时会用到：
  - Windows：**Windows 键 + Shift + S**
  - macOS：**⌘ + Shift + 4**，然后拖动选择区域
  - ChromeOS：**Ctrl + Shift + 显示窗口键**
  - Android：**电源键 + 音量减键**
  - iPhone：**侧边按钮 + 调高音量按钮**（有主屏幕按钮的 iPhone：**侧边按钮 + 主屏幕按钮**）

### 第 6 步 —— 密码、两步验证登录和诈骗（TODO 7）

你的账户很快就会保存你的代码、你的作品集和你的职业声誉。现在就保护好它们。

1. **使用密码管理器。** 它会为每个网站记住一个不同的强密码，这样你只需要记住一个密码。你的浏览器就内置了密码管理器，而像 Bitwarden 这样的免费密码管理器可以在多台设备之间使用。
2. **开启两步验证登录**（也叫双重身份验证，即 2FA），先从你的电子邮箱开始。即使有人偷走了你的密码，没有你的手机，他们也无法登录。
3. **识别诈骗。** 对任何语气紧急、索要密码或验证码，或者带有你意料之外的链接的消息，都要保持警惕。XR Camp 永远不会向你索要密码，而且完全免费：任何要求你为它付费的人都是在撒谎。

**绝不要把真实的密码写在你的设置页面上。** 只写下你*已经*完成了哪些步骤。

在共用或公共电脑上：使用隐私窗口或无痕窗口，绝不让浏览器保存你的密码，并且每次都要退出登录。

### 第 7 步 —— 出问题的时候（TODO 8）

每位开发者的日常都少不了东西出故障。新手和专业人士的区别，不在于遇到的问题更少，而在于有一套冷静解决问题的步骤。

1. **读一读提示信息。** 错误信息通常会说明哪里出了问题。
2. **保存并刷新。** 很多问题只是文件没保存，或者页面不是最新的。
3. **撤销你最后一次修改。** 如果之前还能正常运行，问题就出在你刚刚做的事情上。
4. **重启程序**，然后再重启电脑。
5. **搜索完整的错误信息**，并加上引号。
6. **寻求帮助**，并提供你的设备、系统、浏览器、你预期会发生什么、实际发生了什么，以及一张截图。

用你自己的话，在页面上写下你自己版本的这套步骤。

## 关键代码解析

**`<dl>`、`<dt>` 和 `<dd>`：描述列表。** 你页面上的设备部分把名称和值配成一对（「系统：Windows 11」）。这正是描述列表的用途，它也能让屏幕阅读器知道页面上有一组名称和值。

**`<kbd>`：键盘输入。** 把一个按键放在 `<kbd>` 中（`<kbd>Ctrl</kbd> + <kbd>C</kbd>`），就在代码中把它标记为需要按下的东西，而不是需要阅读的文字。浏览器会用不同的样式显示它；大多数屏幕阅读器会把它当作普通文字读出，所以它周围的文字依然很重要。

**用 `<ol>` 写故障排查步骤。** 这些步骤有先后顺序，所以使用有序列表。

## 无障碍要求

| 要求 | WCAG 2.2 | 原因 |
| --- | --- | --- |
| 一个 `<h1>`，各部分使用 `<h2>` | 1.3.1 | 屏幕阅读器用户正是靠标题在页面中移动。 |
| 快捷键表格有 `<th scope>` 和 `<caption>` | 1.3.1 | 每个按键都始终与它的操作对应。 |
| 按键用 `<kbd>` 标记 | 1.3.1 | 代码会说明哪些文字是需要按下的按键。 |
| `lang` 与你所用的语言一致 | 3.1.1 | 发音正确。 |

## 性能注意事项

这个页面只有纯 HTML 和少量 CSS：即使从没有网络的 U 盘中打开，也能瞬间显示。一个在出问题时要用到的参考页面，必须在出问题时也能正常打开。

## 常见错误

| 错误做法 | 会发生什么 | 正确做法 |
| --- | --- | --- |
| 隐藏了文件扩展名 | 你不知不觉中保存成了 `index.html.txt` | 显示扩展名（第 3 步） |
| 名称中有空格或大写字母 | 在网页服务器上链接会失效 | 使用小写字母、数字和连字符 |
| 直接在「下载」文件夹里工作 | 文件会丢失或被删除 | 把所有东西移到 `xr-camp/` 中 |
| 把真实密码写下来 | 任何看到页面的人都能拿到它 | 记录步骤，绝不记录密码本身 |

## 故障排查

**我的文件打开后显示的是文字，而不是网页。** 检查扩展名是不是 `.html`，而不是 `.html.txt`。

**我找不到「下载」文件夹。** 打开浏览器的下载列表（在 Windows 和 ChromeOS 上按 **Ctrl + J**；在 Mac 上，Chrome 按 **⌘ + Shift + J**，Firefox 按 **⌘ + J**，Safari 则点击右上角附近的下载按钮），然后选择**在文件夹中显示**（在 Mac 上是**在访达中显示**）。

**截图快捷键没有反应。** 有些键盘还需要同时按下 **Fn** 键。用「截图」加上你的设备型号搜索一下。

## 标准聚焦

文件名和扩展名之所以能在所有系统上通用，是因为有共同的约定和标准。告诉浏览器「这是 HTML」或「这是一张 JPEG 图片」的媒体类型（`text/html`、`image/jpeg`）都在 IANA 注册，而 IANA 也正是负责协调互联网地址的那个组织。当你发布自己的第一个网站时，还会再次遇到它们。
