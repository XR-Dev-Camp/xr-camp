My backup plan

Every Sunday I copy my xr-camp folder to a USB drive. My journal is also in my cloud storage.

Staying safe

  • I use the password manager built into my browser.
  • Two-step sign-in is on for my email.
  • I never type my password after clicking a link in a message.
  • On the library computer I use a private window and always sign out.

When something goes wrong

  1. Breathe. Read the message slowly.
  2. Save, then reload.
  3. Undo my last change.
  4. Restart the program, then the computer.
  5. Search the exact error message, in quotes.
  6. Ask for help, with my device, browser, and a screenshot.
