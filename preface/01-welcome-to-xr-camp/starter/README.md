# Starter — Welcome to XR Camp

Begin here.

`index.html` is a small 3D world with six numbered `TODO` comments. Work
through them in order.

Copy this folder somewhere you can find again before you start editing, so you
always have the clean version to return to.

Full instructions: [`../README.md`](../README.md).

Do not open [`../completed/`](../completed/) until you have made your own
world. There is no wrong answer here: yours only has to be yours.
