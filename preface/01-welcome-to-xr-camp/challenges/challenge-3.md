# Challenge 3: Explorer

**Optional.** Roughly 30 minutes.

Build visually with the A-Frame Inspector.

## Task

1. Open your world in the browser and press **Ctrl + Alt + I** (on a Mac, **Control + Option + I**). The A-Frame Inspector opens.
2. Click a shape. Drag the coloured arrows to move it. Change its colour in the panel on the right.
3. The Inspector does **not** save your changes to your file. Copy the new `position` and `color` values from the panel into your code in the text editor, then save.
4. Close the Inspector with the same keys and reload. Your changes are now permanent.

## Why this matters

Professional 3D developers switch between visual tools and code all the time. Visual tools are faster for placing things; code is how the result is saved, shared, and understood. You have just used both.

## Done when

- [ ] You moved at least one shape in the Inspector.
- [ ] After a reload, the shape is still where you put it.
