# Reto 1: Fundamento

**Obligatorio.** Aproximadamente 30 minutos.

Clasifica cinco productos reales.

## Tarea

1. Piensa en cinco aplicaciones, juegos, sitios web o dispositivos que hayas usado o de los que hayas oído hablar: una aplicación de mapas, un videojuego, un filtro que te pone orejas de animal en la cara, el sitio web de un museo, un juego para visor.
2. Para cada uno, decide: ¿es 2D, 3D interactivo, VR, AR o MR? Algunos son más de uno.
3. Para cada uno, escribe una oración: ¿sería mejor, peor o igual en otra dimensión?

## Por qué esto importa

Las palabras VR, AR y MR se usan sin mucha precisión en la publicidad. Usarlas con precisión es parte de ser profesional, y parte de tomar decisiones honestas para las personas para quienes construyes.

## Se completa cuando

- [ ] Hay cinco productos clasificados en tu diario.
- [ ] Cada uno tiene una oración sobre si otra dimensión ayudaría.
