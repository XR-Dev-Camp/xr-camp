# Challenge 3: Explorer

**Optional.** Roughly 30 minutes.

Try your page in VR with a browser emulator.

## Task

1. In Chrome or Edge on a computer, install the free **Immersive Web Emulator** extension, published by Meta, from your browser's extension store. In mainland China, where the Chrome Web Store is not available, install it from Microsoft Edge's add-ons store.
2. Open your page from a web address that starts with `http://` or `https://` (the emulator does not work on a file you opened directly, whose address starts with `file://`). The easiest way: in VS Code, install the free **Live Server** extension, open your folder, and choose **Go Live**. Your page opens at an address like `http://127.0.0.1:5500`. Then click the emulator's icon in the browser toolbar. The page reloads with the emulator's control panel on top of it.
3. The **View in VR** button now appears, because the emulator pretends to be a headset.
4. Press it. Use the emulator's panel to move the pretend headset and controllers, and look at your object from inside.

## Why this matters

Most developers do not own every headset. Emulators let you test immersive pages on an ordinary computer. You will use one throughout Phase 4.

## Done when

- [ ] The VR button appeared with the emulator on.
- [ ] You took a screenshot from inside your immersive view.
