# 挑战 2：创意

**选做。** 约 45 分钟。

为你的社区设计一个沉浸式创意，并诚实地判断它是否真的应该做成沉浸式。

## 任务

1. 想一个你的社区中真实存在的需求：一段没有人记录过的地方历史、一个很难找到的集市、一项人们希望安全地学习的技能。
2. 为每一个维度各描述一个创意：一个 2D 页面、一个交互式 3D 体验，以及一个沉浸式体验。
3. 选出最好的一个，并解释原因。选择 2D 完全没有问题，而且往往是正确的选择。
4. 把你的创意作为一个新板块添加到你的页面上。

## 为什么这很重要

最优秀的空间开发者，并不是到处都使用 XR 的人，而是清楚地知道它在什么时候能帮上忙的人。这种判断力，就从现在开始培养。

## 完成标准

- [ ] 你的页面上有一个板块，用全部三个维度展示你的创意。
- [ ] 你选出了其中一个，并给出了理由。
