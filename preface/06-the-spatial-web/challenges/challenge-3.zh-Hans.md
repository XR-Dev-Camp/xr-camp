# 挑战 3：探索

**选做。** 约 30 分钟。

用浏览器模拟器在 VR 中试用你的页面。

## 任务

1. 在电脑上的 Chrome 或 Edge 中，从浏览器的扩展商店安装由 Meta 发布的免费扩展 **Immersive Web Emulator**。在中国大陆，由于无法使用 Chrome 网上应用店，请从 Microsoft Edge 的加载项商店安装。
2. 通过以 `http://` 或 `https://` 开头的网址打开你的页面（如果你直接打开文件，网址会以 `file://` 开头，模拟器在这种情况下无法工作）。最简单的方法：在 VS Code 中安装免费扩展 **Live Server**，打开你的文件夹，然后选择 **Go Live**。你的页面会在类似 `http://127.0.0.1:5500` 的地址打开。接着点击浏览器工具栏中的模拟器图标。页面会重新加载，并在上方显示模拟器的控制面板。
3. 现在 **View in VR**（在 VR 中查看）按钮出现了，因为模拟器假装自己是一台头显。
4. 按下这个按钮。用模拟器的面板移动这台假想的头显和手柄，从内部观察你的物体。

## 为什么这很重要

大多数开发者并没有每一款头显。模拟器让你可以在普通电脑上测试沉浸式页面。在整个第四阶段，你都会用到它。

## 完成标准

- [ ] 开启模拟器后，VR 按钮出现了。
- [ ] 你在沉浸式视图内部截了一张图。
