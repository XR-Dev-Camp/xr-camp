Before the web (1945–1988)

  1. July 1945

    "As We May Think"

    Vannevar Bush imagines the memex, a desk that stores documents and links them together by association.

  2. 1965

    The word "hypertext"

    Ted Nelson publishes the word hypertext: text that links to other text.

  3. 9 December 1968

    "The Mother of All Demos"

    Douglas Engelbart shows a mouse, clickable links, and live collaboration on screen, decades early.

  4. 29 October 1969

    The first ARPANET message

    Two computers in California exchange the first message on ARPANET, the network that grew into the internet.

  5. 1 January 1983

    ARPANET switches to TCP/IP

    The rules computers still use to talk to each other become the standard. Many call this the birth of the internet.

The document web (1989–1998)

  1. March 1989

    A proposal at CERN

    Tim Berners-Lee proposes a linked information system at CERN. His manager writes on it: "Vague but exciting."

  2. December 1990

    The first website

    The first web server, browser, and website run at CERN.

  3. 1991

    A browser for everyone

    Nicola Pellow's line-mode browser lets people use the web from simple text-only terminals, not just expensive workstations.

  4. 30 April 1993

    The web is given away

    CERN puts the web's software in the public domain, so anyone can build on it without paying.

  5. 1993

    Mosaic

    The Mosaic browser shows images inside pages, and the web starts to look like the web.

  6. 20 April 1994

    China connects

    China's first full connection to the internet goes live, after Hu Qiheng of the Chinese Academy of Sciences persuades the US National Science Foundation to allow it.

  7. October 1994

    W3C and CSS

    Tim Berners-Lee founds the World Wide Web Consortium (W3C) to write the web's standards. The same month, Håkon Wium Lie proposes CSS.

  8. 1995

    JavaScript

    Brendan Eich creates JavaScript at Netscape, famously in about ten days, so pages can respond to people.

  9. 1995

    Yinghaiwei

    Zhang Shuxin founds Yinghaiwei, often called China's first internet company, and brings dial-up internet to ordinary households.

  10. December 1996

    CSS becomes a standard

    CSS level 1 becomes a W3C Recommendation. Structure and style can finally be kept apart.

The application web (1999–2006)

  1. May 1999

    WCAG 1.0

    The first Web Content Accessibility Guidelines set out how to make the web work for disabled people.

  2. 1999

    Fetching without reloading

    Internet Explorer 5 adds XMLHTTP (later standardised as XMLHttpRequest), letting a page get new data without loading a whole new page.

  3. June 2004

    WHATWG

    Browser makers form the WHATWG to keep HTML evolving for web applications.

  4. February 2005

    "Ajax"

    The name Ajax is coined for pages that update themselves, as Gmail and Google Maps had just shown was possible.

The everywhere web (2007–2019)

  1. June 2007

    The web in your pocket

    The iPhone goes on sale with a full web browser. Phones become the main way many people use the web.

  2. December 2008

    WCAG 2.0

    Accessibility guidelines are rewritten around four principles: perceivable, operable, understandable, robust.

  3. May 2010

    Responsive web design

    Ethan Marcotte names responsive web design: one page that adapts to any screen.

  4. October 2014

    HTML5

    HTML5 becomes a W3C Recommendation, with native video, audio, and graphics.

  5. 2015

    Progressive web apps

    Frances Berriman and Alex Russell name progressive web apps: websites that install like apps and work offline.

  6. May 2019

    One HTML standard

    W3C and WHATWG agree to work on a single HTML Living Standard.

The spatial and intelligent web (2011–today)

  1. March 2011

    WebGL

    WebGL 1.0 lets browsers draw fast 3D graphics without plug-ins.

  2. December 2019

    WebXR

    The WebXR Device API ships in a major browser, so websites can open in virtual and augmented reality headsets.

  3. November 2022

    AI assistants go mainstream

    ChatGPT is released, and AI assistants begin to change how people search, learn, and write code.

  4. May 2023

    WebGPU

    WebGPU ships in a major browser, bringing modern graphics and AI computation to the web.

  5. October 2023

    WCAG 2.2

    The current accessibility guidelines add rules for focus, dragging, and target size.
