## 历史故事

每次学习阅读一个时代，然后把这个时代的里程碑添加到你的时间线上。**加粗**的里程碑出现在参考解决方案中；你可以使用它们，也可以自己去寻找。

### 万维网诞生之前（1945–1988）

早在万维网成为一项技术之前，它就已经是一个梦想。**1945年**，工程师万尼瓦尔·布什（Vannevar Bush）设想了一种名为 *memex* 的书桌，它可以存储文档并把它们相互链接起来，就像思绪从一个想法跳到下一个想法那样。**1965年**，泰德·尼尔森（Ted Nelson）为这个想法起了一个名字：*超文本*（hypertext），即链接到其他文本的文本。**1968年**，道格拉斯·恩格尔巴特（Douglas Engelbart）向满屋子的观众展示了鼠标、可点击的链接，以及身处不同地方的两个人同时编辑同一份文档。这场展示后来被称为「所有演示之母」。

与此同时，一个网络正在成长。**1969年**，加利福尼亚的两台计算机在 ARPANET 上交换了第一条消息。**1983年1月1日**，ARPANET 切换到 TCP/IP，这正是计算机至今仍在用来交换数据的规则。

**互联网不等于万维网。** 互联网是网络本身：在计算机之间传输数据的线缆、无线链路和规则。万维网是运行在互联网之上的一种东西：由链接连在一起、在浏览器中阅读的页面。电子邮件和视频通话都使用互联网，但它们并不属于万维网。

### 文档之网（1989–1998）

**1989年3月**，在 CERN（位于瑞士的欧洲物理实验室）工作的英国科学家蒂姆·伯纳斯-李（Tim Berners-Lee）提出了一种让研究人员通过链接共享文档的方法。到 **1990年12月**，第一台网页服务器、第一个浏览器和第一个网站已经在 CERN 运行起来。一位实习学生 Nicola Pellow 编写了一个简单的**行模式浏览器**（line-mode browser），让人们不仅能在昂贵的工作站上、也能在简易的文本终端上使用万维网。从诞生的第一年起，万维网就是为所有人而设计的。

最重要的决定出现在 **1993年4月30日**：CERN 将万维网的软件置于公有领域。任何人都可以构建浏览器、服务器或网站，无需请求许可，也无需付费。正因如此，你今天才能免费学习网页开发，XR Camp 也才得以存在。

随后，万维网迅速传播开来。**Mosaic** 浏览器（1993年）能够在页面中显示图片。**1994年4月20日**，**中国**首次实现与互联网的全功能连接；此前，中国科学院的胡启恒说服了美国国家科学基金会，同意中国接入。**1994年10月**，伯纳斯-李创立了**万维网联盟（W3C）**，负责制定万维网的标准；同年，Håkon Wium Lie 提出了 **CSS**。**1995年**，布兰登·艾克（Brendan Eich）在 Netscape 创造了 **JavaScript**；同年在中国，**张树新**创办了瀛海威，它常被称为中国第一家互联网公司。

### 应用之网（1999–2006）

页面开始变成程序。**1999年5月**，第一版**网页内容无障碍指南（WCAG 1.0）** 阐明了如何让残障人士也能使用万维网。同一年，Internet Explorer 5 获得了一种无需重新加载页面就能获取数据的方法，其他浏览器很快也纷纷效仿。到 **2005年**，Gmail 和 Google 地图展示了这种能力带来的可能，这项技术也有了一个名字：**Ajax**。**2004年**，各浏览器厂商组建了 **WHATWG**，让 HTML 持续演进，以满足应用的需要。

### 无处不在之网（2007–2019）

**2007年6月**，搭载完整网页浏览器的 iPhone 开始发售，手机逐渐取代电脑，成为大多数人访问万维网的方式。设计师们必须作出回应：**2010年5月**，Ethan Marcotte 提出了**自适应网页设计**（responsive web design，又称响应式网页设计）的概念，即一个页面适配所有屏幕。**HTML5**（2014年）新增了原生的视频、音频和图形功能。**2015年**，Frances Berriman 和 Alex Russell 提出了**渐进式网页应用**（progressive web apps）的名称：可以像应用一样安装、离线也能继续使用的网站。**2019年5月**，W3C 与 WHATWG 达成协议，共同维护唯一的 HTML 标准。

### 空间与智能之网（2011年至今）

**2011年3月**，**WebGL** 让浏览器无需插件即可快速绘制 3D 图形，万维网从此拥有了第三个维度。**2019年12月**，**WebXR Device API** 在一款主流浏览器中正式发布，网站从此可以在虚拟现实或增强现实头显中打开。**2022年11月**，**ChatGPT** 发布，AI 助手开始改变人们搜索、学习和编写代码的方式。**2023年5月**，**WebGPU** 为浏览器带来了现代图形和 AI 计算能力。**2023年10月**，**WCAG 2.2** 更新了无障碍规则，而上述每一项技术都仍然必须遵守这些规则。

这正是 XR Camp 所关注的那一部分故事，也是你即将参与书写的那一部分。

### 添加一个里程碑

每个里程碑都是同样的一段 HTML：

```html
<li>
  <time datetime="1994-04-20">20 April 1994</time>
  <h3>China connects</h3>
  <p>China's first full connection to the internet goes live.</p>
</li>
```

复制整段代码，从 `<li>` 到 `</li>`，粘贴到同一时代最后一段的后面，然后修改其中的三行。让里程碑保持按日期排序：这个列表是带编号的，所以顺序本身就是含义的一部分。

### 你自己的里程碑（TODO 8）

历史不只是发生在名人身上的事。互联网是什么时候来到你所在的城镇的？你，或者你的母亲，第一次上网是什么时候？去问问比你年长的人。把他们说的话记下来；当你把它添加到时间线上时，在学习日志中注明它的来源。

## 关键代码解析

**`<ol>`：有序列表。** 时间线是一个顺序很重要的列表，所以它是一个有序列表。屏幕阅读器会朗读「列表，共 10 项」，并读出每一项所在的位置，让听众知道自己已经读到了历史的哪一段。

**`<time datetime="1994-04-20">`。** 标签之间的文字是给人看的，可以用任何语言或格式书写：*20 April 1994*、*20 de abril de 1994*、*1994年4月20日*。`datetime` 属性是给机器读的，始终按「年-月-日」书写。无论页面使用哪种语言，搜索引擎、日历和翻译工具都会读取它。

**`<section aria-labelledby="...">`。** 每个时代都是一个以其标题命名的板块，这样屏幕阅读器用户就可以在时代之间跳转。

## 无障碍要求

| 要求 | WCAG 2.2 | 原因 |
| --- | --- | --- |
| 里程碑使用有序列表 | 1.3.1 | 顺序是含义的一部分。 |
| 每个日期都有 `datetime` | 1.3.1 | 机器可以可靠地读取任何语言中的日期。 |
| 标题按层级排列：一个 `h1`，时代用 `h2`，里程碑用 `h3` | 1.3.1、2.4.6 | 许多人正是靠标题来浏览长页面。 |
| 页面在手机宽度下可以正常使用 | 1.4.10 | 任何内容都不应该需要横向滚动。 |
| `lang` 与你所用的语言一致 | 3.1.1 | 告诉屏幕阅读器如何读出你的文字。 |

## 性能注意事项

这个页面只有 HTML 和少量 CSS：没有图片，没有脚本，也没有需要下载的东西。即使在很慢的网络下，它也几乎能瞬间加载。当你之后开始添加 3D 时，这一点值得记住。每一项功能都有代价，所以只在它能帮助读者时才添加。

## 常见错误

| 错误做法 | 会发生什么 | 正确做法 |
| --- | --- | --- |
| 把一段代码粘贴到另一段的内部 | 里程碑互相嵌套 | 粘贴在某个 `</li>` 之后，绝不要粘贴在它之前 |
| 忘记写 `datetime`，或写成 `20/04/1994` | 机器无法读取日期 | 始终按年-月-日书写：`1994-04-20` |
| 里程碑顺序错乱 | 带编号的列表讲述了一个错误的故事 | 每个时代内都按日期排序 |
| 事实没有来源 | 没有人能核实它 | 在学习日志中记下每一个来源 |

## 故障排查

**粘贴之后布局乱了。** 你很可能只粘贴了一段代码的一部分。每个 `<li>` 都需要对应的 `</li>`。撤销操作，然后重新复制整段代码。

**某个里程碑出现在错误的时代里。** 它被放进了错误的 `<ol>`。把它剪切下来，粘贴到正确的板块中。

**两个来源给出了不同的日期。** 这在历史研究中很常见。优先采用离事件最近的来源：相关机构自己的档案，或当时留下的记录。在学习日志中注明这处分歧。

## 值得认识的女性

**张树新**于 1995年创办了瀛海威，它常被称为中国第一家互联网公司。在那个中国极少有人上过网的年代，瀛海威向普通家庭销售拨号上网服务，并运营着中国最早的在线服务之一。在创办初期，它曾在北京中关村立起一块著名的广告牌，发问中国离信息高速公路还有多远。

瀛海威最终没能生存下来，它的故事在中国常被当作「起步太早」的教训来讲述。但走在时代前面，也正是先驱者所做的事。你时间线上的许多里程碑，都是由那些第一次尝试以失败告终的人建立起来的。

## 标准聚焦

万维网之所以能在任何设备、任何国家、任何浏览器上运行，是因为它的规则是开放标准：**HTML**（WHATWG）、**CSS**（W3C）和 **JavaScript**（Ecma International，标准名称为 ECMAScript）。没有任何公司拥有它们，任何人都可以免费阅读，任何人也都可以参与编写。你将在课程 0.7 中认识这些标准背后的组织。
