# Challenge 3: Explorer

**Optional.** Roughly 30 minutes.

Visit the first website ever made, and compare it with a website today.

## Task

1. Open [info.cern.ch/hypertext/WWW/TheProject.html](https://info.cern.ch/hypertext/WWW/TheProject.html), CERN's restoration of the first website.
2. Right-click the page and choose **View Page Source**. Do the same on any modern website.
3. In your journal, list three things the first website has that pages still have today, and three things it does not have.
4. Try the first website with only your keyboard. Then try the modern one. Which is easier?

## Why this matters

The first website is plain, but it is fast, readable on any device, and fully usable with a keyboard. Many modern websites are none of those things. Newer is not always better, and that is worth remembering every time you add a feature.

## Done when

- [ ] Your journal has both lists.
- [ ] You have written one sentence on what keyboard-only use was like on each site.
