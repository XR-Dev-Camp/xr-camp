# Reto 3: Explorador

**Opcional.** Aproximadamente 30 minutos.

Visita el primer sitio web de la historia y compáralo con un sitio web de hoy.

## Tarea

1. Abre [info.cern.ch/hypertext/WWW/TheProject.html](https://info.cern.ch/hypertext/WWW/TheProject.html), la restauración que hizo el CERN del primer sitio web.
2. Haz clic derecho en la página y elige **Ver código fuente de la página**. Haz lo mismo en cualquier sitio web moderno.
3. En tu diario, anota tres cosas que tiene el primer sitio web y que las páginas siguen teniendo hoy, y tres cosas que no tiene.
4. Prueba el primer sitio web usando solo el teclado. Luego prueba el moderno. ¿Cuál es más fácil?

## Por qué esto importa

El primer sitio web es sencillo, pero es rápido, se puede leer en cualquier dispositivo y se puede usar por completo con el teclado. Muchos sitios web modernos no cumplen ninguna de esas cosas. Más nuevo no siempre significa mejor, y vale la pena recordarlo cada vez que agregues una funcionalidad.

## Se completa cuando

- [ ] Tu diario tiene las dos listas.
- [ ] Escribiste una oración sobre cómo fue usar cada sitio solo con el teclado.
