## 故事

### 互联网和万维网不是一回事

**互联网**是一个由许多网络组成的全球网络：海底的线缆、街道下的光纤、连接到你手机的无线链路，以及让任何一台计算机都能给另一台计算机发送消息的共同规则（称为协议）。

**万维网**是运行在互联网之上的一种东西：由链接连在一起、在浏览器中阅读的页面。电子邮件、视频通话和网络游戏也都使用互联网，但它们并不是万维网。在课程 0.4 中，你已经了解了它们各自诞生的时间：互联网从 20 世纪 60 年代开始发展；万维网则在 1989–1990年间出现。

### 客户端、服务器和浏览器

每一次访问网站，都是两台计算机之间的一场对话：

- **客户端**负责提问。你上网浏览时，客户端就是你的**浏览器**：Chrome、Firefox、Edge、Safari。
- **服务器**负责回答。它是一台计算机，通常放在数据中心里，任务就是把页面发送给任何提出请求的人。

「服务器」说的是一项工作，而不是一种特殊的机器。在第五阶段，你会把自己的电脑变成一台服务器。

### 地址、名称和数字

互联网上的每台计算机都有一个由数字组成的 **IP 地址**，例如 `203.0.113.25`。人们记名字比记数字容易，所以我们使用 `example.org` 这样的**域名**。你可以从一种叫作域名注册商的公司那里租用一个属于自己的域名。

**域名系统（DNS）**是互联网的通讯录：它把名称转换成数字。你的浏览器会询问一个 DNS 解析器（通常由你的网络服务提供商运营）：「`example.org` 对应的数字是多少？」，并把答案记住一段时间。

**网站托管**是指租用服务器上的空间来存放你网站的文件，让网站一直保持在线。在课程 1.8 中，你将免费发布自己的网站。

### 请求和响应

浏览器和服务器之间使用 **HTTP**（超文本传输协议）来交谈。浏览器发送一个**请求**（「GET：把这个页面给我」），服务器则返回一个**响应**：一个状态码和具体内容。`https` 中的 `s` 表示这场对话是加密的，所以你和服务器之间的任何人都无法读取或篡改它。

| 状态码 | 含义 |
| --- | --- |
| `200` | 成功：这是你要的页面 |
| `301` | 已移动：页面搬到了新的地址 |
| `404` | 未找到 |
| `500` | 服务器出了问题 |

### 静态与动态，前端与后端

**静态**网站是一组按原样发送的文件：你到目前为止构建的页面都是静态的。**动态**网站会在你请求时才生成每个页面，而且通常要用到数据库：社交网络在同一个地址上，给每个人显示的首页都不一样。

**前端**是在浏览器中运行的一切：HTML、CSS、JavaScript。**后端**是在服务器上运行的一切：数据库、账户、保存你的数据。XR Camp 先教前端（第一至第四阶段），再教后端（第五阶段）。**网页应用**则把两者结合在一起。

## 关键代码解析

**按钮一开始是隐藏的。** `controls` 元素带有 `hidden` 属性。脚本运行之后才会把它移除。如果 JavaScript 运行失败或被关闭，访客会看到以普通列表形式显示的全部九个步骤，而永远不会看到点了也没反应的按钮。这叫作**渐进增强**：先做出一个能用的东西，再去改进它。

**`tabindex="-1"` 和 `focus()`。** 当你按下 **Next step**（下一步）时，脚本会把键盘焦点移到新的一步上。屏幕阅读器随即就会把它读出来。`tabindex="-1"` 让列表项可以通过脚本获得焦点，而不会被加入 Tab 键的切换顺序中。

**`aria-live="polite"`。** 「Step 3 of 9」（第 3 步，共 9 步）这条信息位于一个实时区域中，所以当它变化时，屏幕阅读器会把它播报出来。

## 常见错误

| 错误做法 | 会发生什么 | 正确做法 |
| --- | --- | --- |
| 想说「万维网」时却说成「互联网」 | 以后碰到电子邮件、游戏和应用时会混淆 | 万维网运行在互联网之上 |
| 以为服务器是一种特殊的计算机 | 听起来比实际更难 | 任何响应请求的计算机都是服务器 |
| 照抄本指南中的句子 | 做完了却没有真正理解 | 用你自己的话写每一步 |

## 值得认识的女性

**胡启恒**领导了让中国首次实现与互联网全功能连接的项目，这一连接于 1994年4月20日开通。作为中国科学院副院长，她说服了美国国家科学基金会，同意中国接入。1997年，她创建了中国互联网络信息中心（CNNIC），负责管理中国的 `.cn` 域名：也就是你在本课中学到的那种「通讯录」。2013年，她入选互联网名人堂。

你示意图中的每一步，都依赖于网络之间的相互连接。对数亿人来说，这种连接始于胡启恒的工作。

## 标准聚焦

HTTP 由 **IETF**（互联网工程任务组）维护，并以一种叫作 RFC 的文档形式写成，任何人都可以阅读。DNS 也是一项 IETF 标准，而 **ICANN** 负责在全球范围内协调域名和 IP 地址。你将在课程 0.7 中再次认识这些组织。
