# 挑战 3：探索

**选做。** 约 30 分钟。

在浏览器的开发者工具中数一数一个真实页面的请求数。

## 任务

1. 打开任意一个网站。按 **F12**（在 Mac 上按 **⌘ + Option + I**）打开开发者工具。在 Safari 中，要先开启**设置 → 高级 → 显示网页开发者功能**。
2. 选择 **Network**（网络）标签，然后刷新页面。
3. 每一行就是一个请求。找出：
   - 总共有多少个请求（显示在底部）；
   - 第一个请求（HTML 页面）的状态码；
   - 一个 CSS 请求、一个 JavaScript 请求和一个图片请求。
4. 对你自己的示意图也做一遍。比较一下这些数字。

## 为什么这很重要

这就是你示意图中的第 8 步，正在实时发生。每个请求都要花费时间和流量。在网速慢或流量贵的网络上，一个有 200 个请求的页面会让你的访客花掉真金白银。

## 完成标准

- [ ] 你写下了两个页面各自的请求总数。
- [ ] 你在那个真实网站上找到了一个 CSS 请求、一个 JavaScript 请求和一个图片请求。
