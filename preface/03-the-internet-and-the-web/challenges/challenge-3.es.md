# Reto 3: Explorador

**Opcional.** Aproximadamente 30 minutos.

Cuenta las solicitudes de una página real en las herramientas para desarrolladores de tu navegador.

## Tarea

1. Abre cualquier sitio web. Presiona **F12** (en una Mac, **⌘ + Option + I**) para abrir las herramientas para desarrolladores. En Safari, primero activa **Settings → Advanced → Show features for web developers** (en los ajustes avanzados de Safari, la opción que muestra las funciones para desarrolladores web).
2. Elige la pestaña **Network** (Red) y recarga la página.
3. Cada fila es una solicitud. Encuentra:
   - cuántas solicitudes hubo en total (aparece en la parte de abajo);
   - el código de estado de la primera solicitud (la página HTML);
   - una solicitud de CSS, una de JavaScript y una de una imagen.
4. Haz lo mismo con tu propio diagrama. Compara los números.

## Por qué esto importa

Este es el paso 8 de tu diagrama, pasando en vivo. Cada solicitud cuesta tiempo y datos. Con una conexión lenta o cara, una página con 200 solicitudes le cuesta dinero de verdad a quien la visita.

## Se completa cuando

- [ ] Anotaste el total de solicitudes de las dos páginas.
- [ ] Encontraste en el sitio real una solicitud de CSS, una de JavaScript y una de una imagen.
