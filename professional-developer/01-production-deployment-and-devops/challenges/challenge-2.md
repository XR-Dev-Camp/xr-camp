# Challenge 2: Creative

**Optional.** Roughly 45–60 minutes.

Make the release dashboard genuinely useful for your own project or community.

## Task

1. Pick a real project you have already built in XR Camp (an earlier lesson's `completed/`, or something of your own), and adapt `index.html` to describe deploying that project instead of the exhibit.
2. Rewrite the "Outside GitHub" section for the audience you have in mind: if you or your community mostly use GitHub already, say so plainly instead of hedging; if mainland-China access matters to your audience, say what you would actually try first, and why, while still being honest that you have not tested it yourself.
3. Translate the dashboard's own text into your language, keeping the same structure.

## Why this matters

A pipeline that only you understand is a pipeline only you can fix. Writing it up for your own project, in your own words and your own language, is what makes it something a friend or a future teammate could actually pick up.

## Done when

- [ ] The dashboard describes a real project you have built, not the exhibit.
- [ ] The "Outside GitHub" section reflects a genuine audience and a cautious, honest tone.
- [ ] The page still passes a WCAG 2.2 AA check.
