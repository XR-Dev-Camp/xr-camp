# 挑战 2：创意

**选做。** 约 45–60 分钟。

让发布仪表盘对你自己的项目或社区真正有用。

## 任务

1. 选一个你已经在 XR Camp 中做过的真实项目（之前某节课的 `completed/`，或者你自己的作品），并调整 `index.html`，让它描述的是部署那个项目，而不是这个展览。
2. 为你心里想着的受众重新撰写「Outside GitHub（GitHub 之外）」这一节：如果你或你的社区大多已经在用 GitHub 了，就直接明确地这么说，不要含糊其辞；如果中国大陆的访问情况对你的受众很重要，就说明你会先实际尝试哪个方案、为什么，同时诚实地说明你自己还没有真正测试过它。
3. 把仪表盘自己的文字翻译成你的语言，保持相同的结构。

## 为什么这很重要

一条只有你自己看得懂的流水线，也就只有你自己能修。用自己的话、自己的语言，为自己的项目把它写清楚，才能让一位朋友或未来的队友真正接手它。

## 完成标准

- [ ] 仪表盘描述的是你已经完成的真实项目，而不是这个展览。
- [ ] 「Outside GitHub」这一节体现出真实的受众，语气谨慎而诚实。
- [ ] 这个页面仍然能通过 WCAG 2.2 AA 检查。
