# 挑战 2：创意

**选做。** 约 45–60 分钟。

把你的案例分析和提案，扎根在你自己的语言、文化或社区中的一个真实项目或问题上，而不是一个泛泛的示例上。

## 任务

1. 在 `freelancing-basics.md` 的提案模板中，把那个虚构的项目，换成你在自己社区里注意到的一个真实、具体的需求：一个没有无障碍网站的本地组织、一家可以用上简单在线形象的小商户，或者一个可以用上像你在第三、四阶段搭建的那种小型 3D 或 Web 展览的文化团体。
2. 围绕这个真实的需求，重新撰写提案中「我理解你的需求是」和「我将交付的成果是」这两个部分。
3. 在你的案例分析中加一两句话，说明你的虚拟文化展览与你自己的文化或社区有没有什么关联（一个故事、一件物品、一项你选择去呈现的传统，或者如果重新制作，你会加入的东西）。
4. 如果你愿意，可以用体现你自己声音的方式，来撰写简历中的职位说明或类似 LinkedIn 的标题，而不是套用一句从别人那里翻译过来的行业套话。

## 为什么这很重要

一个全球平台上最显眼的那些客户，往往不是你自己所在城市或地区最显眼的那些客户。说出一个真实的、本地的需求，并愿意在你的专业文字中描述你自己的文化，而不是把它抹去，往往会让你的工作更容易被人发现，而不是相反。

## 完成标准

- [ ] 提案描述的是一个来自你自身处境的真实、具体的需求。
- [ ] 案例分析中说明了与你自己的文化或社区的真实关联，或者诚实地说明目前还没有这样的关联。
- [ ] 这套材料包中的某处能看到你自己的声音，而不只是一句泛泛的行业套话。
