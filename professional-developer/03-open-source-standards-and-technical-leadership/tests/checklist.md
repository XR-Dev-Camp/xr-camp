# Project check

Work through this list before you submit.

## Standards participation
- [ ] A free W3C account exists, and a real Community Group is named with a reason it fits.
- [ ] The explainer follows every section of the real W3C TAG explainer template, in order.
- [ ] The planned spec issue names a real repository, a clear title, and a body that gives context, not just a request.
- [ ] The spec issue was actually filed (Challenge 1), and the outcome, or lack of one so far, is recorded honestly.

## Contribution and review
- [ ] `contribution-record.md` links a real, filed issue or pull request on a real public repository.
- [ ] The contribution record explains why it was chosen and what made it a good issue or pull request.
- [ ] A review of someone else's real work is recorded, quoting the actual comment left.

## Running a small project
- [ ] `mini-project/GOVERNANCE.md` names at least two roles and how a decision gets made for a small and a large change.
- [ ] `mini-project/CODE_OF_CONDUCT.md` names a real, monitored reporting path, not just "contact a maintainer."
- [ ] The licence decision record names an exact SPDX identifier and explains the trade-off it makes.

## The summary page
- [ ] `index.html` has one clear `<h1>` and a logical heading order.
- [ ] Every section links to the document it summarizes; no content is only duplicated with no link back.
- [ ] No placeholder or invented status appears; everything reflects the actual documents.

## Accessibility
- [ ] The page passes a WCAG 2.2 AA check (for example, `pa11y`).
- [ ] The keyboard can reach every link.
- [ ] Focus is visible at all times.
- [ ] Colour contrast meets WCAG 2.2 AA.
- [ ] Every list styled with `list-style: none` has `role="list"`.

## Responsiveness
- [ ] The page works at mobile width.
- [ ] Nothing overflows horizontally.

## Quality
- [ ] The browser console has no errors on `index.html`.
- [ ] Comments explain intent, not syntax.
- [ ] No invented facts appear anywhere in the plan; anything uncertain is phrased cautiously or left out.
