# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), a widely used code of conduct template for open-source communities. Adopting a well-known template, instead of writing one from scratch, means contributors already know what to expect, and it has been reviewed by far more people than one maintainer could ask.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of background or experience level.
