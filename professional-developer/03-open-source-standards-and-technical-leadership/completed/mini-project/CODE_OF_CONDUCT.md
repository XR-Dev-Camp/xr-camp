# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), a widely used code of conduct template for open-source communities. Adopting a well-known template, instead of writing one from scratch, means contributors already know what to expect, and it has been reviewed by far more people than one maintainer could ask.

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of background or experience level.

## Scope

Applies everywhere project business happens: issues, pull requests and their comments, and the project's discussion board. It also applies to any in-person or video meetup organised under the project's name.

## Enforcement

Reports go to a monitored project email address, checked by the maintainer team, not a single individual's personal inbox (so a report is never blocked on one person being reachable). Anyone uncomfortable emailing a maintainer directly may instead flag any project comment for review.

## Consequences

A maintainer not involved in the report reviews it and talks privately with everyone concerned before deciding anything. Outcomes range from a private word about a specific comment, to a public warning, to removal from the project for repeated or serious violations. The goal is a proportionate response that keeps the project welcoming, not a fixed punishment for a fixed offence.
