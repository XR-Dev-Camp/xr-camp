Running a small open-source project

scene-description-lint: a small imagined command-line tool that checks a folder of HTML files for a scene-description element next to every 3D scene. Its governance names two roles and a lightweight approval rule; its code of conduct is the Contributor Covenant with a real reporting address; its licence is MIT, chosen so any learner's project can use it freely.

Done. See the governance, code of conduct, and licence decision record linked above.

Technical leadership: mentoring

For anyone joining scene-description-lint, the plan is to explain the "why" before the "how", by pointing to docs/en/xr-accessibility.md first. On a first pull request: name something done well, ask questions rather than give instructions where a choice is a matter of taste, and always explain the reason behind a requested change.

Done. See section 8 of the plan.
