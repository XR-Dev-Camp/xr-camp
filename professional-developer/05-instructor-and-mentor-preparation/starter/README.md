# Starter - Instructor and Mentor Preparation

Begin here.

- `lesson-template/` is a complete, empty copy of the XR Camp lesson anatomy: `README.md`, `project.json`, `starter/`, `completed/`, `challenges/`, and `tests/checklist.md`. Choose this if you are writing a short lesson. TODOs 1-9 live inside it, in the order the walkthrough uses them.
- `mentor-plan-template.md` is a single document with the sections a mentor plan needs. Choose this instead if you are writing a mentor plan. It carries TODOs 10-11.
- `index.html` is a short hub page. It starts pointing at both templates; TODO 12 asks you to update it once you know which one you finished.

Choose one main deliverable. Challenge 3 is the only place you are asked to try the other.

Open everything through a local server (http://).

Full instructions: [`../README.md`](../README.md).
