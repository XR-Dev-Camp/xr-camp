# 挑战 3：探索

**进阶选做。** 约 90 分钟。

把另一项成果也写出来：如果你在挑战 1-2 中写的是课程，现在也写一份简短的导师计划；反之亦然。

## 任务

1. 从 `starter/lesson-template/` 或 `starter/mentor-plan-template.md` 中，复制你还没有用过的那一个模板。
2. 写出第二份、规模更小的成果：如果你先写的是课程，现在为同一个主题写一份导师计划，说明你会如何一次交流一次交流地指导某人完成你的课程；如果你先写的是导师计划，现在写一节微型的、只有一次交流的课程（一次 45 分钟的交流、一个可见的成果、一个无障碍的完成页面），主题是任何你熟悉的初学者话题。
3. 让两者互相引用：你的导师计划应该提到一位导师会如何把你的课程（或类似的课程）当作它的一个实例讲解来使用，你课程的 README 也应该用一句话说明一位导师可能会如何引入它。
4. 如果你的第二份成果包含一个带有任何 3D 内容的完成页面，它仍然必须通过 `tests/checklist.md` 中同样的无障碍检查清单，包括「3D 与 XR（人工检查）」这一节。

## 为什么这很重要

教学和指导是同一项技能的两面：一节课程为一个陌生人提供一条清晰、自成一体的路径；一份导师计划则为某一位具体的人提供一条有引导、能适应变化的路径。XR Camp 真正的讲师往往两者都会做。尝试你没有选择的那项成果，能让你看清「无障碍教学」「给出反馈」和「处理伤害事件」这些能力中，哪些部分能在两者之间通用，哪些不能。

## 完成标准

- [ ] 存在第二份完整的成果（一节简短的课程，或一份导师计划，取决于你之前没写的是哪一个）。
- [ ] 两份成果至少在一处互相引用了对方。
- [ ] 任何新的完成页面依然完整通过了 `tests/checklist.md`，如果适用，也包括 3D 与 XR 那一节。
